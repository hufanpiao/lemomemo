# 迷你架构文档（M4 样例：只留 3.3 C 和附录 A 末尾两段）

**C. private schema 的授权白名单**（样例）
```sql
-- 注释行不比
alter default privileges for role postgres revoke execute on functions from public;   -- 0001
revoke execute on all functions in schema private from public, anon, authenticated;   -- 0001
grant usage on schema private to authenticated;                                       -- 0001
grant execute on function private.is_active() to authenticated;                 -- 0001  对照：迁移里有、标对了
grant execute on function private.report_tz_impl(text, uuid, text) to authenticated;   -- B1 新迁移  对照：B1 的还没建，不报
grant execute on function private.files_authorize_impl(text, jsonb) to authenticated;   -- 0004  对照：写在 0004
grant select on private.admins to service_role;                                       -- 0004  违规：标 0004，实际写在 0001
grant execute on function private.gone() to authenticated;                      -- 0001  违规：标 0001，0001 里没有
grant select on private.invites to service_role;
-- 上一行违规：行尾没标文件
```
