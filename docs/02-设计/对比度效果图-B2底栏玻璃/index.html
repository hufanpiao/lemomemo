底栏玻璃上的字：改前 / 改后效果图（R-296）

明早清单第 73 条：规定玻璃上的字对玻璃本身至少 3:1，字对柔光至少 4.5:1。下面把真实底栏（四个页签、“＋”、选中液滴）放在三种典型内容上：浅色列表、深色列表、带图片的卡片。两种皮肤各有浅色、深色、自动深浅三组。左边是改前，右边是改后（主持人推荐值），手机上改前在上、改后在下。

数值按 build/check_contrast.py 的算法：半透明玻璃先叠到“最坏底色”上再算（深玻璃叠在纯白 / 柠檬黄 / 最亮项目色上，浅玻璃叠在墨黑 / 最深项目色上，取最低），模糊、高光、柔光的扩散都不算。所以“浅色列表”那一格（白底）就是深玻璃的最坏情况；深色列表上实际对比度远高于表里的数。两种皮肤底栏令牌相同，数值一样。
