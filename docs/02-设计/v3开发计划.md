# v3 开发计划

- 范围：[修改清单-v3](修改清单-v3.md)（已冻结）+ [需求澄清-v3](需求澄清-v3.md)
- 验收：[测试用例-v3](../06-测试/测试用例-v3.md)；通过标准是 P0 100%、P1 ≥ 95%，没有未解决的高严重度缺陷
- 界面依据：[草图第 3 版](草图-v3/草图.html)（定稿）；草图里的新样式开发时拆进 src/styles/components/ 并写进 build/manifest.json
- 规矩：[架构约定](../10-架构/架构约定.md)；每个任务都要通过 `python build/build.py`（含架构检查）和 `node tests/run-all.mjs`
- 分支：`feature/v3`，从 main 拉出；全部完成并通过各项审查后合并，打标签 `v3.0.0`
- 执行人：除特别注明外，都由主持人做

## 完成标准（每个任务都要满足）
1. 代码放在架构约定规定的层，构建和架构检查通过。
2. 有对应的单元测试，或者测试用例里的页面用例已在本地跑过。
3. 数据字典、文件登记册、CHANGELOG 已同步更新。
4. 在 375×812 和 1280×820、浅色和深色下目测过，控制台无报错。
5. 单独提交一次，提交说明写清楚任务编号。
