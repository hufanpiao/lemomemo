柠檬记 4.0.0：两套皮肤的视觉稿

柠檬记 4.0.0 的视觉定稿，2026-10-24 按第七轮整体检查和 R-76～R-92 修订过。这里定颜色、字体、圆角、阴影、玻璃、动效和触控区，全部写成变量；后半部分另有登录页和官网首页。

以哪份为准：视觉以本稿（皮肤视觉稿）为准，交互以定稿线框（草图 v4 定稿）为准，两者冲突时以需求记录里编号最新的一条为准。

简洁（默认）

  • 在 v3 的基础上往前走：便当格、马卡龙项目色、黑色胶囊导航、柠檬黄 #F2DF4A 的“＋”和主按钮都保留。
  • 面板一律纯白（深色是 #1C1D22）、不加阴影，只靠底色区分；圆角分三级：大面板 28、小卡片 20、输入框 14，胶囊全圆。
  • 黄色只留给“该你动手”的地方：主按钮、“＋”、“现在”卡的进度条、时间河上的“现在”时间。其他地方用黑白灰，所以黄色一出现就知道该点哪里。
  • 深色模式里，“现在”卡从黑色换成整块柠檬黄，在黑底上一眼就能找到。

磨砂玻璃

  • 底色就是图标的光：左上和右下两团柠檬黄柔光，右上一点粉，左下一点蓝，位置和图标里的光斑一致。
  • 玻璃用在哪里（按现状，R-79、R-80、R-89）：底部导航 70% 不透明＋模糊 6px（两套皮肤都是）；提醒响起时的按钮条是半透明玻璃（R-89，有意和提示条不同）；底部弹层、录音面板、隐私记解锁卡是玻璃。“＋”是实色柠檬黄，“已记下”提示条是实色（--glass-solid，不模糊）。列表和卡片一律实色，保证字清楚。
  • 选中状态从“黑底白字”换成“柠檬黄底黑字”；“现在”卡浅色时是一块柠檬黄，深色时是带黄光的深色卡。
  • 减少透明效果时，玻璃、导航、遮罩都换成实色后备值（令牌表里的 --glass-solid），也不再模糊。iPhone 的网页读不到系统“降低透明度”，所以在“设置 › 皮肤”里放一个“减少透明效果”开关，默认关（R-84）；Windows 仍自动跟随系统的“透明效果”。页面顶部可以勾“模拟‘减少透明效果’”来看效果。

和图标怎么呼应

  • 柠檬黄的光：图标的主光就是 #F2DF4A。两套皮肤的主按钮、“＋”和“现在”的标记都用它；磨砂玻璃的底色直接取自图标的光斑。
  • 三根声纹：图标上的三根黑色竖条，就是录音面板里的声波。录音时画面里的声波和图标是同一种笔画：黑色（深色模式用柠檬黄）、圆头、粗细一致。
  • 玻璃圆片：录音按钮外面的两圈光晕，就是图标玻璃圆片的外沿和内圈；登录页和官网首屏背景里那块大玻璃圆片，直接用了图标的主体。
  • 启动画面：登录页、Safari 引导页和官网首屏都用启动画面的柠檬光做背景（令牌 --login-bg），第一眼看到的和启动时看到的一样。

字体

  • 数字（时间、日期、计时）：Manrope，等宽数字；没有时退回 SF Pro Rounded、系统字体或 Segoe UI。
  • 中文：系统字体，iPhone 上是苹方，Windows 上是微软雅黑 UI。
  • 韩文：Apple SD Gothic Neo、Malgun Gothic 优先，按词换行（word-break: keep-all）。
  • 给开发的建议：只自带 Manrope 一种字体，裁成拉丁字母和数字（woff2 大约 30 KB，开源 OFL 许可）；中文、韩文用系统字体，不打包。本页没有引用任何外部字体文件，没装 Manrope 的电脑上看到的是退回后的字体。

自评结果，以及据此改了什么

按 design-critique 的五项（第一眼、可用性、层级、一致性、可读性），用无头 Edge 逐个看了四种组合的手机版和电脑版截图，再用脚本实测对比度。分数是改完以后的（10 分制）。

看截图和跑脚本发现的问题，以及改了什么：

  • 玻璃上的字不够清楚：第一次跑对比度，有 5 项没过，都在玻璃上：深色玻璃上的次要文字只有 2.93，深色导航文字 3.90，深色提示条小字 3.78，浅色弹层的次要文字 3.81，深色底色上的次要文字 4.42。把浅色玻璃的透明度从 72% 提到 80%、深色从 74% 提到 84%，并把相关的灰字调亮或调深一档，现在全部 ≥ 4.5。
  • 令牌表只看得到一列：字体那几行的取值很长又不换行，把第一列撑得很宽，其他三列被挤到外面。改成单元格内换行。
  • 瀑布流卡片底部挤成两行：分类胶囊“韩国生活”被折成两行。改成不换行、字号小一号，时间放不下时省略。
  • 韩文日期折行：“10월 24일 토요일”在 30 px 下放不下，折成两行。韩文日期改成 27 px 不换行。
  • 随手记最后一条被输入行挡住：手机列表底部加大留白，最后一条能完整滚出来。
  • 电脑月历超出窗口：月历放大 1.25 倍后最后一行被裁掉，改成 1.06 倍。
  • 电脑提示条太挤：放在中间一栏底部时，两颗按钮和文字挤在一行，标题和说明都被折成好几行。改成上下两层：上面是文字，下面右对齐放“撤销 / 修改”。
  • 深色模式下手机外框看不见：外框和页面都是近黑色，加了一圈很淡的描边。
  • 官网手机首屏：主视觉里的手机被裁掉了底部，拆出来的三条盖住了录音面板。缩小手机、收窄卡片，并加了一行“AI 拆成了 3 条”。深色页面上官网手机框的状态栏看不见，也一并修了。
  • 官网隐私说法：原来写的“你记的东西只有你自己能看到”不成立（服务器能访问、内容会交给谷歌）。已按 R-81 改成产品负责人定的原文，官网、登录页中韩两版都放。

已定（R-84）：iPhone 网页读不到系统“降低透明度”，在“设置 › 皮肤”加“减少透明效果”开关（默认关），打开后用同一组实色后备值；Windows 版读系统的“透明效果”设置，切换同一组变量。还需开发实测：官网写的 iOS 版本要求（“推荐 iOS 17 以上，最低 16.4”）、Face ID 在主屏幕版里能不能用。

第七轮整体检查之后改了什么（2026-10-24，R-76～R-100）

  • 隐私说法（R-81）：官网、登录页改成产品负责人定的原文，韩文给了对应译文。
  • 邀请码（R-83）：只有管理员能发；所有“请朋友在设置里发一个”改成向柠檬记的负责人要；校验只显示“邀请码有效”，不显示邀请人；示例改成 12 位。设置里的“邀请朋友”只在管理员账号出现（视觉稿画的是管理员）。
  • iPhone 安装（汇总严重 2）：第 1 步先点“开始使用”（或打开 lemomemo.com/app），在 App 页面里再“添加到主屏幕”；首页按钮“登录”改成“开始使用”，链接 /app/；网页登录地址改成 /app/。安装说明加了大陆收 Gmail 验证码的提醒（R-91）。
  • Windows（R-87、R-90）：“即将推出”改成可用的“下载 Windows 版”；电脑版不做语音，Ctrl+Alt+空格 改成弹出打字框（官网、电脑侧栏提示、电脑设置、电脑“录音”画面都改了）。
  • 名字（R-88）：主屏幕上的名字是“Lemo”；App 内中文名仍是柠檬记，韩文界面和电脑韩文标题栏是“레모”。标语统一为“说一句，清清爽爽记下来”，韩文统一为“한마디면 깔끔하게 기록돼요”。
  • 官网韩文：正文、安装、邀请制说明、隐私、页脚都有韩文完整一页；页脚改成“隐私说明 · 使用条款”链接占位。
  • 不说过头：Face ID 写成“可用 Face ID（支持的设备）或密码”；“手机和电脑一起响”加了“装了电脑版时”；iOS 写“推荐 iOS 17 以上，最低 16.4”，需开发实测。
  • 设置：皮肤下加“减少透明效果”开关（默认关，R-84）；“随手记显示方式”写明只对本类设备生效；隐私记“离开 1 分钟上锁”（R-86）不变；补画朋友第一次登录的“AI 处理告知”。
  • 贴底元素：底部导航离底 28 → 42px、“＋”28 → 40px（和导航中线对齐，同线框），提示条和提醒按钮条 → 118px，输入行 → 116px，录音按钮 → 42px，都和线框一致。
  • 触控区：所有可点元素点击区至少 44×44（小按钮看得见 32px，用伪元素外扩），逾期两颗按钮间距 8px；页面顶部可勾“显示 44px 点击区”检查。令牌表加了 --hit。
  • 对比度：“没赶上”淡红描边从 55% 调到 75%，四种组合 ≥ 3.25:1；补测纪念日菱形、平铺后的项目标记；遮罩和背后磨砂在“减少透明效果”时也改成实色、不模糊。
  • 韩文：“시월 초파일”改“음력 10월 8일”，“29세”改“만 29세”，电脑侧栏改成“클릭: 입력 / Ctrl+Alt+Space”。
  • 补画 8 屏（手机）：AI 处理告知、提示条失败态、断网、其他页面的提醒横幅、整页提醒（待办）、隐私记第一次设密码、空状态、韩文设置页。提醒横幅和整页提醒里的待办，标题前加了可点的完成圆圈。
  • 动效规范（R-93）：见“设计令牌表”后面的“动效规范”。
  • 月历标记（R-100，方案 C）：“N项”去掉，改成色块标签：每件事一个项目色小标签（项目块色底＋左侧 2px 项目深色竖线＋两个字简称），手机每格最多 2 个、电脑最多 4 个，多出来写“+N”，格子加高约 20px；纪念日仍是菱形；图例改写；标签文字对比度加进了对比度表。
  • 节假日三选一（R-97）：设置 › 日历：只显示中国 / 只显示韩国 / 两国都显示，默认跟界面语言。中文月历和中文官网小月历只标中国节假日，韩文设置默认“공휴일: 한국”，韩文官网小月历只标韩国节假日。
  • 周、月翻页（R-99）：画了两种摆法给产品负责人选：A 小箭头贴在标题旁；B 标题可点选年月、“‹ 今天 ›”放在分段控件右侧（推荐）。都支持左右滑动，电脑用 ← →。
  • 纪念日提醒（R-94）：补画“纪念日编辑”一屏：默认提前 7 天和前一天、早上 9:00，每一条可单独改提前天数（可多选）和时间。

动效规范（R-93）

4.0.0 只做基础动效，并给以后的趣味动效留好位置。时长和曲线都用令牌表里的变量（--dur-press、--dur-ui、--dur-sheet、--ease-spring、--ease-standard），组件里不写死数字。

对比度实测

用脚本按 WCAG 2.x 的相对亮度公式算出来，正文要求 ≥ 4.5:1，大字和图标 ≥ 3:1。表里写的是最不利的那一组前景 / 背景色。渐变背景逐个色标测，取最低值；玻璃按最不利的底下内容测：浅色玻璃假设底下正好是墨黑的字或色块，深色玻璃假设底下正好是柠檬黄“＋”、白色或最亮的项目色，先按玻璃透明度混合再算，不把模糊带来的柔化算进去，所以实际只会更好。
