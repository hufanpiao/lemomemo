# 线上存档（自动）

每次用 Artifact 发布稿子（线框、视觉稿、对比页等 html / md），都会自动在这里另存一份副本。

- 起因：产品负责人 2026-10-24 要求“稿子每次出来的时候都自动存一份到本地”。
- 做法：Claude Code 全局设置里的 PostToolUse 钩子（`~/.claude/settings.json`），调用 `~/.claude/hooks/archive_artifact.py`。
- 文件名：`日期_时分秒_原文件名.html`，例如 `2026-10-24_143455_皮肤视觉稿.html`。同一秒重名时加 `_2`、`_3`，已有文件一律不覆盖。
- 本文件夹里的副本不逐个登记，`build/check_registry.py` 会跳过它们，只登记本说明。
- 2026-10-24 之前的线上版原样存档见 `docs/02-设计/线上存档-2026-10-24/`。
