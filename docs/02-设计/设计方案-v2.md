# v2 设计方案（汇总 8 份评审 + 参考视频）

## 参考视频要点（参考文件/术语设计Skill…6种高级dashboard菜单.mp4）
- 便当格（bento）布局：大圆角面板（约 24px），面板之间只用底色区分，不加边框和分隔线。
- 条目做成饱满的马卡龙色块（黄、紫、粉、绿、蓝、珊瑚），色块上用深色字。
- 黑色胶囊分段切换（Week / Day / People），当前项用白底。
- 大数字配小单位（“26 小时 40 分”）。
- 快捷操作用圆形按钮，最常用的那个用主色（参考里是柠檬黄）。
- 当前项展开文字，切换时用弹性动画。

## 没采纳的意见及原因
- UI-1 的“哑光、无圆角”和打孔胶片条：用户给的参考是大圆角加马卡龙色块，以参考为准；只保留播放头这个记忆点。
- UI-2 的左滑删除：和页面滚动、返回手势冲突（UI-4 也反对），改成在编辑面板里删除，删除后可撤销。
- UI-3 的 Fraunces 衬线大日期：和参考的几何无衬线风格不统一。
- PM-1 的子任务、导出 .ics；PM-2 的“帮我排今天”：放到以后的版本。
- PM-4 的 Claude 定时简报：要等用户同意后再设置。

## 数据字段（兼容 v1）
- events：title, date, time, durationMin, project, note, source(page/chat), rawText, createdAt, updatedAt
- todos：title, done, due, important, project, source, rawText, createdAt, doneAt, updatedAt
