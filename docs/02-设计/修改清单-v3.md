# v3 修改清单（第二轮：4 位独立产品经理 + 用户需求）

## 用户新需求
- [x] 深色 / 浅色切换按钮：抬头右上角一个圆形按钮，点一下在“跟随系统 → 浅色 → 深色”之间切换，选择保存在本机。
- [x] 到期提醒和提前提醒：
  - 日程（有时间）：不提醒 / 准时 / 提前 15 分 / 30 分 / 1 小时 / 1 天，默认提前 15 分。
  - 全天日程：不提醒 / 当天 9:00 / 前一天 20:00。
  - 待办（有截止日）：不提醒 / 当天 9:00 / 前一天 9:00；默认当天，标了“重要”的默认前一天。
  - 页面开着时：到点在顶部弹提醒卡片，响提示音，可以选“知道了”或“10 分钟后再提醒”。
  - 页面关着时：网页本身无法推送，也不能下载 .ics（不在允许的格式里）。改由 Claude 定时任务读数据库、推送通知；要不要开、多久查一次，由用户决定。
  - 字段：remindMin / remindDays、remindAt（算好的提醒时间）、notifiedFor（已经提醒过的那个时间，用来去重）、snoozeAt。
  - 一句话识别：“提前半小时提醒”“提前1天提醒”“不用提醒”。
