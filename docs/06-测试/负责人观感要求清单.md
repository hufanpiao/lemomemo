# 负责人观感要求清单

每条都用负责人原话。凡是改到界面的批次，送给负责人之前必须做完下面三步：

1. 每条截一张对应的图，浅色、深色各一张；跟动作有关的，截过渡中间的几帧。
2. 主持人本人逐张看图。
3. 视觉验收员只看图、不看代码，对着原话逐条判“符合”或“不符合”。

有一条不符合就不送。新的要求追加到表末尾，不改旧的。
