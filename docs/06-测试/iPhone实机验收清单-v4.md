## P1　B1 签完后（和倾斜实测同一次，约 20 分钟）

B1 已经用电脑模拟 iPhone 签过；这里是真机再确认一次。发现的问题在 B2 里改，不重开 B1。B2 验收时还会再确认一次（P2-15）。

- [ ] **P1-01**　主屏幕独立启动（①，R-88）
  - 步骤：先在 Safari 里打开预览地址，试着登录；再“添加到主屏幕”，从主屏幕图标打开。
  - 看什么：Safari 里**不给登录**，只显示“添加到主屏幕”的教程；主屏幕图标下的名字是 **Lemo**；从图标打开是全屏、没有 Safari 地址栏，进的是 App（`/app/`）。
- [ ] **P1-02**　验证码和人机验证（②）
  - 步骤：在主屏幕版里用测试邮箱登录。
  - 看什么：邮件里的验证码能在键盘上方自动出现、一点就填入；人机验证（Turnstile）能正常通过，不会一直转圈。
- [ ] **P1-03**　断网启动（⑨，B1 只看“能打开、能看已有内容”）
  - 步骤：登录后先联网打开一次；打开飞行模式；从后台彻底划掉 App 再打开。
  - 看什么：能打开，能看到之前的内容，不白屏。（B3 有了打字入口后再测一次离线记事，P3-04。）
- [ ] **P1-04**　安全区和四种键盘（⑬）
  - 步骤：在有输入框的地方依次用中文拼音、中文手写、韩文、系统听写四种键盘。
  - 看什么：刘海、底部横条不挡内容和按钮；键盘弹起时输入框和按钮不被挡。
- [ ] **P1-05**　**倾斜授权实测**（0.27 第 5 点，R-153）
  - 步骤：
    1. 打开主持人发的“倾斜授权试验页”（装在主屏幕版里）；
    2. 点页面上的按钮，系统弹出“动作与方向”授权时点**允许**；倾斜手机，看高光会不会跟着动；
    3. 从后台**彻底划掉** App，再从主屏幕打开；
    4. 不点任何按钮，直接倾斜手机。
  - **两种结果**（照实勾一个）：
    - ☐ **记得住**：第 4 步不用再授权，高光直接跟着动 → B2 用做法 ①（第 4 次打开 App 时问一次）。
    - ☐ **记不住**：第 4 步高光不动，要重新点按钮、可能再弹授权 → B2 用做法 ②（设置 › 皮肤里放开关，打开时第一次点底栏才问），这个开关提前到 B2 做。
  - 备注：这一项不卡 B2 开工。

## P2　B2 验收（推送要放 3 天，其余约 1.5 小时）

**推送从“推送链路做通、主持人通知你”那天开始测**，不用等到 B2 验收；3 天后再测一次。

### 推送和提醒

- [ ] **P2-01**　App 关着能收到推送（③）
  - 步骤：新建一条 3 分钟后的提醒；从后台彻底划掉 App；等到点。
  - 看什么：到点收到推送，**误差 1 分钟以内**（写下实际收到的时刻）；点开进入整页提醒，按钮在页内。
- [ ] **P2-02**　锁屏和重启后也能收到（③）
  - 步骤：同上，分别在锁屏状态、重启手机后各测一次。
  - 看什么：都能收到，误差 1 分钟以内。
- [ ] **P2-03**　放 3 天再测（④）
  - 步骤：第一次推送测试后 3 天不动这个测试账号，第 4 天再按 P2-01 测一次。
  - 看什么：仍然能收到（订阅还在）。写下第一次和这一次的日期。
- [ ] **P2-17**　退出其他所有设备、锁屏不显示标题（S-P2，15.7 第 18 项；和 P2-01 同一次做，约多 5 分钟）
  - 准备：电脑上（或主持人那边）用同一个测试账号登录着。
  - 步骤：
    1. 在 iPhone 上：设置 › 账号 › “退出其他所有设备”；
    2. 看电脑上那个登录（刷新一下或点任意一项）；回到 iPhone 继续用；
    3. 在 iPhone 上打开设置 › 提醒里“锁屏只显示‘有 1 项日程’”（不显示标题）的选项；建一条 3 分钟后的日程，锁屏等它到点；
    4. 把这个选项关掉，再建一条 3 分钟后的，锁屏等到点。
  - 看什么（判定）：第 2 步电脑上随即退出、要重新登录，iPhone 本机**不受影响**、不用重新登录；第 3 步锁屏推送只写“15:00 有 1 项日程”这类，**看不到标题**；第 4 步锁屏上能看到标题。任何一条不符合就打 ❌ 并写是哪一步。
- [ ] **P2-04**　时区（⑭，R-59）
  - 准备：主持人事先在测试账号里放好一条首尔时间 10:00 的固定日程，和一条提醒时刻是“上海时间几分钟后”的待办（按你开测的时间造，开测前告诉主持人）。
  - 步骤：设置 › 通用 › 日期与时间，关掉“自动设置”，时区选上海；打开 App 看那条日程；等那条待办的提醒。
  - 看什么：日程显示成 09:00（换算后的时刻）；待办按上海时间准时响（不用等到第二天早上 9 点）。测完把时区改回自动。
- [ ] **P2-05**　已送达的通知能不能收回（⑤，R-52）
  - 步骤：让一条提醒推送到 iPhone，**不要点它**；在电脑上把这条提醒处理掉；再打开 iPhone 上的 App。
  - **两种结果**：
    - ☐ 打开 App 后，通知中心里那条通知消失了（`getNotifications()` / `close()` 能用）；
    - ☐ 通知还在（这两个接口在主屏幕版里用不了）→ 照架构的退路：打开 App 时尽量清掉，清不掉就接受，隐私说明里不受影响。
- [ ] **P2-06**　离线新建提醒（⑯）
  - 步骤：
    1. 开飞行模式，新建一条 3 分钟后的提醒；
    2. 看条目和提示条；
    3. 划掉 App，等到点；
    4. 再做一遍，这次到点前回到 App、关掉飞行模式，等它同步完再划掉 App。
  - 看什么：第 2 步显示“未同步，提醒可能不响”；第 3 步**到点不响**（这是预期的）；第 4 步同步后能按时收到推送。
- [ ] **P2-07**　时钟偏差（⑰）
  - 步骤：旁边开着电脑（电脑时间是自动的），或让主持人放一条“10 分钟后开始”的日程；把手机时间手动调快 3 分钟；看今天页的“现在”和那条日程的倒计时。
  - 看什么：今天页的“现在”和电脑上的时间一致、倒计时和调时间前对得上（仍按服务器时间，不跟着快 3 分钟）。测完改回自动。

### 速度、日历、液态玻璃

- [ ] **P2-08**　**冷启动 5 次**（1.3 B2）
  - 步骤：彻底划掉 App，从主屏幕打开，数到今天页内容出来为止；重复 5 次。（最好录屏，QA 按录屏量。）
  - 看什么：写下 5 次的大概秒数；每次 **1.5 秒内**能看到上次的内容、**8 秒内**同步完（架构 14.6 的门槛；QA 按录屏量）；每次都能正常出今天页。
- [ ] **P2-09**　液态玻璃底栏流畅度（R-143、R-153，0.27 性能验收）
  - 步骤：在**今天、日历（含月格左右横滑）、待办**三页分别做：
    1. 快速轻扫列表；
    2. 打开“低电量模式”后再滑；
    3. 让主持人在电脑上连续改几条，**实时同步进来时**滑动；
    4. 按住底栏的选中液滴、在页签之间切换。
  - 看什么：和你之前试过的“真机试验页第 2 版”一样流畅；底栏副本没有明显跟不上、没有露出空白条。
  - **两种结果**：☐ 流畅 → 照现做法；☐ 掉帧 → 先去掉液滴副本（液滴改成纯着色），再不行三页一起改成普通的背后模糊画法。
- [ ] **P2-10**　切页时和自动深浅（0.27 第 5 点）
  - 步骤：在三页之间来回切；把底栏停在深色项目卡片上下慢慢滑过。
  - 看什么：
    - 切页的约 0.4 秒里，底栏玻璃里的内容和背后会**短暂对不上**——这是已知的、可以接受的，请你看一眼是否能接受（☐ 能接受 / ☐ 太明显）；
    - 底栏在深色卡片上会自动变深、离开后变回来，**停在边缘时不会来回闪**。
- [ ] **P2-11**　倾斜高光（按 P1-05 的结果做对应的一种）
  - 做法 ①（记得住）：第 4 次打开 App 时出现提示条“让底栏高光跟着手机倾斜？……允许 / 不用”；点允许后倾斜手机，高光跟着动；划掉再开不再问。
  - 做法 ②（记不住）：设置 › 皮肤里打开“倾斜高光”；每次打开 App 第一次点底栏时才弹授权；开关关着时不弹。
  - 两种都看：点“不用”或拒绝后，高光停在左上方，App 照常能用。
- [ ] **P2-12**　主屏幕版更新流程（8.1）
  - 步骤：先看一眼设置页最下面的版本号；主持人部署一个新版本后通知你，并告诉你新版本号是多少；打开 App。
  - 看什么：出现“有新版本 · 重新打开”，点了以后设置页最下面的版本号变成主持人说的那个。
- [ ] **P2-13**　月历、周视图左右滑动翻页（⑱，R-98、R-99）
  - 步骤：左右滑翻月、翻周；同时试上下滚动、从屏幕左边缘往右滑（系统返回手势）。
  - 看什么：不和上下滚动、边缘返回冲突；滑动跟手、不掉帧；375 宽下项目色块标签看得清。
- [ ] **P2-14**　VoiceOver 抽查（今天、日历、待办三页和底栏）
  - 步骤：设置 › 辅助功能 › 旁白 打开；在三页上左右滑动逐个听；双击底栏页签切页。
  - 看什么：每个按钮都读得出名字（不是“按钮”两个字）；底栏只读一遍（玻璃里的副本不会被读第二遍）；当前页签读出“已选中”；能用双击完成勾选待办。
- [ ] **P2-15**　B1 真机项再确认一次：P1-01～P1-04 在新版本上各看一眼，有变化写备注。
- [ ] **P2-16**　底栏字在三种最难看清的背景上（R-170，架构 0.29 第 30 条）
  - 步骤：主持人在测试账号里放好：一张深色照片（随手记页）、一张整块深色的项目卡片（今天页）、深色主题下的一张白色图片；分别把底栏停在这三种背景上，看底栏的字和图标。
  - 看什么：三种背景上底栏的字都能一眼认出来。
  - **两种结果**：☐ 都清楚 → 玻璃着色保持现在的 34%；☐ 有看不清的（写是哪一种）→ 着色加浓到约 40% 后再看一次。

## P3　B3 验收（约 40 分钟；录音格式实测在 B3 第一天）

- [ ] **P3-01**　长按“＋”（⑥）
  - 步骤：长按右下角黄色“＋”开始说话；在列表文字上长按看看。
  - 看什么：长按“＋”不会触发 iOS 的选字、放大镜；从按下到出现“正在听你说的…”大约多久（写秒数，文档里没有门槛，只记下来）；说完到出结果在 **3 秒内**（线框写的是通常 1～3 秒）。
- [ ] **P3-02**　录音格式和耗时（⑦，B3 第一天先做第 1、2 步）
  - 步骤：
    1. 按住“＋”说一句中文、一句韩文、一句中韩混说；
    2. 录一段约 60 秒的话；
    3. 让主持人临时关掉 Gemini（模拟用不了），再按住说一句；
    4. 划掉 App 再打开，再按住说话。
  - 看什么：第 1、2 步的结果主持人会从日志读出实际格式（AAC / WebM）和能不能直传；**识别准不准（含中韩混说）只凭你的感觉看，写一句“准 / 还行 / 不准”和例子就行，不打分、没有及格线**（R-167）；60 秒那段**20 秒内出结果**；第 3 步走浏览器自带识别（Web Speech）也能记下，或提示你改用键盘听写；第 4 步麦克风权限是否每次冷启动都要重新问（☐ 要 / ☐ 不要）。
- [ ] **P3-03**　录音中收到新版本（0.27 第 1 点）
  - 步骤：开始一段较长的录音时，请主持人部署新版本。
  - 看什么：录音不被打断、内容不丢；“有新版本 · 重新打开”的横幅**等录音结束后才出**；录完自动重新载入后，刚才那句已经记下。
- [ ] **P3-04**　离线打字记事（⑨，B3 有了打字入口再测）
  - 步骤：飞行模式下点“＋”打字记两条；关掉飞行模式。
  - 看什么：离线时能记、马上出现在列表；联网后自动同步到电脑。

## P5　B5 验收（约 55 分钟，含 B4 并进来的 10～15 分钟）

- [ ] **P5-01**　**第一件事**：放了 7 天以上，本机内容还在不在（⑪、⑮）
  - 步骤：先**开飞行模式**再打开 App（这样看到的是本机存的，不是刚从网上拉的）；然后关飞行模式。
  - 看什么：断网时之前的内容都在；写下放了几天 ______；联网后正常同步。主持人会另看日志里持久存储（`storage_persist`）的结果。
- [ ] **P5-02**　随手记插图和随手记页的液态玻璃（⑩，B4 并进来，R-108）
  - 步骤：从相册插一张 HEIC 照片（最好是开了定位拍的）；上传后在电脑上下载这张图（QA 会读里面的信息）；在随手记页（两列瀑布流、有图片）快速上下滑，把底栏停在深色图片和浅色图片上。
  - 看什么：照片能正常显示；QA 读下载的文件**查不到定位和拍摄信息**；滑动流畅；底栏在深色图片上自动变深、浅色上变浅，不来回闪。
- [ ] **P5-03**　Face ID（⑧）
  - 步骤：设置隐私记数字密码；绑定 Face ID；上锁后用 Face ID 解锁；遮住脸让它失败，改输密码。
  - 看什么：失败后能用密码；离开 App 超过 1 分钟回来是锁着的（R-86）；改过数字密码后要重新绑定 Face ID（旧的绑定失效）。
  - **两种结果**（需求澄清 2.9 要实测）：☐ 主屏幕版里 Face ID 能用 → 照原设计；☐ 不能用 → 解锁界面只有“输入密码”、没有 Face ID 入口，写下来交架构（测试用例 TC-B5-18）。
- [ ] **P5-04**　隐私记页面的底栏
  - 步骤：进隐私记页面（含解锁界面），上下滑。
  - 看什么：底栏和“＋”是**实色**的、没有玻璃效果（里面不会映出隐私内容）；上锁时直接遮住、不做淡出动画。
- [ ] **P5-05**　纪念日单条单独改提醒时间（R-94）
  - 步骤：一条生日用默认提醒；另一条改成“提前 3 天、20:30”；把第二条的提醒时间设成几分钟后（主持人会帮你造一条测试用的）。
