### 2.1 其他观察（不算缺陷，建议顺手看一下）
- 断网时勾选一件待办，回滚是对的，但会同时弹出“完成了，今天第 N 件”和“没保存上”两条，前一条有误导。断网时删除也是这样，会同时出现“已删除 1 项”和失败提示。
- 本机存储多了 `pv-purged`（每日清理记录）和 `pv-device`（运行日志的设备号），都不含条目内容。TC-SEC-08 和数据字典的“本机存储”一节需要补上这两个键。
- “已完成 N 件”折叠按钮没有 `aria-expanded`。
- 输入法组字：页面没有监听 `compositionend`，靠 input 事件更新。Chrome 里没问题，iPhone Safari 的事件顺序不同，实机验收时请看一下。
- 测试用例文件还没写进需求澄清 #28–#38。按这几条，TC-REM-27、TC-REM-30、TC-VOICE-01、TC-SCHED-09、TC-TODAY-04 现在的实现都符合；建议主持人同步更新用例文件。
