# 预览导出实测：负责人本机跑法（TC-B1-142）

> 用途：TC-B1-73 的“预览校准一档”。主持人 10-31 定跑法 b：由负责人在自己电脑上跑一条命令，不做 CI 工作流。
> 依据：架构 0.47 第 16 条（安全审查 M4）、0.47 续 ⑤ b、④ 第 5 点；R-220（密钥不另存）；TC-B1-141（护栏）。
> 脚本：`tools/e2e/export-load-preview.mjs`（护栏在 `export-load-preview-guards.mjs`，单测在 `tests/build/export-load-preview.test.ts`、`export-load-preview-run.test.ts`）。
> 写：后端，10-31。

## 这条命令会做什么

1. 先读预览库的大小。超过 250 MB 就停下，什么都不建。
2. 在**预览项目**里临时建一个测试账号，邮箱形如 `e2e-export-<13 位数字>@lemomemo.test`。
3. 给这个账号造合成数据：9 张同步表各 5,000 行，日志 45,000 行，原文约 49 MB。不传任何图片或文件。
4. 用这个账号按正式的分片方式导出一次，核对片数、计数、日志和每张表的行数。
5. 跑完（中途出错也一样）先逐条核对“这是本次建的测试账号”，再删掉账号、数据和计数，并核对删干净了。
6. 不发信（`.test` 邮箱，函数里直接跳过），不在电脑上留下任何文件。

脚本只认预览项目，不会连正式项目。

## 跑之前

- 安全审查员已审过脚本（10-31：D1、D2、E4 通过），主持人通知可以跑了。
- 仓库是最新的 main；本机有 Node 24（`node -v` 显示 `v24.…`）。
- 需要预览项目的 service key（Supabase 后台 → 预览项目 → Project Settings → API Keys 里的 service_role / secret）。
  **这把钥匙只在下面第 2 步粘进这个窗口，不要存到文件、记事本、聊天里，也不要贴给任何人（包括主持人和 Claude）。**
- 同一时间只跑一个，不要开两个窗口同时跑。

## 步骤（PowerShell）

**第 1 步**：开一个**新的** PowerShell 窗口，进仓库目录：

```powershell
cd "D:\claude code\柠檬记APP"
```

**第 2 步**：把 service key 只设在这个窗口里。下面这行会提示你粘贴，输入时不显示，钥匙也不会进命令历史：

```powershell
$env:E2E_PREVIEW_SERVICE_KEY = [System.Net.NetworkCredential]::new('', (Read-Host '粘贴预览 service key（不显示）' -AsSecureString)).Password
```

从 Supabase 后台复制后**直接粘进这个提示里**，不要先粘到记事本或聊天框中转。

粘贴完，随便复制一段别的文字，把剪贴板里的钥匙覆盖掉；再按 **Win+V**，点“全部清除”（开了剪贴板历史时，覆盖后钥匙仍留在历史列表里，开了跨设备同步还会上传）。按 Win+V 弹出的是“开启剪贴板历史”的提示，说明没开，直接关掉提示，不用开。

**第 3 步（可选，推荐）**：填你自己常用的邮箱。脚本删号前会核对“不是负责人的账号”。不填也能跑，输出里会记一条“跳过”：

```powershell
$env:PREVIEW_OWNER_EMAILS = Read-Host '你的邮箱（多个用逗号隔开，可留空）'
```

**第 4 步**：跑这一条命令：

```powershell
node tools/e2e/export-load-preview.mjs --sync-rows 5000 --log-rows 45000
```

- 第一行会打印 `{"created": "<一串 id>"}`，这是本次建的测试账号。**请记下这一行**，中途出事时要用它补删。
- 之后等它自己跑完，最后打印一段报告。本机演练用时见文末，预览上网络慢一些，多等一会儿正常。
- **不要直接关窗口。** 想中途停下就按 **Ctrl+C**，等它把清理做完、打印出报告再关。

**第 5 步**：看结果，再把报告贴回给主持人：

```powershell
$LASTEXITCODE
```

- 显示 `0` 就是通过。
- 把窗口里**脚本打印的全部内容**（第一行的 created 加最后的报告）复制贴给主持人。报告里只有条数、字节数、毫秒数、错误码和这个测试账号的 id，**没有钥匙**。
- 贴之前看一眼：不要把第 2 步的钥匙一起贴出去。

**第 6 步**：关窗口前再按一次 **Win+V**，确认历史里没有钥匙（有就点“全部清除”）。然后关掉这个 PowerShell 窗口，钥匙随窗口一起消失，不留在电脑上。

## 出了问题怎么办

| 最后的退出码（`$LASTEXITCODE`） | 意思 | 怎么办 |
|---|---|---|
| 0 | 通过，已经删干净 | 把输出贴给主持人 |
| 1 | 导出核对没过，或删除前的核对没过、删不干净 | 把输出贴给主持人。报告的 `cleanup` 里有 `id` 和“交主持人”的提示，**不要自己去后台删** |
| 2 | 参数不对、没设钥匙，或地址不是预览项目 | 检查第 2 步、第 4 步是否原样输入 |
| 3 | 预览库超过 250 MB，或读不到库的大小 | 什么都没建。把输出贴给主持人 |
| 4 | 建测试账号失败（比如邮箱已存在） | 什么都没删。把输出贴给主持人 |
| 130 | 按了 Ctrl+C，已经走完清理 | 看报告里的 `cleanup`：`userGone: true` 就是删干净了；不是的话把输出贴给主持人 |
| 130（没有报告） | 清理途中又按了一次 Ctrl+C，直接退出了，可能没删干净 | 输出最后一行是 `interrupted_twice` 加 id。照下面“不小心关了窗口”的办法，用第一行 created 后面的 id 跑 `--cleanup` 补删 |

### 不小心关了窗口、按了两次 Ctrl+C，或电脑断电

脚本没来得及清理，预览里可能留下这个测试账号。用第 4 步记下的 id 补删：

1. 重新开 PowerShell 窗口，照第 1～3 步设好（钥匙同样只设在这个窗口）。
2. 跑（把 `<id>` 换成第一行 created 后面那串）：

```powershell
node tools/e2e/export-load-preview.mjs --cleanup <id>
```

3. 补删同样会先核对：是 `@lemomemo.test` 测试邮箱、不是管理员、不是你的邮箱，建号时间在最近 24 小时以内。核对全过才删，删完再核对干净。退出码 0 就是删好了，把输出贴给主持人。

**超过 24 小时的残留**，`--cleanup` 会拒绝，交主持人手工处理。手工处理也走同样的核对（同一组条件），不按邮箱模式批量删。

如果连 id 都没记下：把情况告诉主持人。主持人按 `e2e-export-` 开头、`@lemomemo.test` 结尾、建号时间在你跑的那段时间里找出 id，再用 `--cleanup` 删。
