# iPhone 实机验收清单

由产品负责人（用户本人）在 iPhone 上逐项操作。每项打 ✅（正常）、❌（有问题），或写一句备注，然后把结果发给主持人（截图最好）。
AI 测试只能模拟手机尺寸，真实的 Safari、触摸手感、键盘弹出、主屏幕图标这些，只有实机能验证。

**测试环境**：iPhone 型号 ______　iOS 版本 ______　打开方式：Safari / Claude App / 主屏幕图标

## 1. 打开与外观
- [ ] 登录 claude.ai 后打开链接，3 秒内能看到内容
- [ ] 文字不会太小，不用放大就能看清
- [ ] 页面不能左右滑动（没有横向滚动）
- [ ] 刘海、底部横条没有挡住内容或按钮
- [ ] 右上角的主题按钮能在“跟随系统 / 浅色 / 深色”之间切换，关掉再打开后保持上次的选择（v3）
- [ ] 手机切换深色模式后，“跟随系统”状态下页面也跟着变

## 2. 记事
- [ ] 右下角黄色“＋”单手拇指能点到
- [ ] 弹出键盘后，输入框和“加入”按钮没有被键盘挡住
- [ ] 输入“明天下午3点和 NEOX 对片”，识别成日程，时间是 15:00
- [ ] 输入“周五前交 SignPlex 韩文版”，识别成待办，截止日期是周五
- [ ] 加完后能马上在列表里看到

## 3. 日常操作
- [ ] 勾选待办，有划线动画，提示“今天第 N 件”
- [ ] 点开一条，可以修改并保存
- [ ] 删除后点“撤销”，能恢复
- [ ] 删除后去“最近删除”里也能恢复（v3）
- [ ] 底部导航“今天 / 日程 / 待办”切换顺畅，没有卡顿
- [ ] 日程页左右翻周，“回到今天”能回来（v3）

## 4. 提醒（v3）
- [ ] 给一个 5 分钟后的日程设“准时提醒”，页面开着时到点弹出提醒卡片并响提示音
- [ ] 点“10 分钟后”，10 分钟后再次提醒
- [ ] 点“知道了”，不再重复提醒
- [ ] （如果开启了 Claude 定时推送）页面关着时，手机能收到推送

## 5. 多设备
- [ ] 在电脑上加一条，手机上不刷新也能自动出现，并短暂高亮
- [ ] 手机上勾选完成，电脑上同步变化

## 6. 主屏幕
- [ ] Safari 分享按钮里点“添加到主屏幕”，桌面出现图标，点开能正常使用
