# 数据字典

数据存在 claude.ai 云端数据库（[ADR-002](../04-决策/ADR-002-用云端数据库保存数据.md)），两个集合：`events`（日程）、`todos`（待办）。文档 id 由数据库生成（页面里是 `doc().id`），不在字段里。

- 依据：v1/v2 源码的写入代码（v1 `add()`，v2 弹出层 `submit`、勾选、改期），[设计方案-v2](../02-设计/设计方案-v2.md) 的“数据字段”，[修改清单-v3](../02-设计/修改清单-v3.md) 和 [PM-B](../03-评审/第二轮/第二轮_PM-B_提醒功能.md)。
- “谁会写”：**页面**＝planner 页面；**Claude**＝在聊天里代记或定时任务。Claude 写入的数据可能缺字段或类型不对，页面读入时按默认值整理（v3 normalize）。
- 时间戳一律是毫秒数（`Date.now()`）；日期 `YYYY-MM-DD`，时间 `HH:MM`（24 小时制，补零）。

## events（日程）

| 字段 | 类型 | 必填 | 默认值 | 含义 | 起始版本 | 谁会写 |
|---|---|---|---|---|---|---|
| title | string | 是 | — | 标题 | v1 | 页面、Claude |
| date | string `YYYY-MM-DD` | 是 | 弹出层默认取当前选中的那天 | 日期 | v1 | 页面、Claude |
| time | string `HH:MM` | 否 | `""`（全天） | 开始时间，空表示全天日程 | v1 | 页面、Claude |
| durationMin | number（分钟） | 否 | 60 | 时长，用于时间轴和“下一件事”的结束时间 | v2 | 页面、Claude |
| project | string | 否 | `""` | 项目名，决定颜色和筛选 | v2 | 页面、Claude |
| note | string | 否 | `""` | 备注 | v1 | 页面、Claude |
| source | string：`page` / `chat` | 否 | 页面写入为 `page`；缺省视为页面 | 来源；`chat` 显示“Claude 代记” | v2 | 页面、Claude |
| rawText | string | 否 | `""` | 用户在一句话框或聊天里的原话 | v2 | 页面、Claude |
| createdAt | number（毫秒） | 是 | 创建时 `Date.now()` | 创建时间 | v1 | 页面、Claude |
| updatedAt | number（毫秒） | 否 | 每次保存时 `Date.now()` | 最后修改时间 | v2 | 页面、Claude |
| remindMin | number（分钟）/ null | 否 | 15（有时间的日程） | 提前多少分钟提醒：0 准时、15、30、60、1440；null 不提醒 | **v3 计划** | 页面、Claude |
| remindDays | number / null | 否 | 全天日程见右 | 全天日程：0＝当天 9:00，1＝前一天 20:00，null 不提醒（与待办共用此字段名，含义按集合区分，以实现为准） | **v3 计划** | 页面、Claude |
| remindAt | number（毫秒）/ null | 否 | 保存时按 date、time、remindMin 算出 | 算好的提醒时刻 | **v3 计划** | 页面（Claude 写入时也应计算） |
| notifiedFor | number（毫秒）/ null | 否 | null | 已经提醒过的那个 remindAt 值，用于页面和推送去重 | **v3 计划** | 页面、Claude 定时任务 |
| snoozeAt | number（毫秒）/ null | 否 | null | “10 分钟后再提醒”的时刻 | **v3 计划** | 页面 |
| deletedAt | number（毫秒）/ null | 否 | null | 软删除时间；有值表示在“最近删除”里，30 天后清理（[ADR-006](../04-决策/ADR-006-软删除和最近删除.md)） | **v3 计划** | 页面（Claude 删除也应写它） |

## todos（待办）

| 字段 | 类型 | 必填 | 默认值 | 含义 | 起始版本 | 谁会写 |
|---|---|---|---|---|---|---|
| title | string | 是 | — | 标题 | v1 | 页面、Claude |
| done | boolean | 是 | false | 是否完成（不能写成字符串 "false"） | v1 | 页面、Claude |
| due | string `YYYY-MM-DD` | 否 | `""`（无截止日） | 截止日期 | v1 | 页面、Claude |
| important | boolean | 否 | false | 是否重要，只影响排序和标记 | v1 | 页面、Claude |
| project | string | 否 | `""` | 项目名 | v2 | 页面、Claude |
| note | string | 否 | `""` | 备注。v1/v2 待办没有此字段；v3 搜索要求“标题、备注、原话都能搜”，若给待办加备注以实现为准 | **v3 计划（待定）** | Claude |
| source | string：`page` / `chat` | 否 | 页面写入为 `page` | 来源 | v2 | 页面、Claude |
| rawText | string | 否 | `""` | 原话 | v2 | 页面、Claude |
| createdAt | number（毫秒） | 是 | 创建时 `Date.now()` | 创建时间 | v1 | 页面、Claude |
| doneAt | number（毫秒） | 否 | 0 | 完成时间，未完成为 0；用于“今天完成 N 件” | v1 | 页面、Claude |
| updatedAt | number（毫秒） | 否 | 每次保存、勾选、改期时 `Date.now()` | 最后修改时间 | v2 | 页面、Claude |
| remindDays | number / null | 否 | 有截止日时 0；标了“重要”时 1；无截止日不提醒 | 0＝当天 9:00，1＝前一天 9:00，null 不提醒 | **v3 计划** | 页面、Claude |
| remindAt | number（毫秒）/ null | 否 | 保存时按 due 和 remindDays 算出；完成或删除时清空 | 算好的提醒时刻 | **v3 计划** | 页面 |
| notifiedFor | number（毫秒）/ null | 否 | null | 已提醒过的 remindAt，用于去重 | **v3 计划** | 页面、Claude 定时任务 |
| snoozeAt | number（毫秒）/ null | 否 | null | 稍后再提醒的时刻 | **v3 计划** | 页面 |
| deletedAt | number（毫秒）/ null | 否 | null | 软删除时间 | **v3 计划** | 页面 |

## 不做的字段
- `kind`（对片/交付/会议，PM-2 建议）：v2 未采纳。
- `icsFor`（PM-B 建议）：.ics 做不了，不加（[ADR-004](../04-决策/ADR-004-不用ics.md)）。
- `repeat`（PM-D⑤ 重复事项）：v3 暂不做。
