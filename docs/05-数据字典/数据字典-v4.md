## 3. 公共约定

### 3.1 类型和命名（3.1）

| 项 | 规则 |
|---|---|
| 命名 | 业务字段沿用 v3 数据字典，驼峰改下划线（`durationMin` → `duration_min`），适配器自动互转 |
| 业务时间 | `bigint` 毫秒（`created_at`、`updated_at`、`deleted_at`、`remind_at`、`done_at` 等） |
| 服务器时间 | `timestamptz`（`synced_at`、`consent_ai_at`、private 表的时间等） |
| 日期 | `date`（`events.date`、`todos.due`、`next_date`） |
| 时刻 | `text`，`HH:MM`（24 小时制，补零），check `^([01]\d|2[0-3]):[0-5]\d$` |
| 主键 | 用户表的 `id uuid` 由**客户端生成** |

### 3.2 公共列（每张用户表都有；附A 开头、3.1）

适用：settings、devices、events、todos、categories、notes、note_images、note_files、anniversaries。（profiles、api_tokens、applied_ops、logs、app_config 和 private 表**没有**公共列。）

| 列 | 类型 | 空 | 默认 | 含义 | 谁写 |
|---|---|---|---|---|---|
| id | uuid | 否（主键） | — | 客户端生成 | 客户端 insert；`touch()` 不准改 |
| user_id | uuid | 否 | `auth.uid()` | 属于谁；references auth.users on delete cascade | 默认值；`touch()` 不准改 |
| rev | int | 否 | 1 | 行版本；有用户字段变了才 +1 | 只由 `touch()` 写 |
| fv | jsonb | 否 | `'{}'` | 每个字段最后一次被修改时的 rev（H9） | 只由 `touch()` 写 |
| deleted_at | bigint | 是 | — | 软删除时刻（毫秒）；有值 = 在“最近删除”里，30 天后清理 | 客户端（patch） |

| ~~legacy_id~~ | text | 是 | — | **不建**（R-208 不搬家，架构 0.30）；原为“从 v3 搬来时的旧文档 id（5.8）” | — |

- 没有硬删除：删除和撤销都是 patch（写 `deleted_at`、`undone`，4.2）。devices 例外，见 P-21。

### 3.3 本文件“谁写”一栏的记号

| 记号 | 含义 |
|---|---|
| **C** | 客户端可写（insert 和 update 都授权；最终以清单 `clientWritable` 为准） |
| **C-i** | 客户端只能 insert，之后不能改 |
| **D** | 派生列：客户端或服务器按规则算出，改了**不加 rev**（登记进 `table_meta.system_cols`） |
| **S** | 系统列：只有服务器函数写，改了不加 rev，客户端无授权 |
| **V** | 只经 vault / vault-file 函数（`fn_vault`）写，客户端无授权 |
| **T** | 只由触发器写 |
| **NC** | 不报冲突的列（`table_meta.no_conflict`）：两台设备同时改，后写的胜出、不提示 |

> 3.3 的列级授权只写了“`grant insert (id, title, date, time, tz, …客户端可写列) on events`”，没有逐表列全。本文件的 C / D / S 是按 3.1（系统列、派生列）、3.2（谁能写）、4.5（客户端算 remind_at）反推的，见 P-09。

### 3.4 RLS 通用规则（3.3 A）

普通用户表（events、todos、anniversaries、categories、settings、devices、note_images、note_files、logs、applied_ops）四条策略：

| 策略 | 条件 |
|---|---|
| sel（select） | `user_id = (select auth.uid()) and private.is_active()` |
| ins（insert） | with check 同上 |
| upd（update） | using 同上；with check `user_id = (select auth.uid())` |
| del（delete） | using 同上 |

- logs、applied_ops 没有 upd、del。
- note_images 的 ins 另加 `bucket = 'images'`。
- note_files 的 ins、upd 另加 `is_vault = false`，并由 `private.guard_note_file()` 查挂的随手记 `is_private = false`。
- notes 见 4.11（3.3 B）；profiles、api_tokens、app_config 见各表（3.3 B2）。
- 表级 `revoke insert, update on all tables in schema public from anon, authenticated`，再按列 grant；`alter default privileges` 让以后的新表也不自动给写权限（3.3）。
- `body_enc`、`token_hash` **不收回读权限**（3.3）。
