## 阶段 1：claude.ai 版 v3（已发布，2026-10-24）
- **目标**：在 claude.ai 上完成主题切换、到期/提前提醒、第二轮评审的问题修复；同时把源码拆成模块，数据层改成适配器。
- **交付**：`src/` 模块化源码；`src/scripts/data/` 数据适配器、`src/scripts/platform/` claude.ai 运行环境；`build/build.py --target claude`；`dist/planner.html`；`tests/unit/parse-quick.test.mjs`；线上 Version 3；`archive/releases/v3/planner.html`。内容清单见 [修改清单-v3](../02-设计/修改清单-v3.md)。
- **依赖**：用户确认页面关着时是否开 Claude 定时推送（[ADR-005](../04-决策/ADR-005-页面关闭时的提醒靠Claude定时推送.md)）。
- **工作量**：约 3–5 天（修复项多，提醒和软删除涉及字段变更）。
- **完成标准**：修改清单全部勾完；单元测试通过；发布后在 claude.ai 上实测云端读写和页面内提醒；UI 层不直接调用 `window.claude`，只经适配器。

## 阶段 2：PWA 外壳
- **目标**：页面可安装到电脑桌面和手机主屏幕，断网时能打开并查看已有数据。
- **交付**：`manifest.webmanifest`（名称、主题色、启动方式）；Service Worker（静态资源缓存、离线兜底页）；离线缓存策略与离线写入队列；各尺寸图标（含可遮罩图标）；`build/build.py --target web` 输出多文件版本。
- **依赖**：阶段 1 的适配器结构；一个 HTTPS 的测试域名（Service Worker 需要 HTTPS 或 localhost）。
- **工作量**：约 2–3 天。
- **完成标准**：Chrome/Edge 桌面和 Android 能“安装”；iOS Safari 能加到主屏幕；断网后重开能看到最近数据；Lighthouse 的 PWA 检查无阻断项。

## 阶段 3：独立后端
- **目标**：数据从 claude.ai 云端数据库搬到自己的服务器，多设备登录同一账号。
- **交付**：后端接口（events、todos 的增删改查与实时/轮询同步）；数据库表结构（按 [数据字典](../05-数据字典/数据字典.md)）；登录；`src/scripts/data/` 新增 web 适配器、`src/scripts/platform/` 新增 web 运行环境；数据迁移工具（读 v3 导出的 JSON 备份写入新库）；部署说明（域名、HTTPS、备份）。
- **依赖**：用户决定后端技术（例如 Node + SQLite 或 Supabase）、登录方式、域名和 HTTPS、迁移方式（见 ADR-007 待决定问题）。
- **工作量**：约 4–8 天（托管服务偏少，自建偏多）。
- **完成标准**：电脑和手机登录后看到同一份数据；迁移后条目数、字段与 claude.ai 一致；UI 代码不改动只换适配器；有每日数据备份。

## 阶段 4：Web Push 推送提醒
- **目标**：页面关着时也能准时提醒，取代 Claude 定时推送。
- **交付**：VAPID 密钥与订阅管理；服务端定时扫描 `remindAt` 并发送推送，沿用 `notifiedFor` 去重；Service Worker 处理推送与点击（打开对应条目、“稍后 10 分钟”）；页面里的订阅开关。
- **依赖**：阶段 2（Service Worker）、阶段 3（服务端和登录）；iOS 需 16.4 以上且已加到主屏幕。
- **工作量**：约 2–3 天。
- **完成标准**：电脑和手机在页面关闭时按设定时间收到通知（误差 1 分钟内）；同一提醒不重复；可以在页面里关掉推送。


## 补充（2026-10-23）
- 页面内语音输入按钮：claude.ai 页面不能用麦克风，放到阶段 2（PWA 外壳）或阶段 3 实现，用 Web Speech API，iOS Safari 14.5 以上支持。在这之前用 iPhone 键盘听写代替。
- 重复事项：排到 v4。

## 风险清单
| 风险 | 影响 | 应对 |
|---|---|---|
| 页面关着时的提醒依赖电脑上的 Claude App 开着，并连接 Remote Control | 电脑关机或断网时收不到提醒 | 页面开着时自己提醒；上了独立服务器后改用 Web Push |
| iPhone 网页推送的限制（要添加到主屏幕、iOS 16.4 以上） | 阶段 4 的推送不一定准点 | 实机验收时专门测 |
| 开发主要靠主持人一个人 | 缺少开发者之间互相检查 | 每个版本都做代码审查和 QA；构建时自动检查架构 |
| claude.ai 平台的能力或接口变化 | 页面功能可能失效 | 平台相关代码只放在 src/scripts/platform/，改一处即可 |
| 一句话识别出错，记错时间 | 误事 | 识别结果先给用户确认才保存；单元测试覆盖常见说法 |
