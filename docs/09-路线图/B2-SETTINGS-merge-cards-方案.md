## 1. 线框和现状差在哪里

**线框的设置首页**：标题“‹ 今天　设置”，下面是三张卡，再加一个单独的“退出登录”。
- 卡 1 账号：头像、邮箱、“2 台设备：iPhone、Windows ›”，整张卡是一个入口。
- 卡 2：界面语言、皮肤（下面缩进两行开关：减少透明效果、减少动态效果）、字体、随手记显示方式、日历、提醒与通知、语音与 AI、隐私记、时区。
- 卡 3：数据、在 Claude 聊天里记事、邀请朋友（只有管理员看得到）、符号说明、关于。
- 每一行都是“名字 + 右边的当前值 + ›”。卡片上面没有组标题，卡片下面也没有灰字说明。

**现在**：每组一张卡（`.grp`），卡上面有组标题（`.gt`），卡下面挂灰字说明（`.sn`）。
- 界面语言：卡里是分段按钮（中文 / 한국어），下面有说明。
- 皮肤：倾斜高光开关，下面有说明，被拒绝时还有一行报错。
- 日历、提醒：已经是“一行摘要 + 二级页”（前端 A 的 R-320 和 REMIND-wiring）。这两行由 calendar、reminders 功能懒加载提供，各自渲染整个 `<section><ul class=grp>`。
- 数据：卡里直接是“导出全部”按钮，带进度和最近的导出。
- 账号：已登录设备列表、退出其他设备、注销入口，都直接摊在首页。
- 电脑（只有 exe 有）：快捷键一行。
- 关于：只有说明文字，没有行。
- 线框里的字体、随手记显示方式、语音与 AI、隐私记、时区、Claude、邀请、符号说明，这些分组现在都还没做。

现在每组下面的灰字说明（语言说明、倾斜高光说明、数据说明、电脑说明、农历致谢）在合卡以后不能再挂在“组下面”。建议：

- **倾斜高光的说明和拒绝报错**：放进开关那一行，做成两行的开关行，不挂在卡底下把卡劈开（M2）。

## 4. 抽进 kit 的组件（FA-3 设计审查第 5 条）

放在 `src/kit/components/Settings/`，样式从 `SettingsPage.module.css` 搬过去，不改数值：
- `SettingsCard`：`<section>` 包一个看不见的 `<h2>`（卡名，必填），再放 `<ul class=grp>`（M3）。
- `SettingsRow`：`<li>`，即现在的 `.row`。有三种写法：
  - 入口行：`Pressable` 撑满 44px，名字 + 值 + ›，即现在的 `.rowBtn`、`.tx`、`.v`、`.chev`；
  - 开关行：`label` 包住 `role="switch"`，即现在的 `.switchRow`、`.toggle`；
  - 自定义内容。
  - `indent` 属性给“皮肤”下面的子开关用。
- `Segmented`：两段或多段的分段按钮，即现在的 `.seg`、`.segBtn`，保留 R-282 的 38/32 尺寸和扩到 44 的点击区。

各分组组件（LanguageSection 等）不再自己渲染 `<section>`、`<ul>`，只返回一行或几行 `SettingsRow`，由 SettingsPage 按表装进卡里。

**跨功能的两行**：日历、提醒的入口行在 calendar、reminders 功能里。它们要改成只返回 `SettingsRow`，这两个文件是前端 A 的，要改得先说一声。

**懒加载的空位（M4）**：入口行由 settings 自己渲染，行名也由 settings 自己管，不从功能里复制一份。这一行一开始就能点，只有右边的“值”由功能懒加载填进来，加载前先空着。值单行省略，保证行高 44。二级页的分包下载失败时，二级页里显示兜底提示（重试或返回），不能是白页。这样 calendar、reminders 提供的是“值”组件和二级页，不再提供整行。
