## 一、底栏玻璃

- 两个根因都查得对。第二个根因（`.bar` 带 view-transition-name，成了里面元素的背景根）有去掉名字的对照图（根因2-有无切页名字对比），证据充分。把模糊挪到 `.bar`、`.fab` 自己身上是对的做法。
- **模糊深浅：选 3px。** 和视觉稿第 7 屏、第 1 屏对照：背后的字糊成一团读不出来，只透出颜色和形状（月历图例的蓝色标签、待办的圆圈）。6px 只剩一片白，看不出底栏后面有东西，玻璃感就没了。
- **页签字可读性：好。** 页签字和图标都清楚，背后的内容不会和页签抢。对比度最低 6.2:1，够了。
- 和稿子比，还差一点：稿子里背后的颜色更饱满（第 7 屏的红色圆圈很鲜明），修后的 3px 整体偏白一点。建议 G-1：真机看过以后，如果还觉得“白”，把副本档的着色 `--g-tint` 降一档（比如 0.34 → 0.28），**不要再加模糊**。这一条要负责人真机拍板，不挡。
- 外框去掉、内侧柔光、沿边亮光、两层阴影：特写里看，胶囊的轮廓靠阴影和亮光撑住，在灰底上没有糊成一片，可以。
- 遗留：副本引擎还在白建看不见的副本（GLASS-copy-unused），已经记进接手清单，同意等以后改 motion 时去掉。

## 二、顶部渐变模糊带

量出来的：静止时带子下沿那条线的色差只有 1 级（233 和 232），看不出来，不是问题。

**必改 T-1：静止时页头不能压在带子里。** 待办页“滚动前”那张，大标题“待办”字的上沿已经发虚、带灰影（放大看很明显）。原因是页面顶部的留白正好等于安全区，带子却是安全区 + 12px，大标题最上面那几像素就落在了模糊里。还没滚动标题就是虚的，看着像渲染出错。
- 改法：带子高度保持 A（安全区 + 12px），**页面顶部同样多留 12px**，让静止时带子里什么都没有。这一条不在第 0 节的三个选项里：C 是带子 +24、页面 +12，静止时还是有 12px 压在带子里，也不行。
- 月历页的年月按钮没压到（它本来就在更下面），但同一条规则全站都要满足：每个有底栏的页面，静止时第一行内容的上沿都要在带子下面。建议加一条 e2e：比较带子底边和第一个可见元素的 top。

**模糊多深：选 C（4px + 1px）。** 现在 8px 的问题是：深色的东西（月历的“月”黑色分段、待办的“全部”黑色胶囊）滚进带子以后，会变成一团上下发虚的黑影，像屏幕上的污渍；浅色的字倒是糊得很好看。4px 时深色块还能看出形状，淡出就自然了。状态栏那一段本来就靠实色盖住，用不着 8px。

**实色占多少：选 A（安全区上半段实色，现在的做法）。** 时间和信号下面一定要干净。选 B 的话，滚过去的黑色胶囊会在时间底下透出颜色，正好撞上上面说的污渍问题。

**带子高度：选 A（安全区 + 12px），同时照 T-1 页面顶部多留 12px。** 不选 B、C：24px 的淡出段在 375 宽的手机上太占地方，而且静止时页头压得更多。

其他：
- 两层 backdrop-filter、挂在 html、body 的伪元素上，没有重踩底栏根因 2 的坑。不挡点按，减少透明效果时只留实色渐变，≥900px 不加：都同意。
- 真机为什么原来那条实色底条没盖住状态栏，还没查清，建议在预览版上和这次一起看。

## 三、L-6 按钮字体

- `button { font: inherit }` 放在 base.css 里，全站的宋体都没了：韩文待办的“NEOX 2”“旅行 1”、各行的 ×、“退出登录”都换成了页面字体，好。
- 待办行带项目名的那几行从 44px 高到 47～49px：可以接受，触控区更大了。
- **L6-a 要确认：“退出登录”和“中文”分段按钮变粗了。** “退出登录”原来是细的灰字，现在是粗黑字。应该是组件本来就写了 font-weight，宋体没有粗体所以以前看不出来。“退出登录”变成全页最粗、最显眼的一行，比各个设置项还重，层级不对。请确认这个粗细是不是本来想要的；如果不是，把“退出登录”改回常规粗细。分段按钮选中项变粗可以接受。
