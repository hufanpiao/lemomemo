## 逐项核对

### 1. 选择器是否覆盖所有退场层
- RemindHost 里一共三处 `Appear`（`RemindHost.tsx` 第 139～155 行）：
  - 横幅、按钮条用 `styles.layer`；
  - “15:25 再提醒你”提示用 `styles.layerNote`。
  - 新规则 `.layer[data-state="leaving"] > *, .layerNote[data-state="leaving"] > *` 三处都盖住了。
- `data-state="leaving"` 打在哪：`motion/Appear.tsx` 第 65 行，打在 `AppearBody` 的 `m.div` 上，也就是带 `className` 的那一层，和选择器对得上。
  - 横幅根元素、按钮条（`.bar`）里的 Pressable 自己也会写 `data-state="pressed|idle"`（`motion/Pressable.tsx` 第 27 行），但选择器看的是外层 `.layer` 上的 `data-state`，不会互相干扰。
- 优先级：
  - `.layer > *` 是 (0,1,0)，`.layer[data-state="leaving"] > *` 是 (0,2,0)，退场规则一定赢，和写在文件里的先后顺序无关；
  - `pointer-events` 会继承，全仓库只有 `.layer > *` 这一处把它设回 `auto`（已 grep），孙子元素（按钮、链接）跟着变成 `none`。
- 横幅根元素上的上滑收起手势（`RemindHost.tsx` 第 50～67 行的 `onPointerDown/Move/Up`）退场时也一起失效，这是想要的。
- 整页提醒（`FullReminderPage.tsx`）：没有用 `Appear`，按钮不播退场动画，处理完直接跳页，没有类似问题。
- 今天页：“现在”卡变成提醒是今天页自己画的，按钮仍然是 RemindHost 的按钮条（`route === 'today'` 时只是不画顶部横幅），已经在覆盖范围内。今天页的列表用 `AppearList`，它自己有 `entering`/`leaving` 不接点按的处理，不在这次范围。

### 2. 注 CSS 的测法是否可靠
- 前提“单测里类名不加哈希”有配置保证：`vitest.config.ts` 第 87 行，unit 项目 `css: { modules: { classNameStrategy: 'non-scoped' } }`，`styles.layer` 就是 `layer`。
- 这个前提一旦被破坏，测试不会假通过：
  - 两条退场测试断言 `user.click(...)` 必须因为 `pointer-events` 报错；
  - 类名对不上时 CSS 不生效，点击成功，测试会失败。
  - 也就是说测试自己就在检查“样式生效了”，可靠。
- user-event 会沿祖先找最近一处声明了 `pointer-events` 的元素，jsdom 的 `getComputedStyle` 也会按优先级和先后层叠。下面的变异 X3（降低优先级、挪到前面）被拦住，说明测试真的按层叠判断，不是“文件里写了这条就算”。
- 正常动效和 `data-rm="1"`（只淡出）两种退场都测了，两种都会打 `leaving`。
- 小点（L2）：`readFileSync('src/features/reminders/ui/Remind.module.css')` 是相对当前目录的路径，换个目录跑 vitest 会读不到文件。

### 3. 有没有误挡进场或常态的点按
- `data-state` 只在 `!present` 时才是 `'leaving'`，进场、停稳时都是 `undefined`，规则不匹配。
- 退场途中又显示（`show` 变回 true、同一个 key）时，AnimatePresence 让同一个元素回到 present，`data-state` 清掉，马上能点。
- 换下一条提醒（队列里还有）时 `show` 一直是 true，外层 `Appear` 不退场，只是里面 `Banner key={r.tag}` 换了，不受影响。
- 对照测试（没退场时点“详情 ›”能触发）守着常态。变异 X5（常态也设 `none`）被它拦住。

### 4. 对动效的影响（按 review-animations 的标准）
- 只改 `pointer-events`，不碰 `opacity`、`transform`，不引起布局和重绘，退场的时长、曲线、减弱动效时的处理都不变，不影响掉帧。
- 体验上有一点副作用（L1）：退场期间点按会穿过去，落到下面的页面上。Dialog 有遮罩，这里没有遮罩。
