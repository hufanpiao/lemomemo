# B2 底栏透明度：真机和视觉稿的差异排查

## 0. 第二轮（11-06 下午）：根因更正和修法

负责人真机复核：“跟那个没关系，我把字移到下面也不透明”。第一轮的主因（后面没内容）不成立，更正如下。

**根因：副本档的副本层本身是不透明的。** glass-ghost.ts 的 makeLayer 给副本层写了 `background: var(--bg)`（整块纯灰），里面只放带 data-ghost 的元素的复制品（月历格、周视图、日清单、现在卡、今天页和待办的行）。没标 data-ghost 的内容——月历图例、页面标题、分段控件、“这一天没有安排”这类空状态、设置页各卡片——走到底栏后面时，副本层里什么都没有，纯灰底把真实画面整个挡住，再叠 0.34 白，就是一条实心白胶囊。副本档反而比后备档（backdrop-filter，透得出真实像素）更“实”。

- 复现（webkit 375×700，月历顶部，图例“客户 标签…”“+N：还有 N 件”正在底栏后面）：data-glass="copy"，副本层底色 rgb(233,234,238)，副本数 0；截图 `修前-月历图例在底栏后面.png`、`修前-月历图例-底栏特写.png`：底栏里一个字都看不到，栏外右边露出半个“还”字。
- 第 2 问逐条：只复制 data-ghost 元素、不复制其余内容（是）；副本跟滚动（跟，scroll 时重算位置）；位置对（对，月历顶部那张图里日清单卡的副本位置正确）；没被 overflow 裁错。
- 第 3 问：副本层用的 filter（blur/saturate/brightness）、transform: translate 在 iOS Safari 都支持，主屏幕版和 Safari 同一个引擎；不是 iOS 专有问题，webkit 桌面同样复现。
- 第 4 问：构建产物里 backdrop-filter 都带了 -webkit- 前缀（lightningcss 自动加，dist 里 11 处 none、各档模糊都成对出现），后备档在 iOS 上是好的。
- 第一轮第 2 节说“没有停在后备档”是对的，但结论“副本档是好的”错了：副本档只对 data-ghost 内容好。

**修法（已改，11-06）：** 副本档不再用副本层，改成直接模糊背后的真实画面。

- GlassBar.module.css：`.bar[data-glass='copy'] .barTint` 改成 `background: var(--g-tint); backdrop-filter: var(--g-copy-fx)`（就是副本那组滤镜 blur(2px) saturate(1.8) brightness(1.04)，看起来和副本一样，但什么内容都透得出来）；“＋”同样；副本层 `[data-glass-layer]` 在底栏和“＋”里 display: none；自动深浅的深色层只在 data-ad="dark" 时加同一组 backdrop-filter。
- 没改 src/motion/glass-ghost.ts（固定规矩不动 motion）：引擎照常接管，管自动深浅（data-ad）和倾斜高光；它仍会建副本（只是藏着看不见），这部分白做的工作留给后面改 motion 时去掉（要主持人同意动 motion）。
- backdrop-filter 层数：底栏、“＋”各一层，和首屏后备档一样多（后备档本来就有这两层），没有比修前的后备档多；data-ad="dark" 时底栏多一层。
- 同时照稿补了 A 类（负责人 11-06 定外框去掉）：后备模糊 12px → 8px；去掉 0.5px --rim-shade 外框；内侧柔光 inset 0 0 10px（新令牌 --g-glow-c，自动深浅用 --g-ad-glow-c）；沿边亮光（.glass::before，1.6px 一圈，上沿 --g-hi、下沿 --g-hi2，位置跟 --g-sx）；阴影换成两层（新令牌 --g-bar-shadow：0 8px 24px 加 0 1px 3px，浓度同 --g-drop）。令牌改在 tokens.json，tokens.py 重新生成。
- 修后截图：`修后-月历图例在底栏后面.png`、`修后-月历图例-底栏特写.png`（图例文字、客户标签、纪念日菱形都透出来、轻微模糊）；`修后-待办16条滚到中间.png`、`修后-待办-底栏特写.png`。
- 负责人在 iPhone 主屏幕版复核：部署到预览后请负责人再看一次（月历把图例拖到底栏后面、待办滚到中间）。

**根因 2（11-06 傍晚，主持人对照截图发现“修后字清清楚楚、和页签抢”时查出）：模糊写在了看不到背景的那一层。** .bar、.fab 带 view-transition-name（tabbar、tabbar-add），按 Filter Effects 2 的 backdrop root 规则它们自己就是子元素的“背景根”，里面着色层（.barTint、.fabTint）的 backdrop-filter 只能看到 .bar 里面，等于没模糊。这条从首屏后备档起就一直存在：后备档的 blur(12px) 在 Chromium 和 iOS Safari 上也没生效，底栏只剩 0.62 白着色叠在清晰的内容上。

- 证据：Chromium 375 宽 3 倍图，同一位置只把 .bar 的 view-transition-name 去掉，模糊立刻生效（`根因2-有无切页名字对比.png`，上：有名字、字清楚；下：去掉名字、糊掉）。各层祖先只有 nav 有 view-transition-name，没有 filter、opacity、mask、clip-path。
- 注意：Playwright 在 Windows 上的 webkit 根本不画 backdrop-filter（去掉名字、去掉模糊带都没变化），所以上面“修后-月历图例…”“修后-待办…”这 4 张 webkit 截图里背后的字是清楚的，看不出模糊效果；模糊效果以 Chromium 截图为准，真机以负责人复核为准。
- 修法：backdrop-filter 挪到 .bar、.fab 自己身上（后备 blur(8px) saturate(1.8)；副本档 var(--g-live-fx)）；着色层、深色层、液滴只管颜色。减少透明效果时 .bar、.fab 的 backdrop-filter 改成 none。
- 模糊多少：按视觉稿对照试了 3、4、6、8、10px（Chromium 3 倍图）。6px 以上背后只剩一片白、看不出形状，和稿子不像；3px 和稿子最接近（字糊成一团、读不出，只透出颜色和形状）。新令牌 --g-live-fx = blur(3px) saturate(1.8) brightness(1.04)。对照图 `对照-视觉稿和修后3px.png`，特写 `修后3px-待办-底栏特写.png`、`修后3px-月历图例-底栏特写.png`。
- 页签字对比度（#141518 对底栏平均底色，3px 时）：待办 15.3:1，月历图例 15.9:1；底栏里最暗的那一块也有 6.2:1，都 ≥ 4.5。
- 副本引擎还在白建副本（看不见），已记进接手清单 GLASS-copy-unused，等改 motion 时去掉。

### 顶部渐变模糊带（负责人 11-06：向下滑时顶部也要和底部一样的渐变模糊）

- 现象：负责人截图里“2026年11月”滚进状态栏底下和“10:21”叠在一起。原来 base.css 有一条 body::before 底色条（高 = 安全区，实色），webkit 里模拟 59px 安全区时它能盖住（`measure-glass/top/现状-*`），真机上为什么没盖住还没查清（可能和预览版本有关），这次一起换成渐变模糊带，请负责人真机看。
- 做法（纯 CSS，只改 base.css，不加 DOM、不进首屏脚本）：带高 = 安全区 + --top-fade（12px，宽屏 0）。
  - body::before 仍是底色条，加了遮罩：从最上沿整段渐变到透明（负责人 11-06 选定不留实色段）。
  - 两层模糊：html::before 8px 管状态栏那一段，body::after 2px 管往下的过渡段，方向和底部那条相反。
  - 层级 1、不挡点按。减少透明效果两种都藏模糊、只留底色渐变（实色渐变）。≥ 900px 不加。
  - 只用两层 backdrop-filter（底部那条 5 层），主持人提醒 webkit 多层拖慢主线程。
  - 背景根：两层都挂在 html、body 的伪元素上，它们的背景根是 html 本身，看得到整页内容（截图已证实），不会重踩底栏根因 2 的坑。
- 截图（Chromium 3 倍图；Windows 版 webkit 不画 backdrop-filter）：`顶部模糊带-月历-滚动前后.png`、`顶部模糊带-待办-滚动前后.png`。滚动前页头清楚，滚动后进带子的分段控件、筛选胶囊被糊掉、淡出。
- 拿不准、要问负责人的（外观取舍）：
  1. 带子多高：A 安全区 + 12px（现在）；B 安全区 + 24px，淡出更长更柔，但静止时页头最上面 24px 也压在带子里（页面顶部留白现在正好等于安全区）；C 安全区 + 24px，同时页面顶部多留 12px。
  2. 模糊多深：A 8px + 2px（现在）；B 12px + 4px，更像底部那条最深处；C 4px + 1px，只是轻轻柔化。
  3. 实色占多少：A 安全区上半段实色（现在，时间、信号下面一定干净）；B 不留实色、全靠模糊和渐变，更通透，但滚过去的深色卡片会在时间底下透出颜色。

- 设计评审 T-1（a80917，11-06）：静止时待办大标题的上沿落进了带子里。已改：base.css 里把 --safe-top 改成“安全区 + --top-fade”，各页顶部都多留 12px，宽屏仍为 0，有版本横幅时仍为 0。Chromium 按 59px 安全区量了一遍：今天、待办、月历、设置四页，第一个可见元素的上沿分别在 80.5、71、82.5、82.5，都不高于带子底边 71。

## 一句话结论

玻璃本身是好的：副本引擎已经接管（data-glass="copy"，着色是更透的 0.34），没有被“降低透明度”压成实色。**看着像实心，是因为底栏后面没有东西**：页面底部留了 142px 空白，内容滚到底也停在底栏上方；页面短时（月历、今天、待办在没数据或数据少时）根本不用滚，底栏后面永远只有纯灰底色 #E9EAEE。0.34 白叠在纯灰上，就是一条浅白的胶囊。视觉稿那几屏之所以通透，是稿里内容一直铺到底栏后面（列表、卡片、黄色块从底栏下面穿过去）。

另有三处参数和视觉稿不一样（后备模糊、阴影、内侧柔光和沿边亮光），影响小一些，见第 4 节。

## 2. 用的是哪一档材质（第 ② 问）

| 项 | 实测（4 页都一样） | 视觉稿（贴上副本后） |
|---|---|---|
| data-glass | "copy"（副本引擎已接管） | .scr.lgx（已贴副本） |

所以真机上不是“停在后备那一档”：后备是 0.62 白 + blur(12px)，会更白；我们量到的是副本档。真机上没法直接读属性，但截图里底栏顶沿那条淡淡的模糊带、选中液滴的样子都和 webkit 副本档一致。

注意副本档的一个特性：副本层的底是 var(--bg)，只复制带 data-ghost 的元素，所以“后面没东西”时它就是一块纯灰，比后备档的 backdrop-filter 还“实”——后备档至少会透出页面背景的真实像素。

## 3. 会不会被“降低透明度”压成实色（第 ③ 问）

- 实测 prefers-reduced-transparency = false，:root 上没有 data-rt。负责人已确认 iPhone 的“降低透明度”没开。
- App 里“设置 › 皮肤 › 减少透明效果”：**代码里目前没有任何地方写 data-rt**（src 全文查过，只有 CSS 和 glass-ghost.ts 读它，测试里手动设）。sections.ts 的注释说皮肤页“含减少透明效果”，但开关还没做。所以真机上 data-rt="1" 不可能被打开，这条也可以排除。
- 真的进入实色档时，底栏会是 #FFFFFF 纯白、没有模糊带；负责人截图里顶沿还有模糊带，也说明不是实色档。

## 5. 修法

### A. 做法类（不改外观口径，按稿补齐，可以直接做）

1. 补内侧柔光：.glass 的 box-shadow 加 `inset 0 0 10px rgba(255,255,255,var(--g-glow))`（A11 不让 rgba 里套变量的话，按文件头说的用单独一层 opacity）。
2. 补沿边亮光：.glass 再加一个伪元素或一层，照稿 spec::after（1.6px 环形遮罩，上沿 --g-hi、下沿 --g-hi2，位置跟 --g-sx）。
3. 后备模糊 12px 改回稿子的 8px。
4. 阴影照稿换成两层（0 8px 24px + 0 1px 3px）；--shadow-2 是全局令牌，只能给底栏单独写，或在令牌表加 --g-bar-shadow（要过 tokens.py）。

这四条做完，底栏边缘会更“玻璃”一些，但**解决不了“后面没东西时发白”**。

### B. 外观取舍类（要问负责人）

1. **底部留白要不要缩小，让内容能滚到底栏后面？**
   - 选项 1：维持现状（142px，最后一行一定露在底栏上方，好点、好读）。
   - 选项 2：照稿 120px，改动小，效果也小（只多压 22px）。
   - 选项 3：留白只留到底栏中线（约 70px + 安全区），最后一行能滚到底栏后面一半，玻璃里一直有内容；代价是最后一行点按要往上推一下。
2. **页面短、后面就是没东西时，玻璃要不要“自己有点颜色”？**
   - 选项 1：维持（发白就发白，和稿子月历屏一致）。
   - 选项 2：副本档底下垫一点页面背景的变化（比如淡淡的顶光渐变），让纯灰底也有层次。
   - 选项 3：后面没内容时把着色降到 0.2，靠阴影和亮边勾形状，更透但对比会掉（要重算 R-154 的 4.5 门槛）。
3. **外圈 0.5px 细线去不去？** 稿子没有；它是为了浅色底上看清边界加的（--rim-shade）。去掉更像稿，浅灰底上边界会弱一点。
4. **副本要不要照稿复制整屏**（标题、图例、分段控件也进玻璃）？更像稿，但每帧复制的东西多，iPhone 上可能掉帧，要先做性能试验；建议放后面。
