## 逐项核对（做对的）

**设计**
- 尺寸位置和试验页一字不差：底栏左 14、右 94、高 62、内边距 5、离底 8+安全区；“＋”66×66、离底 6+安全区、外圈 4px 底色；481px 以上居中 372 宽。375 宽实测：底栏 x14 宽 267，页签 63×52，“＋”66×66，头像 44×44。触控面积全部 ≥ 44。
- 安全区：`viewport-fit=cover` 已开，`env(safe-area-inset-bottom)` 用在底栏、“＋”和模糊带高度上，iPhone 15 上底栏下沿离屏幕底 42px，躲开 home 条。
- 四套皮肤（玻璃/简洁 × 浅/深）在条纹底上都截了：栏字浅色 #141518、深色 #F2F3F5，加 `--g-halo` 光晕，按最不利底色估算 ≥ 5.9:1；“＋”墨黑在柠檬黄上 ≥ 10:1。简洁皮肤和玻璃同一套底栏，符合决定④。
- 决定①～③都落实：今天页右上角头像进设置、日历/待办右上角放大镜不受影响；4 个页签、随手记“即将推出”且没有“＋”；“＋”今天/日历新建日程、待办新建待办，待办页右上角原“＋”已去掉。随手记页“＋”不出时底栏不挪位置，四页页签位置一致，这样是对的。
- 中韩：中文“随手记”3 字、韩文“캘린더”3 音节都在页签内，不换行不截断。

**动效**
- 只动 `translate`、`scale`（合成层属性）；液滴位置用 CSSOM 写 `--i`，避开 CSP 的 style-src-attr。
- 减少动态效果：系统设置和 `data-rm` 两条都写了；chromium 实测切页不走 View Transition、液滴直接到位、按住不放大。
- 切页时底栏不参与过渡：`view-transition-name: tabbar / tabbar-add`，group/new `animation:none`，old `display:none`。chromium 采样期间所有过渡动画只有 root 三条，没有 tabbar 的；连拍里底栏稳定不淡入淡出（webkit 的消失是 D1 的 Suspense 引起的，不是过渡规则）。
- `::view-transition { pointer-events:none }` 在样式表里（e2e 也测了），连点不被吞。
- CSS transition 天然可打断，连点时液滴从当前位置接着滑（L1 的果冻层除外）。
- 没有 hover 样式，所以不存在没门控的 hover；以后电脑版加 hover 要放进 `@media (hover:hover) and (pointer:fine)`。

**可访问性**
- `<nav aria-label="底部导航/하단 메뉴">`，页签是 `<a href>`，选中 `aria-current="page"`，图标 `aria-hidden`，模糊带 `aria-hidden`。
- “＋”是 `<button>`，读屏名按页变化：“新建日程”“新建待办”。头像 `aria-label="设置"`。
- 键盘：Tab 顺序 页面内容 → 四个页签 → “＋”；`:focus-visible` 2px `--focus` 蓝环加底色隔圈，页签和“＋”在玻璃上都清楚。
- 减少透明效果：系统媒体查询和 `data-rt` 两条都写了，栏底、液滴、“＋”换实色，模糊带隐藏（选中项看不见见 D2）。

## 动效逐帧采样（摘要）

chromium，已访问过的页之间切换，`--i` 在点击后 8～26ms 更新，液滴 0.55s 回弹（最大越界约 13%），约 590ms 停稳；页面过渡 380ms（vt-done 444～511ms）。

webkit，同样操作：去“今天”时 `--i` 在 33ms 更新；去“待办”“日历”时在 **326～353ms** 才更新（三次复测一致），中间有一次直接从 0% 跳到 200%、没有滑动；同时段底栏被 React 藏起（D1）。

果冻：横向 1.22、纵向 0.86（实测峰值 1.216×0.863），0.55s 内回到 1。按住：任何页签按下，当前液滴 `scale` 变 1.16（D3）。

## 回报摘要

- 必改：D1 底栏挪出页面 Suspense，液滴点按即走（高）；D2 减少透明时选中块要和栏底区分开（中）；D3 按住放大只对当前选中页签、用 1.12（中）。
