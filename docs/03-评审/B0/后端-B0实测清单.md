# B0 后端实测清单（离线做不了、要真库或预览项目的）

- **作者**：后端程序员　**日期**：2026-10-28
- **背景**：本机没有 Docker。B0 后端的 SQL 和测试先在 PGlite（WASM 版 Postgres 18.3）+ Supabase 桩上跑通（`cd supabase/tests/offline && npm ci && node run.mjs`）。**桩不是 Supabase 的真实定义**：pg_cron、pg_net 被跳过，auth、storage、Realtime、PostgREST、Supavisor、Auth 服务都没有。下面每一项都要在有 Docker 的机器（`supabase start`）或预览项目上做一遍，结果记进 B0 QA 报告。
- **怎么用这份清单**：按“在哪做”分三段。每项写了做法、预期，以及不符合时怎么办。打勾和截图由做的人补。CLI 一律用项目里的 `npx supabase`（版本以根目录 devDependency 为准）。
