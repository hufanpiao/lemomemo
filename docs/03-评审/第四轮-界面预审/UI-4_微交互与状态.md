# 第四轮 · UI-4 微交互与状态预审（v3 草图）

**结论：有条件通过。** 主要有两处问题。一是提醒卡片和“下一件事”都是黄色、内容也重复，堆在一起像两张一样的卡，建议提醒出现时“下一件事”暂时隐藏。二是主题浮层在草图里画成常驻的三段选择器，和“浮出一行小字、2 秒后消失”的说明对不上。动效记忆点仍然只留给勾选完成，提醒卡片不加弹簧。

1. 提醒卡片：从上方下移 12px 加淡入，240ms，cubic-bezier(.22,1,.36,1)，响铃图标只摆一次（±8°，400ms）。点“知道了”后高度收起、透明度降为 0，200ms，cubic-bezier(.4,0,.2,1)。另一台设备点了时，这边先显示“已在别处确认”0.8 秒再收起。多条提醒时只显示最早一张，右上角标“+N”。
2. 主题切换：颜色统一过渡 200ms ease，过渡期间关掉其他 transition。小字淡入 150ms，停 1.6s，淡出 200ms。
3. 识别胶囊：输入停顿 250ms 后才更新，胶囊位置固定，只换字，换字时透明度闪一下 120ms，不做位移。手改过的字段加锁形图标和描边，读屏读出“已锁定”。
4. 恢复：条目从最近删除淡出 160ms，回到原位置后用现有的 .fresh 高亮。搜索有结果时显示“N 条”并高亮关键词；没结果时显示“没找到”，加“清空”按钮，并提示 Claude 可以帮忙找。
5. 提示条：新的一条从底部上移 8px 进来，200ms ease-out，旧的用 FLIP 上移让位，180ms。改成左对齐、统一宽度，草图里宽度参差不齐。第 4 条进来时最旧的一条淡出，并显示“更早的在最近删除”。
6. 加载中：提醒和搜索先不显示，最近删除显示骨架。断网时提醒卡片标“离线，提醒可能延迟”，恢复按钮置灰。保存超时 10 秒时按钮恢复，提示条写“没保存上，重试”，不会自动消失。
7. 减少动效：所有位移和摆动都取消，只保留 ≤120ms 的透明度变化；声音保留。

## 复审（草图第 2 版）

**结论：有条件通过。** 上次两处主要问题都解决了。7 条方案在新布局下仍然适用，其中 3 条要补充说明。

1. ①A 下一件事卡片进入提醒状态：卡片高度展开，240ms，cubic-bezier(.22,1,.36,1)，铃铛行和按钮淡入，铃铛只摆一次。点“知道了”按相反顺序收起，200ms，cubic-bezier(.4,0,.2,1)。另一台设备点了时，先显示“已在别处确认”0.8 秒再收起。①B 有多条提醒（+N）时，下一条在原位淡入淡出切换，160ms。
2. 主题选择器：从按钮右上角弹出，缩放 .92→1 加淡入，180ms，cubic-bezier(.22,1,.36,1)。选完先停 300ms，让人看清选中项，再收起，150ms。点外面或按 Esc 也会关闭，关闭后焦点回到按钮。选择器要浮在页面上方，不能像草图那样推着内容往下挪。在深色下它和背景几乎分不开，阴影也不起作用，要加 1px 描边。
3. 新问题有两个。② 识别胶囊折成两行，内容变化时会跳行，要给胶囊区固定最小高度，并且 aria-live 也要等停顿 250ms 后再播报。“已改”用 11px 浅灰字，看不清，改成锁形图标，字号至少 12px，对比度至少 4.5:1。
