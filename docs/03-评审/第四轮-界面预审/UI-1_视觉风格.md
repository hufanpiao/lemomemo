# 第四轮 · UI-1 视觉风格预审（v3 草图）

**结论：有条件通过。** 整体延续了 v2 的风格，但第 1 条必须先改。

1. ① 提醒卡片和“下一件事”卡片撞色：两块黄色上下叠放，标题和“15 分钟后开始”都重复了一遍，看起来像出错。改法：被提醒的正好是下一件事时，不另加卡片，直接让“下一件事”卡片进入提醒状态（加铃铛行和两个按钮）；是别的事时，提醒卡片改成反色（浅色模式用墨黑底，深色模式用白底），按钮用黄色，和 v2 的黑色胶囊同一套语言。
2. ① 主题按钮的位置：在 375px 宽度下它掉到了日期下方左侧，并没有在右上角。改法：抬头不换行，按钮固定在右上角，和日期顶部对齐；“没赶上”胶囊挪到日期下面。下方那条三段式胶囊是白色的，和 v2 的黑色胶囊不一致，而且和“点按循环切换”重复。改法：二选一，建议点按后弹出黑色胶囊三选一。三个图标（半圆、太阳、月亮）可以用。
3. ②③ 胶囊行：提醒选项和截止选项都折成两行，“1 天”“不设”单独落在第二行，显得零碎。另外选中态是黑色，和上面的“日程/待办”切换一模一样，层级分不清。改法：单行横向滑动；选中态改成黄底黑字。识别结果的方角灰标签（圆角 8px）统一改成胶囊形。
4. ④ 截止标记：6px 的红色方块紧挨着圆点，看起来就是两个点；而且红色已经用在播放头和“没赶上”上，未到期的截止用红色会让人以为出了问题。改法：换成墨色短横线（8×2px）。列表里的截止行换成待办的圆形勾选框，可以直接勾掉。
5. ⑤ 最近删除：用了 1px 分隔线，违反 v2“不加线”的规则。改法：默认折叠成一行“最近删除 2 件 ›”，背景放在 panel-2 色块里。导出链接去掉下划线。
6. 深色模式：两块大面积黄色在黑底上太刺眼，深色下的黄色应降低约 10% 亮度。“原话”“Claude 代记”标签和 12px 说明文字对比度不够，至少要到 4.5:1。

**v3.1 皮肤提案**（每套 5 色：底、面板、文字、主强调、副强调）
- 蓝幕（抠像蓝 + 信号橙）：#EEF1F6 / #FFFFFF / #0E1726 / #1F4BFF / #FF5A36；深色底 #070B14
- 暗房（安全灯红，以深色为主）：#140C0C / #1F1514 / #F3E6E1 / #E0442E / #9A8580；浅色底 #F4EFEC
- 孔版印刷（荧光粉 + 孔版蓝 + 黄）：#ECEEF0 / #FFFFFF / #1A1A2E / #FF48B0 / #0078BF / #FFE800
