# 第四轮 · UI-2 移动端交互预审（v3 草图）

**结论：不通过**（交互方向对，但有一处阻断问题，热区多处不达标）

**严重**
1. ② 新建：键盘弹起后，可见区域只剩约 45% 的屏高。识别结果还能看到，但「加入」和提醒行会被挤到键盘下面，弹出层也明显偏长。改法：「加入」放进输入框右侧或吸附在键盘上方；输入时识别结果卡就当作确认，类型、字段、提醒收进「改细节」，默认折叠；听写提示只在输入框为空时作为占位文字出现。
2. ③ 编辑：「删除」和「保存修改」在同一行，右手拇指最顺手的位置正好是删除，容易误触。改法：删除单独放到最底部，做成整行、高 44px 以上，和保存之间隔 24px 以上。

**中等**
3. ②③ 的选项胶囊、类型切换只有 36px 高，① 提醒卡片按钮 40px、主题按钮 40px，都要改到 44px。
4. ④「回到今天」挤在左右箭头旁边，容易点错。改法：放到周条下方居中，或者点标题回到今天；让周条紧贴标题，项目筛选放到周条下面。

**轻微**
5. ⑤「最近删除」现在默认展开，应该折叠成一行；导出备份移到设置里或页面最底部。
6. ① 主题按钮要点几次才能循环到想要的状态，用户看不出顺序。改为点开三段选择器（草图里已经有这个样式），去掉循环切换；提醒卡片里把「10 分钟后再提醒」缩短为「稍后」。
