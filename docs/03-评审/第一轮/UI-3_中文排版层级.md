# UI-3 中文排版与层级

**问题**
页面用了三套字体（宋体、黑体、等宽），顶部那个日期又只用 Noto Serif SC 900 来写阿拉伯数字，所以记忆点不够鲜明，旁边的 13px 等宽年月和 20px 宋体星期也在跟它抢注意力。字号阶梯是 11/12/13/14/15/20/76，小号太密，中间却缺了一档。“重要”和“今天”都用同一种蓝，“重要”和“逾期”都是 11px 的小标签，三种状态只能靠颜色分，层级上分不出来。

**建议（按优先级）**
1. 顶部大日期改用 Fraunces 600（Google Fonts 上有，开 opsz 和 tabular-nums），字号 clamp(88px,22vw,128px)，行高 0.85。备用字体写 "Noto Serif SC",Georgia,serif。星期改成 16px Noto Sans SC 500，年月 14px muted，两行贴在日期右下。
2. 去掉 IBM Plex Mono。时间、日期条、统计数字、标签统一用 Inter 500 加 tabular-nums，备用字体写 "Noto Sans SC",system-ui。统计数字 28px，日程时间 15px。
3. 字号阶梯收成 12/14/16/20/28/大日期六档：正文 16px、行高 1.65，备注 14px、行高 1.55，区块标题 20px Noto Serif SC 600、行高 1.3。手机上正文不要低于 16px。
4. 三种状态用三种手段区分。今天：分组标题改成 16px 600 的深色字，左边加一条 3px 蓝竖线。逾期：用警示色，条目标题本身也变色，标签 12px 500。重要：标题加粗到 700，前面放一个实心小点，不用蓝色，免得和“今天”撞色。
5. 中文分组标题去掉 letter-spacing .08em（中文字距拉宽会显得松散），改成 0；h2 里的 small 也一样去掉字距。
