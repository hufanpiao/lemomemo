# UI-4 微交互、反馈与状态

**问题**：勾选或删除时要等云端返回，onSnapshot 再整表重绘，条目会突然消失，没有过渡，失败时也不回滚。删除是 3 秒内点两次，按钮小、没有撤销；加载、离线、出错都只靠一行灰字，Claude 新加的条目悄悄出现。深色下 .tag 底色（--bg）和卡片几乎分不出来，.past 透明度 .55 显得太脏。

**建议（按优先级）**
1. 勾选是全页唯一的记忆点。乐观更新：勾框缩放 0.9→1，用时 160ms，cubic-bezier(.34,1.4,.64,1)；划线用 background-size 从左往右画，280ms，cubic-bezier(.22,1,.36,1)；停留 700ms 后行高和透明度一起收起，240ms，cubic-bezier(.4,0,.2,1)。为此要按 id 增量更新，不能整表重绘。减少动效时直接划线，800ms 后移出。
2. 删除改为立刻隐藏，底部出现撤销条，5 秒后才真正写库。撤销条上移 8px 入场，200ms，ease-out。不做左滑，因为它和页面滚动、返回手势冲突，电脑上也没有对应操作。
3. 写入中按钮显示“保存中…”，失败就回滚，并在提示里给“重试”。监听 online/offline，在顶部显示细条；连接断开时给“重新连接”按钮。
4. 首屏放 3 行骨架，透明度脉动 1.2s、ease-in-out（减少动效时静止）。“已全部完成”的空状态和真正的空状态分开写。
5. 非本端写入的新条目：左侧 2px 强调色竖条加 accent-soft 底色，保留 1.6s 后用 600ms 淡出；不在视口内时显示“新增 N 条”小胶囊。深色模式：标签底色改用 #232a35，过去的日程改用 --muted 字色，撤销条用边框代替阴影。
