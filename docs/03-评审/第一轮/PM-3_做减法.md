# PM-3 做减法（唱反调）

**逐项**
- 三个统计数字：砍掉两个，只留“已逾期”，而且为 0 时不显示。“今日日程”和“未完成”，下面列表一眼就能数出来，再写一遍是噪音，还在手机首屏占了一行。
- 两周日期条：简化。只留圆点提示“哪天有事”，点一下滚动到那天，不再用来筛选。筛选会制造“看全部”这种额外的状态和按钮。手机上 14 个格子会挤成两行，可以考虑改成一行可横滑的本周。
- “显示过去的”开关：砍掉。日程本来就只看今天以后。真要翻旧账，在聊天里问 Claude 就行。
- 待办三种筛选：砍成零。默认只显示未完成，刚勾掉的留在原处划线到当天结束，第二天自动消失。“已完成”不常看，在底部放一个“已完成 N 条”的折叠链接就够了。
- “重要”标记：保留，但只此一种标记，不做优先级分级。它只决定排序（排最前）。
- 日程备注：简化。表单里不放单独的备注框（手机上一个表单 4 个输入框太重），标题写“14:00 会议 @望京”就够了。Claude 代加时可以写进去，有备注就显示。
- 删除点两次确认：改掉。换成“删除后底部出现 5 秒‘撤销’”，少一次点击，误删也能救回来。

**只能新加一个功能**：一个统一的输入框。不用选择是日程还是待办：有时间就算日程，没有时间就算待办。和在聊天里跟 Claude 说话的心智一致。这一个输入框顶替现在两张表单里的 7 个控件，加完功能，页面反而更简单。

**第一眼的顺序**
1. 今天还剩的日程（时间 + 事）
2. 逾期和今天截止的待办
3. 其余未完成待办
4. 输入框
5. 日期条和以后的日程

日期大字头保留但缩小，它不应该是首屏主角。
