# UI-2 移动端交互与信息架构

**问题**
手机上两栏会叠成一长条，待办被压在全部日程下面，想勾一项就得滑过整个日程列表。两张表单一直摆在各栏顶部，加起来 8 个输入框，占掉首屏，又正好在单手够不着的上半屏。热区偏小：删除是 12px 文字，复选框 18px，日期条一次放 14 格，点一下还会偷偷改掉表单里的日期，这层联动用户看不出来。

**建议（按优先级）**
1. 默认打开「今天」视图：上半是今天的日程，下半是今天到期、已逾期和标了重要的待办；底部放标签栏「今天｜日程｜待办」，高 56px，加 safe-area-inset-bottom。
```
┌ 23 周四  3日程·5待办 ┐
│ 一 二 三[四]五 六 日 │
│ 10:00 客户会        │
│ ☐ 交SignPlex 逾期   │
│               (＋)  │
├ 今天 │ 日程 │ 待办  ┤
└─────────────────────┘
```
2. 表单整个去掉，右下角放一个 56px 的「＋」浮动按钮，点开底部弹出层：顶上切换「日程/待办」，只有标题必填，日期、时间、备注收进「更多」；默认日期取当前选中的那天，并且明着显示出来。
3. 加大热区：整行点一下就勾选，左滑出现删除，删除后底部提示条给「撤销」，替掉现在的两步确认；所有可点区域至少 44px。
4. 日期条一次只放 7 天，左右滑动翻周，吸顶；点某天只筛选列表，不再改表单；有安排的日子用圆点、逾期用强调色标出。
5. 桌面端（≥900px）分三栏：左边月历加摘要，中间日程时间轴，右边待办；顶部放一条常驻的快速输入框，回车就能添加，「＋」按钮隐藏。
