# UI-1 视觉风格与识别度

**问题**：现在是冷灰底、钴蓝强调、白卡片加细边框，和通用 SaaS 后台没什么区别，看不出主人是做影像的。标题用宋体 900，再加一条 2px 黑色分隔线，带出了“报纸风”的套路，和下面一板一眼的卡片气质对不上。全页只有“蓝色加小圆点”一种视觉语言，日程、待办、逾期的层次全靠灰色深浅来分，没有一个让人记得住的画面。

**建议（按优先级）**
1. 记忆点用“播放头”：今天的日程列表里，在当前时刻的位置画一根 2px 的红色竖线（横贯列表），旁边标上 `14:32` 时间码，像剪辑软件的时间线。顶部大日期也改成等宽时间码的写法 `10.23`。
2. 换配色：只留一个强调色，用“录制红”；逾期用实心红底，普通强调只用红色描边或红字，两者靠这个区分。
   - 浅色：底 #E8EAED / 面 #F6F7F8 / 字 #15171B / 次要 #6A707A / 线 #D2D6DB / 强调 #E0342A
   - 深色：底 #0E0F11 / 面 #16181B / 字 #ECEDEF / 次要 #8A9099 / 线 #2A2D33 / 强调 #FF4B3E
3. 质感改成“哑光调色台”：去掉卡片边框和圆角，两栏只用面色区分；每条日程做成剪辑片段，左侧 4px 色条加浅底，有时长的按时长显示长短。
4. 字体：拿掉 Noto Serif。标题用 Noto Sans SC 900 压紧字距，所有数字和时间用 IBM Plex Mono 等宽。
5. 两周日期条做成胶片条：上下各一排细小的打孔点，今天用红框标出，有日程的日子把下面的点换成红色短线。打孔点不要加到页面其他地方，避免花哨。
