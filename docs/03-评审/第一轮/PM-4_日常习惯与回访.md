# PM-4 日常习惯与回访

**判断**
现在的页面是一个“录入工具”。打开后最显眼的是大日期、两个表单和“已逾期”红数字，没有回答“我现在该干什么”，所以用户只有想记事时才会来。既然没有推送，唯一能留住人的就是每次打开的前 3 秒都有收获：最上面一张卡片给出“下一件事”，逾期的事一键挪走，不让它堆成负担。另外一个提醒渠道交给 Claude 在聊天里做，页面本身不用承担提醒。

**按优先级排序的建议**
1. **顶部“下一件事”卡片**：替换掉现在的统计区。卡片显示最近一条还没开始的日程（写明“还有 40 分钟”），没有日程就显示最重要、截止最早的待办，卡片上直接能勾完成。价值：最高，这是每次打开的理由。成本：低，现有数据前端算一下就行，大约 40 行。
2. **逾期改成“顺延”区**：去掉红色“逾期”标签，在今天的列表上方折叠显示“N 件没赶上”，每件给“改到今天/明天”按钮，再加一个“全部挪到今天”。用现有 update 改 due 字段即可。价值：高，直接消除焦虑。成本：低。
3. **按时间段换首屏**：早上（12 点前）显示“今天的安排 + 顺延区”；晚上（18 点后）显示“今天完成了 N 件”，列出今天勾掉的事，再预告明天的安排。价值：高，早晚各给一个打开的理由。成本：中低，用现有的 doneAt 按今天筛选。
4. **Claude 定时简报**：用定时任务每天 9:00 和 21:00 读数据库，在聊天里发 3 行摘要（下一件事、逾期几件、明天有什么），附上看板链接。价值：高，弥补没有推送的问题。成本：中，需要用户同意定时任务。另外，聊天和定时任务本身能不能在手机上弹通知，要先确认。
5. **完成反馈**：勾掉时给一个轻微的划线动画，计数加 1（“今天第 3 件”）。表单默认收起，改成一个“＋”按钮，把首屏留给内容。价值：中，带来成就感，首屏也更干净。成本：低。
