# PM-1 核心使用场景

**判断**：页面能记，但不好看，也没法打理。手机上一打开先看到两张录入表单，“今天要做什么”得往下翻才找到。数据里没有“项目”字段，记错了的条目也不能修改，只能删了重记。

**按投入产出比排序的建议**
1. **“今天”视图放在首屏**：把今日日程、今天截止、逾期和重要的待办合成一个列表，两张表单收进一个“+”按钮。价值高，成本低。
2. **加项目字段 project，配固定色块**（SignPlex/NEOX/SOIL 等）：可以按项目筛选；Claude 代记时按关键词自动填。价值高，成本低。
3. **可以编辑和改期**：点开条目就能改；逾期待办一键“顺延到明天”。价值高，成本低。
4. **代替提醒的办法**：截止日期改成倒计时显示（如“剩 3 天”），7 天内到期的自动进“今天”视图；重要节点可导出 .ics 文件到手机系统日历，用系统闹钟提醒。价值中高，成本低到中。
5. **子任务清单**：待办里加一个可勾选的小清单，可选关联到某条日程，适合粗剪、评审、交付这类阶段。价值中，成本中。

**不该做**：重复日程（客户节点不规律）、假装能推送提醒、多级优先级或四象限、拖拽时间块日历、统计报表。
