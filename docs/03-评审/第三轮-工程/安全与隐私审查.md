# 第三轮 · 安全与隐私审查（v3 开工前，审查对象：提交 d779581）

## 一、现阶段（claude.ai 版）

**高：无。** 没有发现把数据库内容用 innerHTML 拼接的地方。`core/dom.js` 的 `h()` 用 `append(String)` 插入文字；它的 `html` 参数只传了常量 `ICON_CHECK`；颜色由 `projColor` 映射成 `var(--pN)`，不会把原始数据写进 style。

**中**
1. **数据库访问规则**：默认规则下根路径读 `view`、写 `interact`，`events`/`todos` 都在根路径下。页面一旦分享，查看者能读全部日程，协作者（Contributor）能改，也能写入一段专门诱导 Claude 定时任务的文字。团队版里同组织的成员也会被放行。建议现在就显式声明：`capabilities:{db:{rules:[{path:"",read:"owner",write:"owner"}]}}`。Claude 在聊天里写库是以本人身份写的，不受影响。
2. **id 会被数据覆盖**：`platform/claude-db.js` 的 `subscribe` 里写的是 `Object.assign({id:d.id}, d.data())`。Claude 写入的条目如果带了 `id` 字段，会盖掉真实 id，之后的改和删就会打到别的文档上。改成 `Object.assign({}, d.data(), {id:d.id})`。
3. **没有做字段整理**：`subscribe.js` 收到数据后直接使用。`title`、`due`、`time` 只要不是字符串，`write.js` 的 `scheduleDelete`（`title.slice`）、`today.js` 的 `renderToday`（`due.localeCompare`）、`sort.js` 的 `pickNext`（`time.localeCompare`）就会抛错，整页白屏。要在 `subscribe` 里加 normalize，强制转类型并限制长度。

**低**
- `write.js` 的 `scheduleDelete` 提示条会显示标题前 12 个字，录屏或旁人可能看到，可以改成“已删除 1 项”。其他错误提示都不含内容。
- localStorage 里只有 `pv-view`，URL 里不带数据，这两点都没问题。`index.html` 加载 Google Fonts 会把 IP 暴露给 Google。
- `rawText` 会永久保存原话；软删除上线后，要保证 30 天到期真的清理掉。

**提醒推送**：内容会经过 claude.ai 数据库 → Claude 定时任务（Anthropic 服务器、会话记录）→ Claude App 通知 → 苹果推送服务（APNs）→ 锁屏和通知中心历史。推送文字不要带完整标题、备注和地点，只写“10:00 1 项日程（NEOX）”这类时间加项目简称；iOS 的“显示预览”设为“解锁时”。

## 二、迁移安全清单

**必须做**
- **登录**：用 Supabase Auth（邮箱验证码、Passkey 或 Apple 登录），关闭新用户注册，开启 MFA。
- **RLS**：每张表都开启，四种操作的策略都限定 `user_id = auth.uid()`，并写 `with check`。
- **密钥**：前端只放 anon key；service_role key 和 VAPID 私钥只放在服务端。Claude 代记要走 Edge Function，用权限受限、可吊销的令牌。
- **HTTPS 与 CSP**：开 HTTPS 和 HSTS。CSP 设为 `script-src 'self'`、`connect-src` 只放行 Supabase 域名、`frame-ancestors 'none'`。web 版不要再内联脚本。继续只用 textContent 渲染，因为登录令牌存在 localStorage 里，一旦有 XSS 就能被偷走。
- **退出登录**：同时清掉 Service Worker 缓存。
- **备份**：Supabase 免费版没有自动备份，要自己定期导出。
- **导出与删除**：提供 JSON 导出，删除账号时级联删除全部数据，软删除到期后彻底清理。

**建议做**
- 写接口加频率限制，开启登录告警。
- Web Push 内容同样做脱敏。
- 选首尔节点（ap-northeast-2）。

**PIPA**：纯个人用途基本不受约束。但日程里记了客户个人的姓名、行踪这类工作信息，严格说属于为业务处理个人信息，所以要做好加密、权限最小化，并先确认公司政策。将来给别人用，就要承担全部义务：隐私政策、取得同意、国外转移告知、泄露通报。
