#### 低（建议改，不卡）
- **低 1：第 16 项“其他设备会提示用新密码解锁，Face ID 要重新绑定”，读起来像只有其他设备要重新绑定。**
  - 架构 5.5 写的是：改密码或重设时，清空这个人全部的 Face ID / Windows Hello 凭据，并给所有设备推送“隐私记密码已修改”。所以改密码的那台设备自己也要重新绑定，而且每台设备都会收到这条推送。
