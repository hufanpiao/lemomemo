# 第二轮 · 独立 PM-A 新手走查

**问题**
1. 【高】误删找不回：编辑面板的红色「删除」没有确认，只能靠 5 秒的「撤销」提示条。期间如果弹出别的提示（比如勾了一件完成），撤销按钮会被顶掉；切到后台会直接真删。App 里没有回收站。
2. 【高】查下周安排看不到截止日：日期条的小圆点和「接下来」只算日程，带截止日的待办不显示。交片死线在日程页里看不到。
3. 【高】只有待办页能按项目筛选，日程不能。也没有一个页面能把某个项目的日程和待办放在一起看。
4. 【中】一句话输入里的「明天3点对片」会被记成凌晨 03:00。另外，只写日期不写时间（如「周五和NEOX开会」）会被当成待办。
5. 【中】在一句话框里接着打字，会把你手动选的「日程/待办」和已经改过的字段改回去。
6. 【中】在今天页加一条没写日期、也没标「重要」的待办，提示「已加入待办」，但今天页上看不到它，像是没存上。
7. 【中】编辑时类型切换被隐藏了，想给待办补上时间、改成日程，只能删掉重建。
8. 【中】翻到别的周后，没有「回到今天」的按钮。点「下一周」会自动选中那周的周一，那一天下面的列表常常是空的。
9. 【低】第一次打开显示「空闲 / 今天没有**别的**安排了」，空数据时「别的」读着别扭。界面里也没提可以在聊天里让 Claude 代记。
10. 【低】「下一件事」卡片是待办时，只有点标题才能编辑。没有截止日的待办，大字只显示「待办」两个字。电脑上的「全部待办」链接点了没反应。弹出层标题「新建」太笼统。

**改进建议（按优先级）**
1. 删除先进「最近删除」并保留 30 天。撤销提示条不被其他提示顶掉。
2. 日程页的日期条和列表也显示待办截止日，加一个「本周总览」。
3. 做一个全局的项目筛选，同时作用于日程和待办。
4. 一句话解析里，1–7 点没写上午还是下午时默认按下午算。只写了日期的事允许记成全天日程。框下方实时显示识别结果。
5. 编辑时可以切换类型。加「回到今天」按钮。改写空状态文案，并说明可以在聊天里让 Claude 代记。
