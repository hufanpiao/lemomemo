# 下一版规划会 · UI 设计经理意见

## 一句话结论
默认皮肤沿用现有便当格风格并做演进（方向 A）。下一版加一套“夜荧光”深色皮肤（方向 C）。磨砂玻璃（方向 B）只在 Windows 桌面上做，排到再下一版。手机底部导航放 4 个页面加 1 个“＋”：今天、日历、待办、随手记；隐私记、生日、设置分别收进随手记、日历和头像入口。桌面改用左侧栏。

## 1. 视觉方向

### A 便当演进（推荐，默认皮肤）
- **配色**
  - 浅色：底 #E8E9EC，面板 #FFFFFF，主文字 #121316，次文字 #5B5F66，主按钮柠檬黄 #F2DF4A（上面用黑字），逾期红 #C8302A。
  - 深色：底 #0B0C0E，面板 #17181B，文字 #F2F3F5。
  - 项目色保持不变：黄 #F2E07A、蓝 #8FD0F0、绿 #8AD49A、粉 #FBDCDC、紫 #C9B8F5、珊瑚 #F6A48C。色块上一律用深色字。
- **字体**：数字用 Manrope，中文用 Noto Sans SC，韩文补 Pretendard（或 Noto Sans KR）。字号阶梯 12/14/16/20/28/48 不变。
- **圆角**：面板 24，卡片 16，按钮和胶囊做成全圆。
- **质感**：纯色面板，不加边框，只在弹出层下面加一层淡阴影。
- **动效**：弹簧动画（阻尼 0.8），时长 200~280 ms。保留红色“播放头”这个记忆点。
- **iPhone**：浮动黑色胶囊导航，加大圆角卡片。
- **Windows**：三栏便当格，窗口外框用 Win11 的 Mica 材质（系统自带的半透明窗口底色）。
- **理由**：已经做成，用户认可，两种颜色模式下对比度都达标，成本最低。

### B 雾玻璃（只做桌面，下下版）
- **配色**：
  - 底色：从 #EEF1F6 到 #F6E9EE 的极淡渐变；
  - 面板：白色 62% 透明加 24 px 模糊，边缘一条 1 px 的白色描边；
  - 文字和强调色：文字 #1B1F2A，唯一的强调色是靛蓝 #4F5BD5。
- **字体和圆角**：同 A；圆角放大到 28。
- **动效**：轻视差和柔和阴影。
- **iPhone**：玻璃只用在导航条和弹出层，列表卡片保持实色。系统打开“降低透明度”或者机型较旧时，自动换成实色 #F4F5F8。
- **Windows**：直接用系统的 Acrylic/Mica 材质，性能最好。
- **风险**：
  - 浅灰字放在玻璃上很容易低于 4.5:1 的对比度；
  - 手机上大面积模糊会掉帧、费电；
  - 和照片、马卡龙色块叠在一起会显得脏。

### C 夜荧光（推荐作为第二套皮肤）
- **配色**：
  - 底和面板：底 #0E0F0C，面板 #1A1C17，分隔线 #2A2D25；
  - 文字：主文字 #EDEFE6，次文字 #9A9E90；
  - 强调色：荧光黄绿 #C8F25A，上面用 #0E0F0C 黑字；
  - 项目色：统一降低饱和度，例如蓝改成 #6FA9C4。
- **用色规则**：荧光色只用在主按钮、当前项、今天这一格这三类地方，不拿来写正文。
- **字体**：同 A；数字可以改用等宽的 JetBrains Mono，做出“仪表感”。
- **圆角和质感**：圆角 14/10，比 A 更利落；用细线条加大量留白。
- **动效**：当前项亮起时有一层微光，不做大幅位移。
- **iPhone**：OLED 屏上的纯黑底省电。
- **Windows**：适合晚上工作。
- **说明**：这套只有深色，不出浅色版；需要浅色时自动回到 A 的浅色。

### 皮肤系统怎么共用组件
1. **三层设置**：基础色板 → 语义变量 → 组件。
   - 语义变量包括：底色、面板、浮起面板、主文字、次文字、强调色、强调色上的文字、危险色、项目色 1~6、圆角大中小、材质（实色或玻璃）、阴影、动效参数。
   - 组件只读语义变量，不直接写任何具体色值。
2. **一套皮肤就是一份变量表**，分浅色、深色两份（C 只有深色）。新增皮肤不用改组件。
3. **项目色的“色相”在各皮肤里固定**：NEOX 永远是黄，各皮肤只调深浅，用户的认知不会乱。
4. **上线前自动检查**：每份变量表都要跑一遍对比度检查，正文 ≥ 4.5:1，大字和图标 ≥ 3:1。“玻璃”材质要带一个实色后备值。

## 2. 信息架构与导航

### 放在哪里
| 内容 | 位置 |
|---|---|
| 日程 | 改名为“日历”，页内用胶囊切换：周 / 月 / 生日 |
| 隐私记 | 随手记顶部一个带锁的“隐私”文件夹 |
| 生日 | 显示在日历的“生日”分页、月历格子里，以及“今天”页的提醒卡 |
| 设置 | “今天”页右上角的头像；原来的深浅色按钮也挪进设置 |

### 手机（底部最多 4 个页面加 1 个“＋”）
```
┌───────────────────────────┐
│  页面内容…                │
│ ╭今天╮ 日历  待办  随手记 (＋)│ ← 黑色胶囊，选中的那项显示文字
└───────────────────────────┘
```
- 选中项显示“图标＋文字”，其余只显示图标，所以 390 宽的屏幕也放得下。
- “＋”按页面不同而不同：在随手记页直接新建随手记，其他页弹出“记一件事”。

### 桌面（左侧栏，三档宽度）
```
┌────────┬──────────────────────────────┐
│ 今天   │                              │
│ 日历   │   主区域（各页自己排版）     │
│ 待办   │                              │
│ 随手记 │                              │
│ 隐私记 │                              │
│ 生日   │                              │
│ ─────  │                              │
│ 设置   │                     (＋)     │
└────────┴──────────────────────────────┘
```
- 窗口 ≥ 1200 px：侧栏宽 220，“今天”页保持现在的三栏。
- 900~1200 px：侧栏只剩图标（宽 72），主区域改成两栏。
- < 640 px：切换成手机布局。
- 快捷键：Ctrl+N 新建，Ctrl+K 全局搜索，Ctrl+L 立即锁上隐私记。

## 3. 关键页面

### 随手记列表（两列瀑布流）
```
[搜索框：搜全文、分类、图中文字]
分类胶囊：全部 · 工作 · 灵感 · 生活 · 购物 …（AI 生成）
[锁] 隐私 3 条  ›
┌──────┐┌──────┐
│[图片]││明天去 │  ← 没有标题：取正文前两行加粗当标题，
│标题  ││老市场 │     字号比真标题小一级
│工作·10/24│ …   │
└──────┘└──────┘
```
- 有图：图放在卡片顶部，最大 16:10，角上标“+2”表示还有几张。
- 没有图：只显示文字。
- 分类显示成卡片底部的小胶囊。

### 随手记编辑器（全屏）
```
‹ 返回      [分类：灵感 ▾]   [图片] ⋯
标题（可不填）
正文……
[图片]（点开大图）
```
- **AI 分类**：保存后 1 秒内，分类胶囊从“分类中…”变成结果，带一圈淡闪。
  - 点开就能改，改完标上“已手动”，AI 不再覆盖这条。
  - 拿不准的时候显示“未分类”，不乱猜。
- **桌面版**：左边列表、右边编辑器，两栏并排。

### 隐私记
- **首次进入**：
  1. 说明“密码只存在这台设备，忘记无法找回”；
  2. 输入 6 位数字密码，再输一遍确认；
  3. 问一句“同时用面容 ID / Windows Hello 吗？”。
- **解锁**：模糊的背景加锁的图标，下面是数字键盘或面容 ID 按钮。
  - 连续输错 5 次，等 1 分钟再试；
  - 输错时圆点左右抖一下，并震动一下。
- **自动上锁**：切到后台或离开 1 分钟就锁上。系统多任务的预览画面里显示占位图，不露内容。
- **隐私记不出现在**：全局搜索、“今天”页、通知内容。

### 月历
```
‹ 2026 年 10 月 ›          [今天]
一   二   三   四   五   六   日
19   20   21   22   23  (24)  25
初九 初十 十一 十二 霜降 十四 十五
••   •         ▔    ••+2 [蛋糕]
```
- **每格内容**：
  - 阳历日期放最大；
  - 农历放在下面，用小号次要文字，节气和节日改成强调色；
  - 最下面一行最多 3 个项目色圆点，超出的写“+N”；
  - 有生日的格子显示一个小蛋糕图标。
- **点一天**：下面展开当天的日程、待办和生日。
- **桌面版**：格子够大，直接写出前两条标题。
- **韩国节日**：在设置里可开可关。

### 生日
列表（分页标题：生日）：
```
妈妈   阴历八月十五 · 今年 9/25   [3 天]
老王   阳历 11/02                [9 天]
```
- 倒数天数放在右边，用大号数字：7 天以内用强调色，当天显示“今天”。
- **新建**：先填姓名，再选“阳历 / 阴历”，然后选月和日（阴历要能选闰月）。
- 新建页最后一行写明“会在提前 7 天、前 1 天各提醒一次”，不用再单独设置。

### 设置（分组列表）
- **外观**：皮肤三选一（显示缩略预览）、浅色 / 深色 / 跟随系统、字号
- **提醒**：通知权限、生日提醒时间（默认上午 9:00）
- **隐私**：改密码、面容 ID / Windows Hello、自动上锁时间
- **日历**：显示农历、韩国节日、一周从周一开始
- **桌面版**：开机自动运行、关闭窗口时缩到系统托盘、全局快捷键
- **账号**：登录状态、导出备份、退出登录
- **关于**

### 登录页
- 页面构成：中间是 App 名字和一句话介绍；下面是“用 Apple 登录”“用 Google 登录”，再下面是邮箱验证码登录。
- 不放大图和轮播，第一次打开 2 秒内就能点。
- 桌面版是一个居中的小窗（480×600）。

## 4. 参考里借鉴什么、不借鉴什么
| 参考 | 借鉴 | 不借鉴 |
|---|---|---|
| KENOTEX | 月历加农历、节气这种排法；全屏想法页；全局搜索高亮；纪念日倒数 | 太小的灰字（深色下对比度不足）；甘特图和习惯打卡（这次没有这个需求） |
| 磨砂玻璃（电脑端） | Win11 的窗口材质；登录小窗的布局 | 大面积玻璃卡片，信息密度太低 |
| AI 待办助手 | AI 结果用“卡片 + 一步一步确认”的方式呈现 | 粉蓝渐变铺满全屏，和马卡龙色块冲突 |
| 健康仪表盘 | 渐变色块，可以给生日卡加一点氛围 | 点阵数字，可读性差 |
| B 端健身界面 | 侧栏的图标和文字排法；一个页面只用一个强调色 | 大号英文标题的装饰感 |

## 5. 纰漏和补充
- **中韩混排**：字体按顺序找字：Manrope → Pretendard → Noto Sans SC，韩文不会掉到系统默认字体。韩文比中文长 30% 左右，按钮要用弹性宽度。
- **iPhone 安全区**：导航条要避开底部的横条；灵动岛区域不放按钮。键盘弹出时，编辑器的工具栏跟着贴在键盘上方。
- **桌面窗口**：最小 400×600；每档布局都要截图验收；在 125% 和 150% 系统缩放下文字不能发虚。
- **空状态**：每个页面都要有一句话加一个按钮，例如“还没有随手记，写下第一条”。不用插画。
- **深色下的图片**：深色模式下照片亮度压到 90%，并加 1 px 描边；白底截图加一层浅灰底衬。
- **无障碍**：
  - 点击区域 ≥ 44 px；
  - 跟随系统字号放大到 130% 时版面不能乱；
  - 不能只靠颜色区分（逾期要同时有文字说明）；
  - 读屏软件要能念出“农历八月十五”；
  - 开了“减弱动态效果”就关掉弹簧动画。
- **编辑**：所有记录统一用“点开即编辑 + 删除后可撤销”。

## 6. 设计流程建议
1. **第 1 周**：出导航和信息架构的灰稿（只用黑白灰），手机和桌面各一套，先确认东西放在哪。
2. **第 2 周**：出 6 个关键页面的高保真稿，先做皮肤 A，浅色和深色都要；同时把变量表定下来。
3. **第 3 周**：用同一套组件换上皮肤 C，验证换皮肤不用改组件。
4. **评审**：每一轮都要：
   - 在 iPhone 实机和 Win11 上截图（含 150% 缩放）；
   - 跑对比度检查；
   - 请一位没用过的人走一遍“建随手记、上锁、加生日”，记下卡住的地方。

## 需要产品负责人决定的事项
1. **默认皮肤**：推荐 A（便当演进）。
2. **下一版做几套皮肤**：推荐 A + C 两套；玻璃风 B 下下版只在桌面做。
3. **手机底部放哪 4 个**：推荐今天、日历、待办、随手记。
4. **隐私记放在哪**：推荐作为随手记里的加锁文件夹，而不是单独一个底部入口（入口越少越隐蔽）。
5. **隐私记密码形式**：推荐 6 位数字，加上面容 ID / Windows Hello。密码忘了就无法找回，需要你接受这一点。
6. **登录方式**：推荐 Apple、Google 加邮箱验证码。
7. **月历上显示哪些节日**：推荐默认显示农历和中国节日，韩国节日在设置里开启。
