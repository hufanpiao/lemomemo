## 一、四人一致的结论

| 议题 | 结论 |
|---|---|
| 登录现在做还是以后做 | **和独立软件一起做，不要往后拖。** 理由：数据一上服务器，就得靠登录来限定“只能本人读写”。以后再补，要给每张表加“这条数据属于谁”、重写权限、再搬一次数据，返工约 3–5 人日，现在做只多约 1 人日 |
| 登录方式 | **邮箱 6 位验证码。** 不用“点邮件里的链接登录”，因为在 iPhone 上会跳到 Safari，进不了主屏幕 App |
| 网页后台管理页面 | **不做。** 一个人用，Supabase 自带的控制台就够了；软件里另做“设置 → 数据与备份”。做后台反而多出一个高权限入口 |
| 隐私记 | **在本机加密，服务器只存看不懂的密文；首次设密码时给一份恢复码。** 忘了密码又丢了恢复码，内容就永久找不回。隐私记不进全局搜索、不交给 AI、不推送、不写日志 |
| AI 分类 | 由服务器端函数调用 Claude 小模型，密钥不放在软件里。AI 只能从已有分类里选，用户手动改过的不再改，拿不准就标“未分类”。设置里做开关，默认开。每月费用不到 1 美元（未按最新价格核实） |
| 手机端 | **iPhone 用 Safari“添加到主屏幕”（PWA），不用付苹果的费用。** 推送要 iOS 16.4 以上，并且要从主屏幕图标打开 |
| 电脑端 | **用 Tauri 打包成 exe**（安装包约 10 MB），开机自启用它的插件。不签名的话，第一次运行时 Windows 会提示，点“仍要运行”就行。**更新包必须签名** |
| 后端 | **Supabase 首尔节点**：登录、数据库、图片、定时推送都在里面，免费版就能起步 |
| 底部导航 | **今天 / 日历 / 待办 / 随手记，外加“＋”。** 日程改名“日历”，页内分周、月、生日；设置放右上角 |
| 参考 App 学什么 | 学：月历（带农历、节气）、纪念日和倒数日、全局搜索高亮、节假日、“稍后”。不学：甘特图、农历宜忌、AI 多步代办、大面积粉蓝渐变 |
| 搬家后最容易漏的 | ① 在聊天里让 Claude 代记会失效，要单独开一个“只能新增”的接口给 Claude；② 每日备份、提醒这两个 Claude 定时任务要改到新服务器 |

## 二、意见不一致的地方，以及主持人的处理

| 议题 | 各方意见 | 主持人建议 |
|---|---|---|
| 版本顺序 | 产品经理：先出 3.1.0，在现有 claude.ai 版上加月历、随手记（纯文字）、生日，几天内就能用；再出 4.0.0 独立软件。架构师：直接做 4.0.0，先把基础搭好 | **先出 3.1.0。** 4.0.0 要等你注册 Supabase、买域名，这些只能你本人操作；3.1.0 不用等，你同时去准备账号。数据层已经做成可以替换，到时多搬两个集合就行。图片和隐私记要有自己的服务器才能做好，所以放进 4.x |
| 隐私记密码 | 产品经理、UI：6 位数字。安全审查员：8 位以上 | **至少 8 位，字母、数字都行。** 内容加密以后，数据库一旦泄露，别人可以离线一个个试密码：6 位数字只有 100 万种组合，很快就能试完，8 位以上才算真正的防线。电脑上可以再加 Windows Hello 快速解锁；iPhone 网页版能不能用 Face ID 还没核实，先只用密码 |
| 登录方式加不加 Apple、Google | UI 建议 Apple + Google + 邮箱；安全审查员建议邮箱 + Apple | **只用邮箱验证码。** 核实结果：网页上用 Apple 登录，需要付费的苹果开发者账号（99 美元/年）。Google 登录要另外配置，一个人用意义不大。以后上 App Store 时再加 |
| 自动上锁时间 | 1 分钟 / 3 分钟 / 5 分钟 | **切到后台立即上锁，3 分钟不操作也上锁**，时间可以在设置里改 |
| 生日推送显示不显示名字 | 安全审查员：默认不显示 | **默认写“今天有 1 位朋友生日”，设置里可以改成显示名字。** 推送内容会经过苹果服务器，也会显示在锁屏上 |
| 节假日 | UI：默认显示中国节日，韩国节日要自己开；产品经理：两国都显示 | **两国都显示，可以分别关掉**（你常在韩国） |
| exe 哪一版做 | 产品经理：4.1.0；架构师：4.3.0 | **4.1.0。** 4.0.0 先用 Edge 把网页装成应用，同样能开机启动 |
| 旧版 claude.ai 保留多久 | 2 周 / 30 天 | **只读保留 30 天，然后下线** |
| 功能文档 | 产品经理：在线文档为正本；架构师：项目里的 Markdown | **在线文档为正本**（iPhone 上能看、能改），每次发版在 `docs/11-功能说明/` 存一份快照。每个功能固定写 6 段，最后一段“演示要点”拼起来就是视频脚本 |

## 三、回答用户的四个疑问

1. **数据怎么分类**：
   - 你看到的是 5 类：日程（有时间）、待办（能打勾）、随手记（没时间，可带图）、隐私记（上锁的随手记）、生日和纪念日（每年一次）。
   - 随手记可以一键转成待办或日程，原来那条留着并标“已转”。
   - 日程和待办用“项目”分组，随手记用“分类”，两套暂时分开。
   - 数据库里共 9 张表：日程、待办、随手记（隐私记也在这张表里）、生日、分类、图片、设置、推送订阅、日志。每张表都带“属于谁”和“最近删除”字段。
2. **软件架构**：
   - iPhone、网页、电脑 exe 共用一套前端，现有代码约 60% 能直接用；
   - 网页文件放在 Cloudflare Pages，自带 HTTPS；
   - 后端用 Supabase 首尔节点；
   - AI 分类和推送由服务器端函数负责；
   - 每分钟扫一次到点的提醒，用 Web Push 推到手机和电脑。
3. **要不要网页后台**：不要（见上）。
4. **怎么发布**：
   - 网页和 PWA：发到预览地址测试，通过后切到正式地址；用户打开时提示“有新版本，点击刷新”。
   - exe：自动打包，内置自动更新。
   - 版本号规则：大改（换平台、要搬数据）升第一位；新功能升第二位；修问题升第三位，比如 3.0.1。
   - 每次发版照旧：先备份，再评审、测试，最后冻结存档。

## 四、建议的版本切分

| 版本 | 内容 | 前提 |
|---|---|---|
| 3.0.1 | 已完成的待办和过去的日程也能编辑；写出功能文档初稿（覆盖 v3 全部功能） | 无 |
| 3.1.0 | 月历（带农历、节假日）；随手记（纯文字，有 AI 分类、查找，可转待办）；生日和纪念日（阴历和阳历，提前 7 天、前一天各提醒一次）；全局搜索；最近删除也覆盖新类型 | AI 分类和生日推送要靠 Claude 定时任务，需要你同意建任务 |
| 4.0.0 | 独立软件：登录、Supabase、iPhone 和电脑都能安装、真推送、从 claude.ai 搬数据、设置页（含皮肤和深浅色）、随手记插图、离线查看、Claude 代记接口 | 你注册 Supabase、买域名，并决定代码放不放 GitHub |
| 4.1.0 | 隐私记（加密、恢复码）；Tauri exe（开机自启、托盘、自动更新） | — |
| 4.2.0 | 倒数日、简单格式、重复事项，第二套皮肤 | — |

**皮肤**：
- 默认是 A“便当演进”：现在的风格，加上韩文字体；电脑窗口用 Win11 的半透明材质。
- 第二套 C“夜荧光”：深色，荧光黄绿只用在主按钮、当前项和“今天”。
- 磨砂玻璃 B 以后只在电脑上做：手机上大面积模糊会卡、费电，玻璃上的浅灰字也看不清。
- 皮肤做成“一份变量表换一套”，组件不用改；每套上线前自动检查对比度。

## 五、补充的纰漏

- **4.0.0 有几件事只能你本人做**：注册 Supabase、买域名（约 10–15 美元/年）、决定代码要不要上传 GitHub（现在的规则是不经同意不上传；不传也行，改成从本机直接发布）。
- **费用**：
  - 免费版能起步。Supabase 免费版 7 天没人用会暂停，数据不丢；正式使用后建议升级 Pro，25 美元/月。
  - AI 每月不到 1 美元。
  - 以上价格是第三方汇总，官网没核实。
- **iPhone 推送不如原生 App 稳**：软件里做一个“推送自检”按钮；4.0.0 必须在真机上验收。实在不稳，再考虑每年 99 美元上 TestFlight。
- **多设备同时改同一条**：以最后一次保存为准，并提示“已在另一台设备上改过”；随手记冲突时两份都留。
- **图片**：上传前在本机压缩，并去掉照片里的定位信息；存到私有空间，只用 10 分钟有效的链接访问。
- **时区**：你常在中韩之间来回，设置里做“跟随手机 / 固定首尔”，提醒时间不能错。
- **合规**：自己用基本不受韩国个人信息保护法约束。以后给别人用，就要有隐私政策、取得同意，并告知 AI 调用会把数据传到美国。
- **设置页**（★ 你提的，☆ 补充的）：
  - 账号：退出登录☆、已登录设备☆；
  - 外观：皮肤★、深浅色☆、字号☆；
  - 日历：一周从周几开始☆、农历☆、节假日☆；
  - 提醒：总开关☆、默认时间☆、免打扰☆、提示音☆、未来 7 天的提醒清单☆；
  - 随手记：分类管理☆、AI 开关☆；
  - 隐私记：改密码☆、恢复码☆、自动上锁时间☆；
  - 时区☆；
  - 数据：导出、导入、最近删除、最后备份时间☆；
  - 桌面：开机自启★、关窗缩到托盘☆、快捷键呼出“记一件事”☆；
  - 关于：版本号、更新内容、说明书入口☆。
