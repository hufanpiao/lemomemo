# 第六轮 下一版规划会：产品经理方案

日期 2026-10-24｜依据：README、CHANGELOG、需求记录 R-19~R-39、路线图、数据字典、参考截帧

## 结论（先看这里）
1. **分三步走**：3.1.0 先在现有 claude.ai 版上加“月历 + 随手记（纯文字）+ 生日”，几天内就能用上；4.0.0 再做独立软件（登录、手机和电脑都能装、真推送、图片）；4.1.0 做隐私记和桌面 exe。
2. **登录现在定、跟 4.0.0 一起做**。以后再补就得再搬一次数据。不需要单独的网页后台。
3. **底部导航从 3 个改成 4 个**：今天 / 日历 / 待办 / 随手记。设置放在右上角齿轮里。
4. **参考 App 只学 4 样**：月历、纪念日（和生日放一起）、节假日、“稍后”。甘特图、宜忌、AI 多步助手不做。
5. **功能文档用在线文档写和改**，每次发版存一份 Markdown 快照到项目里。每个功能都按“演示脚本”的格式写。
6. **最容易漏的一点**：搬离 claude.ai 以后，“在聊天里让 Claude 代记”就用不了了，必须提前决定怎么接上。

## 一、逐条澄清（括号里是推荐默认）
| 需求 | 开发前必须定的点 |
|---|---|
| 随手记 | 和待办的区别：待办能打勾完成，随手记不能打勾（**随手记只用来记，没有“完成”**）。首页那个一句话输入框的规则不变；识别结果上加“日程 / 待办 / 随手记”三个选项，点一下就能换。没写标题时，用正文第一行当标题。AI 分类：**先给 6 个默认分类（工作、生活、想法、购物、学习、其他），可以改名、增加、合并**。AI 只给建议，你手动改过的它不再改。图片：**每条最多 9 张，自动压缩到 1600 像素、单张约 300 KB，iPhone 的 HEIC 格式自动转换**；图片要等 4.0.0 有了自己的存储才能做 |
| 隐私记 | **6 位数字密码，可以开 Face ID；离开 App 或 1 分钟不操作就自动上锁**。忘了密码：内容是加密存的，所以第一次设密码时会给你一个**恢复码**，务必存好；恢复码也丢了，内容就找不回。还有四条：不进全局搜索（解锁后才能搜）、不交给 AI 分类、通知里不显示内容、导出时要你另外勾选 |
| 登录 | **用邮箱验证码登录（6 位数字）**。不用“点邮件里的链接登录”，因为在 iPhone 上点链接会跳到 Safari，进不了已装好的 App。**登录一次保持 90 天**，可以在设置里看哪些设备登录过 |
| 生日记 | 推送时间：**早上 9:00（首尔时间），可以改**；每条可以单独改提醒（沿用 R-19）。阴历闰月：**按当年的正常月份过**。阴历三十那年没有三十：**按廿九算**。2 月 29 日：**平年按 2 月 28 日算**。**显示周岁**。**纪念日放在一起做**（同样是“每年一次”，只是类别不同）。默认推两次：提前 7 天、前一天；当天要不要推，做成开关，默认关 |
| 桌面版 + 手机 | 手机：**iPhone 上“添加到主屏幕”的 PWA（像 App 一样的网页）**，暂不上 App Store（每年 99 美元，还要过审核）。电脑：4.0.0 先用 Edge 把 PWA 装成应用，4.1.0 再做真正的 exe（能开机自动运行、缩到托盘、自动更新） |
| 所有记录可编辑 | **已完成的待办和过去的日程都能编辑**；已删除的要先恢复才能编辑；**不保存修改历史** |
| 月历 | 每天底下显示小圆点（日程、待办截止、生日），点某一天，下方列出那天的事；**一周从周一开始，可以改** |
| 版本号 | 主版本.功能版本.修补版本：只修问题加第三位，加功能加第二位，换形态加第一位 |
| 网页后台 | **不做**。只有你一个人用，用 Supabase 自带的管理台维护就够了。以后给别人用了再考虑 |
| 怎么发布 | PWA：服务器更新后，打开就是新版。exe：安装包自带自动更新。每版仍按现有流程，先备份、再冻结存档 |

## 二、数据分类（你看到的东西）
| 类型 | 是什么 | 在哪看 |
|---|---|---|
| 日程 | 某天某个时间要发生的事 | 今天、日历 |
| 待办 | 要做完、能打勾的事 | 今天、待办 |
| 随手记 | 没有时间的文字和图片 | 随手记 |
| 隐私记 | 上锁的随手记 | 随手记页里的“锁”入口 |
| 生日 / 纪念日 | 每年一次 | 日历；今天页显示“7 天内的生日” |

能这样互相转换：随手记 → 待办或日程（**一键转换，原来那条留着，并标上“已转”**）；待办 ↔ 日程（已经能做）；待办 → 随手记；随手记 ↔ 隐私记（要输入密码）。日程和待办的“项目”和随手记的“分类”是两套东西，**暂时分开**。

## 三、设置页（★你提的，☆我补的）
- **账号**：登录邮箱、退出登录☆、已登录的设备☆（手机丢了可以把它踢下线）
- **外观**：皮肤★、深浅色（从顶部按钮移进来）☆、字号☆（手机上看得清）
- **日历**：一周从哪天开始☆、显示农历☆（阴历生日要用）、显示节假日（韩国 / 中国）☆
- **提醒**：推送总开关☆、默认提醒时间（日程 / 待办 / 生日几点）☆、免打扰时段☆（晚上别吵）、提示音☆

- **时区**：跟随手机 / 固定首尔☆（你在中韩之间来回跑，提醒不能差一个小时）
- **数据**：导出、导入☆、最近删除、最后一次备份的时间☆
- **桌面版**：开机自动运行★、关窗口时缩到托盘☆、用快捷键呼出“记一件事”☆

## 四、参考 App 借鉴（做减法）
| 功能 | 结论 | 理由 |
|---|---|---|
| 月历 | 3.1.0 做 | 你点名要的 |
| 纪念日 | 3.1.0 做 | 和生日用同一套规则，几乎不加工作量 |
| 全局搜索（覆盖所有类型） | 3.1.0 做 | 有了随手记就必须有 |
| “稍后 / 拉入今天” | 4.0.0 做 | 现在已经有“没赶上”区，在它上面扩展就行 |
| 法定假日与调休（韩国 + 中国） | 4.2.0 | 有用，但每年都要更新数据 |
| 倒数日 | 4.2.0 | 可以用纪念日顺带做 |
| 磨砂玻璃 | 作为一套皮肤候选 | 放进皮肤里，不改整体界面 |
| 随手记里的简单格式（加粗、列表） | 4.2.0 | 先只支持纯文字 |
| 习惯打卡、日报、AI 拆解任务 | 以后再说 | 你没提，先看用得多不多 |
| Focus、时间线 | 不做 | 现在的“今天”页和时间轴已经有了 |
| 甘特图、农历宜忌、AI 多步代办 | 不做 | 一个人用不上，做了反而让界面变乱 |

## 五、功能文档（需求 6）
- **形式**：用在线文档当正本，你在 iPhone 和电脑上都能看、能改；每次发版存一份 Markdown 快照到 `docs/11-功能说明/`，和版本号对应。
- **每个功能固定 6 段**：这是什么 / 在哪里 / 怎么用（编号步骤）/ 规则和边界 / 截图位置 / 演示要点（一句旁白 + 一个镜头）。
  - 拍视频时，把“演示要点”一节直接拼起来就是脚本；
  - 做说明书时，用前 5 段。
- **目录**：00 三分钟上手｜01 安装与登录｜02 一句话记录（中文 / 韩文）｜03 今天｜04 日历（周 / 月）｜05 待办｜06 随手记｜07 隐私记｜08 生日与纪念日｜09 提醒与推送｜10 搜索｜11 最近删除｜12 设置（逐项）｜13 导入、导出与备份｜14 常见问题｜附录：功能总表（编号、版本、状态）、名词解释、更新记录。

## 六、版本切分
| 版本 | 范围 | 验收标准 |
|---|---|---|
| **3.0.1** | 改成新的版本号格式；建好功能文档初稿（写 v3 现有的功能）；已完成和过去的记录也能编辑 | 文档覆盖 v3 全部功能；已完成的待办能改、能保存 |
| **3.1.0**（价值最大，先做） | 月历；随手记（文字、AI 分类、查找、转成待办）；生日和纪念日（阴历 / 阳历，暂时由 Claude 定时推送）；全局搜索；最近删除也包括新类型 | 用 2026–2028 年的闰月、2 月 29 日、阴历三十测过；7 天前和前一天各推一次，不重复；搜索能找到所有类型 |
| **4.0.0** | 独立软件：登录、Supabase 首尔节点、iPhone 和电脑都能装、真推送、从 claude.ai 搬数据、设置页、皮肤、随手记插图片、离线能看 | 搬家后条数一条不少；页面关着也能按时收到推送（误差 1 分钟内）；断网能打开看到数据 |
| **4.1.0** | 隐私记；桌面 exe（开机自动运行、托盘、自动更新） | 自动上锁、Face ID、恢复码都能用；隐私记不出现在搜索、推送和 AI 里 |
| **4.2.0** | 节假日、倒数日、简单格式、重复事项 | 按当时再定 |

3.1.0 先做，理由是：最快能用上新东西，而且数据层已经做成了可替换的结构，4.0.0 搬家时只是多搬几个集合。隐私记不在 claude.ai 版上做，因为那里没法真正加密。

## 七、补充建议
1. **Claude 代记怎么接上**：搬家后要给 Claude 留一个能写入的接口；不然你在聊天里“帮我记一下”就失效了。每日备份和提醒这两个定时任务也要改到新服务器。
2. **导入**：能导入 v3 导出的 JSON 文件，这同时也是搬家用的工具。
3. **多设备同时改同一条**：以最后一次保存为准，并提示“已在另一台设备上改过”。
4. **离线**：没网时能看，也能先记下来，联网后自动同步。
5. **提醒统一入口**：在设置里列出“未来 7 天会响的提醒”，可以集中关掉。
6. **最近删除也包括新类型**：随手记（连同图片）、生日也保留 30 天。
7. **旧版过渡**：搬家后 claude.ai 版只读保留 30 天，再停用。
