## 一句话评价

| 版本 | 长处 | 短处 |
|---|---|---|
| 甲 | 稳，好认；设置页最完整，每组直接显示当前值，还有推送自检、AI 用量、Claude 代记钥匙 | 今天页卡片太多，同一件事出现两次；随手记两列瀑布流，没图的时候空 |
| 乙 | 最省操作：随手记像发消息，底部常驻输入框；提示条写明“放进了哪里”，拆错了能一键合并；登录注册一步完成；空状态是“点一句就试” | 手机周视图的横条太小，看不清写的是什么；元素多，显得有点挤 |
| 丙 | **审美最好**：留白、字号、层次最干净。今天页顶部是**一句话**：“正在开 NEOX 横版对片，14:30 结束。之后空 30 分钟，先把没赶上的……补上？”，旁边有“先做这件 / 换一件”；**唯一画了提醒响起时**（锁屏推送 ＋ 应用内整页提醒）；**唯一画了韩文界面**；隐私记解锁做得最好 | 电脑快捷键用了 Ctrl+Shift+空格（和 Windows 切换输入法冲突）；登录分成 3 步，比乙多 |

**结论：以丙为骨架（视觉语言、今天页、提醒、日历、隐私记、录音），随手记、提示条、搜索、登录、空状态用乙，设置页和隐私记入口用甲。**

## 逐屏取用

| 画面 | 用哪版 | 具体取什么 |
|---|---|---|
| 整体视觉 | **丙** | 留白和字号层次；底部导航用玻璃质感的“图标 ＋ 文字”胶囊；列表底部留足空白，不被导航挡住 |
| 今天 | **丙**，加上甲的一处 | 丙：顶部一句话、“先做这件 / 换一件”；已过去的折成一行；“现在”线；空档提示。甲：纪念日在当天和前一天升级成大卡 |
| 提醒响起时 | **丙**（只有丙画了） | 锁屏推送直接写标题和名字；点开进入整页提醒，按钮是“知道了 / 10 分钟后 / 开始时再提醒”；电脑用 Windows 通知，自带按钮；手机和电脑都会响，一边点了，另一边自动消失 |
| 日历·周（手机） | **丙** | 7 条泳道，有时间刻度，下面接选中那天的完整列表。乙的横条看不清，丙加了刻度和下方列表，解决了这个问题 |
| 日历·周（电脑） | **丙** | 加一行“全天”放截止和纪念日；时间格加高，短日程的字不会被切掉 |
| 日历·月 | **丙**，加上乙的一条规则 | 丙：每格放农历和色条，“休”实心代表中国、空心代表韩国，放在右下角；电脑点某天弹出清单，标题能显示两行。乙：格子里那一行文字的优先级是“节假日 > 节气 > 农历”，初一显示月份 |
| 纪念日列表 | **乙** | 顶部大卡显示“最近一个”，下面按剩余天数排序；电脑版详情列出“接下来 3 次的公历日期” |
| 新建纪念日 | **丙** | 只有那一年真有闰月，月份滚轮里才出现闰月；没有闰月的年份按哪天过，写清楚并且可以改；不知道出生年份就不显示岁数 |
| 待办 | **乙**（手机）＋ **丙**（电脑） | 乙：右滑完成，左滑推迟或删除。丙：电脑分两栏，配键盘快捷键（空格完成，T 改到今天，M 改到明天） |
| 随手记列表 | **乙**，加上丙、甲各一处 | 乙：单列时间流，底部常驻输入框，手指够得着。丙：顶部分类胶囊和“要合并吗”提示。甲：隐私记入口常驻在列表顶部一行 |
| 随手记编辑器、转成待办或日程 | **乙 ＋ 丙** | 乙：转换前先预览，清单有几项就拆成几条。丙：键盘上方有“转待办 / 转日程”，转换弹层用磨砂玻璃 |
| 隐私记 | **丙** | Face ID 解锁卡用玻璃质感；解锁后右上角有“现在上锁”；电脑用 Windows Hello |
| 长按“＋”录音 | **丙** | 识别出的文字从声音条往上堆，离手指近；每说完一句就标出会存成日程还是待办；左滑取消，上滑锁定 |
| 保存后的提示条 | **乙 ＋ 丙** | 乙：写明“已放进今天的日程 · 归到 SignPlex”，拆错了可以一键合并。丙：存进去的那一页，导航标签上显示“+1”，每条都能单独撤销 |
| 全局搜索 | **乙** | 能搜到语音原话；NEOX 和 네옥스 当成同一个词 |
| 设置 | **甲** 为主，补上丙的几项 | 甲的完整分组和“直接显示当前值”。丙补的：界面语言、AI 今天还能用几次的进度条、手机电脑同时在线时提醒在哪边响 |
| 登录、注册 | **乙**，加上丙一处 | 乙：一个流程，先填邮箱，是新邮箱才多出一栏邀请码。丙：注册时可以选界面语言（中文 / 한국어） |
| 空状态 | **乙 ＋ 丙** | 乙：今天页给几句例句，点一句就真的记下。丙：没有日程时，提示把“没定时间”的待办放到今天 |
| 断网 | **丙** | — |
| 韩文界面 | **丙**（只有丙画了） | 韩文按词换行（keep-all）；设置项的值过长时换到下一行，不截断 |
| 电脑整体 | **乙 ＋ 丙 ＋ 甲** | 乙：右侧常驻编辑栏。丙：顶部常驻“记一笔”输入栏。甲：左侧栏分三档宽度 |
| 电脑全局快捷键 | **乙** | 按住 Ctrl+Alt+空格说话；Ctrl+Shift 在 Windows 上用来切换输入法，会冲突 |

## 三版都还没有、定稿时要补的
1. 项目颜色在“现在”这一行、时间线、月历色条上的用法：等出皮肤时定。
2. 提醒同时来好几条时，整页提醒怎么切到下一条：丙画了“下一条”，还要补叠了 3 条以上的样子。
3. 韩文界面要补录音、提示条、设置这三处的长文字版本。
4. 今天页那句话的拼句规则要写成文档：先说什么、后说什么，什么情况下换话术。交给 AI 识别评测员做测试用例。
