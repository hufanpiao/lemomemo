## 1. 一句话：这个 App 是干什么的

**一个把“日程、待办、纪念日（含阴历生日）、随手记”放在一起的手机记事本：按住“+”说一句话或点一下打一句，它自动拆成几条、分好类，到点在 iPhone 和电脑上提醒你。**

## 3. 六件事怎么做 + 卡在哪

### (a) 记“明天下午三点开会”
- **打字**：点一下右下角“+” → 弹出输入框 → 打“明天下午三点开会” → 上面预览出“开会 · 明天 10月25日 15:00” → 点“记下”（或回车）→ 底部黑条“已记下 1 条 · 撤销/展开”。**基本没卡**。
- **说话**：按住“+” → 第一次会问麦克风（p02） → 出现“准备中…”，要**等到“可以说了”再开口**（p02 右下），说“明天下午三点开会” → 松手 → “正在整理…” → 已记下。
  - 卡点 1：我习惯按下就说，第一秒会被吃掉；虽然有提示，但很容易忽略。
  - 卡点 2：“← 拖到这里锁定”不知道锁定是什么意思（锁定后可以松手继续录？），“↑ 拖到这里取消”可以理解。
  - 卡点 3：开会和“박 대리”都会说，但如果我说一半韩文一半中文，“中文识别 ›”这个小链接要不要点？点了跳去设置，录音会不会断？

### (b) 找上周记的一条笔记
- 方法 1：底部“随手记” → 列表按“今天 / 昨天 / 10月21日”分组，往下翻。
- 方法 2：右上放大镜 → 输关键词 → 点“上周”筛选 → 看“随手记”分组。
- 卡点：如果我**连关键词都想不起来**，搜索页必须先打字吗？“上周”这个筛选在没输入时能不能直接用？从截图看“上周”只在输了字以后出现（p11 右上那张也是输了字以后才有）。另外如果那条在隐私记里，要先解锁才搜得到（有提示，还好）。

### (c) 给妈妈加一个阴历生日
- 方法 1：底部“日历” → 顶部切到“纪念日” → 右上“+ 新建” → 选“生日” → 名字“妈妈生日” → 日期切“阴历” → 滚轮选年/月/日 → 保存。
- 方法 2：点“+”直接打“妈妈生日是阴历十月初八”（空状态页 p13 就给了这个例句）。
- 卡点：
  - 纪念日藏在“日历”里的第三个标签，我第一反应会去“待办”或“+”里找；还好“3 天后 김지민 生日”胶囊和“+”例句给了提示。
  - 不知道妈妈哪年出生的话，要找到“不知道出生年份”开关，在滚轮下面，能找到。
  - 截图里“新建纪念日”名字已经是“外婆生日”，像是在编辑旧的，不像是新建，会让我怀疑点错了。
  - 用“+”说话加生日，能不能自动识别成“纪念日◆”而不是“待办”？没有画面证明。

### (d) 把一条写好的笔记挪进隐私记
- 我会：随手记列表里找到那条 → **左滑** → 出现“转成待办 / 移到隐私记 / 删除” → 点“移到隐私记”。
- 卡点：
  - 我不一定会想到左滑。打开那条笔记后，详情页顶部的“···”里有没有“移到隐私记”？截图没展示 “···” 点开的样子。
  - 第一次用隐私记还没设密码时，点“移到隐私记”会不会先跳到设密码？流程没画出来。
  - 挪进去以后是不是马上就锁上、列表里那条消失？有没有“已移到隐私记 · 撤销”的提示？没看到。

### (e) 提醒响了，想 10 分钟后再提醒
- 在 App 里：顶部大卡片底下的“10 分钟后” → 黑条“15:25 再提醒你”。清楚。
- 从锁屏点通知进来：整页提醒，底部“10 分钟后”。清楚。
- 卡点：
  - **锁屏通知上没有按钮**（p05 右上），不知道长按通知能不能直接“10 分钟后”，还是必须解锁进 App。
  - **待办**的提醒没有“10 分钟后”，只有“1 小时后 / 明天再提醒”；如果我要 10 分钟后提醒一个待办，做不到。
  - 纪念日提醒的“明天再提醒”和“生成待办”是什么区别，要读小字才懂。

### (f) 第一次打开要做哪些准备
1. 用 Safari 打开 → 按引导“分享 → 添加到主屏幕”；
2. 从主屏幕图标打开 → 输入邮箱 → 发验证码；
3. 新邮箱要**朋友给的邀请码**；
4. 输入 6 位验证码（键盘上方能自动填）；
5. 第 1 步 打开通知；第 2 步 允许麦克风；第 3 步 看符号说明 → “知道了，开始用”。
- 卡点：
  - **没有邀请码就进不去**，我是自己发现这个 App 的话就卡死了。
  - “Safari 和主屏幕版的登录状态不共享”这句我得读两遍才懂：意思是别在 Safari 里登，先加到桌面再登。为什么不能直接下载 App？会怀疑它是不是正规应用。
  - 顺序上，p00 引导先说“加到主屏幕”，但登录页在 p12 才出现，我不确定在 Safari 里是否会先让我登录。
  - 设置里“测试提醒能不能收到”很有用，但不在首次引导里，我可能永远不会发现。

## 5. 第一印象打分：**7 / 10**

**加分**
- 核心动作非常简单：一个“+”，点一下打字、按住说话，边说边看到拆成几条，记下后马上能撤销，安全感强。
- 中韩双语、阴历生日、闰月处理、中韩节假日、韩文人名都考虑到了，对我这种在韩国生活的中国人非常对口。
- 提醒的按钮跟着类型变（日程/待办/纪念日），整页提醒信息很全；错过的提醒集中处理。
- 空状态给例句、出错提示都告诉“下一步怎么办”，语气友好。
- 黑白高对比、大字，看着干净。

**扣分**
- 符号和标签太多（竖条、圆圈、菱形、方块、点、•数字、刚记下、AI、语音记的），首次要背一张 9 项的符号表。
- 进门门槛高：要从 Safari 加到主屏幕、要邀请码、登录状态不共享。
- 手势规则每页不同，很多功能（移到隐私记、转成待办、推迟）藏在左滑里。
- 锁屏通知不能直接延后；待办不能 10 分钟后。
- 几处开发备注漏在画面里，显得不够成品。
- 周视图信息密度太高，第一眼看不懂。
