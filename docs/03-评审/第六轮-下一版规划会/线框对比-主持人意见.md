# 4.0.0 线框对比：主持人意见

- 日期：2026-10-24
- 方法：加载 design-critique skill；用无头 Edge 截了两份线框的手机版整页图逐屏看过，电脑版对照源码核对。
- 对象：
  - 甲：`docs/02-设计/草图-v4/线框-v4.html`（https://claude.ai/artifact/SEdvkY73waYHXQiU2Z5RvG）
  - 乙：`docs/02-设计/草图-v4/线框-v4-乙.html`（https://claude.ai/artifact/7SYbR1vKTgYX2BAXB3NShg）

## 总体印象
- **甲**：稳。沿着 v3 往前走，一屏一块卡片，信息清楚、好认。缺点是今天页卡片太多，同一件事在“下一件事”和时间轴里各出现一次，往下要滑很久。
- **乙**：更聪明，更省操作。“现在”卡带进度条，接着是“下一件”，然后是一条时间河，一眼就知道现在该做什么。随手记像发消息一样随手一句；一句话拆错了能一键合并；空状态直接教人“试一句”。这些都是真正提升好用程度的设计。缺点有两处：手机周视图的横条太小，看不清写的是什么；四种东西混在一列里，第一眼数不出待办有几件。

**推荐：以乙为骨架，几处换成甲的做法。**

## 逐屏选择

| 画面 | 选 | 理由 |
|---|---|---|
| 今天 | **乙**的“现在”卡＋时间河，加上**甲**的两样：纪念日当天和前一天升级成大卡；顶部“1 件没赶上 / 今天完成 N 件”胶囊 | 不重复显示同一件事，最快回答“现在做什么、下一件是什么”；胶囊补上乙“数不出待办有几件”的缺点 |
| 日历·周（手机） | **甲**：日期条＋按天列表 | 乙的横条在手机上只能显示两三个字，看不出是什么事 |
| 日历·周（电脑） | 两份都是 7 列时间格，差别不大；用**乙**的选中后在右栏编辑 | — |
| 日历·月（手机） | **甲**的格子（“休/韩”小标清楚，圆点＋蛋糕），加上**乙**的两条规则：一行文字的优先级是“节假日 > 节气 > 农历，初一显示月份”；把下面的列表往上拖，月历收成一行 | 甲的格子更好认，乙的规则和手势更省地方 |
| 纪念日列表 | **乙**：顶部“最近一个”大卡＋按天数排序 | 最近的那个一眼就看到 |
| 新建纪念日 | **乙**：闰月直接放进月份滚轮；底部实时显示“下一次是公历哪天、满几岁” | 选完立刻能核对换算对不对，比单独放一个闰月开关好懂 |
| 待办 | **乙**：按“没赶上 / 今天 / 明天 / 这周 / 以后 / 没定时间”分组；右滑完成，左滑推迟或删除 | 两份接近，乙的手势更顺手 |
| 随手记列表 | **乙**：单列时间流，底部常驻一行输入框；有图的显示缩略图 | 大多数随手记没有图，用两列瀑布流会空出很多地方；常驻输入框让记一句最快 |
| 随手记编辑器、转成待办或日程 | **乙**：转换前先预览，清单有几项就默认拆成几条 | 比甲多想了一层 |
| 隐私记入口 | **甲**：列表顶部常驻一行“隐私记 · 已上锁” | 你定了好用优先，常驻入口一点就进；乙把它藏在分类条最后一个，不好找 |
| 隐私记设密码、解锁 | 两份接近；**自动上锁时间按纪要定为 1 分钟**（乙写成了 5 分钟） | — |
| 长按“＋”录音 | **乙**：边说边显示“会拆成几条”的预告；左滑锁定后可以松手继续说 | 长段口述更方便，预告只用本地规则，不花额度 |
| 保存后的提示条 | **乙**：写明存到了哪里，比如“已放进今天的日程 · 归到 SignPlex”；附带“拆错了，合并成一条” | 让人放心“记对了” |
| 全局搜索 | **乙**：能搜到原话和韩文写法（NEOX ↔ 네옥스） | — |
| 设置 | **甲**：每组直接显示当前值；推送自检、AI 用量、Claude 代记钥匙都写全了 | 甲更完整；甲里“6 个分类”的写法要按“AI 自己定分类”改掉 |
| 登录、注册 | **乙**：合成一个流程，新邮箱才多出一栏“邀请码” | 少一个选择，少一步 |
| 空状态 | **乙**：今天页是一张“试一句”卡 | 新用户（包括朋友）第一次打开就会用 |
| 断网 | 两份接近，用**乙** | — |
| 电脑整体 | **乙**的“导航 ＋ 主视图 ＋ 右侧常驻编辑栏”；窗口宽时导航栏显示文字（取甲的三档宽度规则） | 常驻编辑栏改起来最快；只有图标的窄导航栏对新用户不友好 |
| 电脑全局快捷键 | **乙**：按住 Ctrl+Alt+空格 | Windows 上 Ctrl+Shift 本身就用来切换输入法，甲的 Ctrl+Shift+空格 容易冲突 |

## 两份都没做到、要补的

1. **底部导航挡住内容**：乙今天页的最后几行被导航栏盖住了。正式稿里，列表底部要留出导航栏的高度再加 16px。
2. **韩文界面**（R-48）：两份都只画了中文。下一轮至少要补今天、录音、设置三屏的韩文版，看韩文变长以后按钮会不会挤、会不会断行。
3. **提醒响起时的样子**：乙写了“‘现在’卡原地变成提醒”，但没画出来；甲也没画。这是每天都会遇到的画面，要补。
4. **项目颜色**：线框里都是灰的。加皮肤时要定下来：项目颜色在“现在”卡、时间河、月历短横线这几个地方分别怎么出现。
