# 第五轮 · UI-1 成品视觉复查（截图：docs/02-设计/成品截图-v3/）

**结论：不通过。** 改动量都不大，改完补拍几张截图复查就行。

预审意见核对：反色卡片、主题按钮、描边选中态、截止短横线、深色暖黄都已兑现。有三项截图里看不到，没法核对：①A 提醒合进“下一件事”卡片、锁形图标、最近删除（06 号截图没拍到这一块）。

按严重程度：
1. 电脑-浅/深-01：提醒卡片横跨三栏，变成一条 2000px 宽的横幅，比例完全走样。改法：放进左栏，宽度和“下一件事”卡片一致，放在它上面。
2. 手机-05、06、07：日程页和待办页顶部也挂着整张提醒卡片，占了屏幕约 1/3。改法：只在今天页显示整卡；其他页缩成一条高 56px 的黑色胶囊，点开再展开。
3. 手机-07：三条提示条叠成约 360px 高的黑色墙，缝隙里露出被切掉的半行文字。改法：同类提示合并成一条，比如“完成了 3 件 · 撤销”；条高降到 48px，和底部导航之间留出间距。
4. 手机-05、06：项目筛选胶囊折成两行，“SOIL STUDIO”单独落在第二行，又出现了上一轮修掉的折行问题。改法：单行横向滑动。
5. 手机-02：主题浮层把“1 件没赶上”切掉了半个字。改法：浮层下移，盖在提醒卡片上。
6. 手机-04：同一张编辑表里，“项目”的选中态是黑底，和其他选项的描边选中态不统一，改成描边。“推后 1 小时”是一个动作，现在和普通选项长得一样，加个箭头图标区分开。
7. 电脑-03：识别结果和“改细节”之间空了一大块，把这个空白去掉。
