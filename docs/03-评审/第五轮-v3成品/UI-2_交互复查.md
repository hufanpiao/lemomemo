**之前的意见都兑现了**：“加入”和输入框在同一行；删除单独一行，48px 高，和保存隔开约 38px；实测所有可点区域都达到 44px（“撤销”“恢复”、识别胶囊、主题按钮）；回到今天在周条下方居中，点标题也能回到今天；最近删除默认折叠，aria-expanded 正确；主题选择器三选一，按 Esc 能收起；识别胶囊可以点，点日期会展开“改细节”并定位到日期框；“选日期…”排在第一位。

**问题**
1. 【中，需实机确认】弹出层固定在底部，代码里没有处理键盘（没有 visualViewport）。在 iPhone 的 Claude App 里，键盘可能会挡住输入框下面的识别胶囊和“改细节”。“识别结果就是确认”的前提是用户能看到识别结果，建议键盘弹起时把弹出层抬到键盘上方。
2. 【中】提醒卡片在待办页和日程页也压在最上面，约 330px，把搜索框挤到了屏幕中部。建议只在今天页显示整卡，其他页缩成一行。
3. 【低】新建时“明天”和“周六”同时高亮，因为两者是同一天，但看起来像选了两项。
4. 【低】展开“改细节”后，页面上同时有两个“加入”按钮。
5. 【低】“回到今天”出现或消失时，下面的列表会跳动约 58px。
