## 一、这把钥匙是什么

- 电脑版 exe 自动更新时，会先用**公钥**核对下载的新版本是不是我们签的，签名不对就不装。**私钥**用来签名，谁拿到私钥就能给恶意更新签名，所以：
  - 私钥**不存在开发电脑上**，不放 GitHub，不贴进聊天；
  - **正式那把**：U 盘 + Google 密码管理器各一份；
  - **预览那把**：**只存 Google 密码管理器**（你 11-03 定的，Q-O7）。丢了就重新生成一把，代价是已装的预览版 exe 要重装一次。
- 私钥由签名工具用**你自己想的密码**加密。密码由签名工具自己在窗口里问你（输入时不显示），**脚本碰不到这个密码**。之后每次签名要同时用到私钥和密码。
- **⚠ 丢了不能重来（正式那把）**：正式私钥或它的密码丢了，已装的正式版 exe 就再也收不到自动更新，每个朋友都得手动重装。所以生成后**马上**存进 Google 密码管理器，脚本会让你复制回来核对一次。
- 公钥是**公开值**，不是密钥。脚本最后把它打印出来，你原样发给主持人，前端 B 写进 exe 的配置。

## 二、运行前准备

1. **签名工具**：主持人会告诉你签名工具（`cargo-tauri.exe`）从哪里下载、放在哪个文件夹（待定，见文末“待定”第 1 条）。**那个文件夹里只放 `cargo-tauri.exe` 一个文件**（签名工具启动时会先找同一个文件夹里的东西，放了别的文件可能被它加载）。脚本会核对它的 SHA-256，和 `tools/ci-tools.lock` 对不上就停。
2. **完全退出 Claude**：Claude 桌面 App、终端里的 claude、编辑器里的 Claude 扩展都关掉（存私钥时剪贴板里会短暂放着私钥）。**脚本不查这一条**（R-298，和其他密钥脚本一致），要靠你自己关。
3. **浏览器里的 AI 扩展**：要存私钥的那个浏览器里，**Claude 扩展和其他 AI、读页面类扩展（翻译、总结、写作助手、密码以外的“读取网页内容”类扩展）先停用**；或者换一个没装任何扩展的浏览器配置（Chrome 右上角头像 › 添加 › 新建一个配置，只登录 Google）。脚本查不出浏览器扩展，要靠你自己停。
4. **剪贴板**：设置 › 系统 › 剪贴板，**“剪贴板历史记录”和“跨设备共享”都关掉**。脚本两样都查。
   剪贴板管理软件、远程桌面、手机连接（Phone Link 的跨设备剪贴板）也会读剪贴板，脚本查不出来，运行前先关掉。
   脚本放私钥进剪贴板时另带“不进剪贴板历史、不上传云剪贴板、不给剪贴板监视程序”三个标记，但不是所有程序都认这些标记，所以上面几样还是要关。
5. **正式那次**：插好 U 盘，记下它的盘符（例如 `F:`）。U 盘上不能已经有 `柠檬记-签名密钥\lemomemo-tauri-prod.key`，脚本不会覆盖旧钥匙。
6. **只在这台电脑上操作**：存进 Google 密码管理器、复制回来核对，都在**运行脚本的这台电脑的浏览器里**做（<https://passwords.google.com>）。**不要在手机上操作，也不要用微信、KakaoTalk、邮件、备忘录把私钥传到手机**——私钥一经过这些软件，就会留在它们的服务器或聊天记录里。

## 三、步骤（预览）

1. **先单独核对脚本**：开始菜单打开一个**新的** “Windows PowerShell” 窗口，粘贴下面这一行，按回车：

   ```
   Get-FileHash -Algorithm SHA256 "D:\claude code\柠檬记APP\tools\keys\gen-tauri-key.ps1"
   ```

   显示的 Hash 和审查记录里“gen-tauri-key.ps1 冻结副本”的哈希**逐字核对**（大小写不用管）。不一样就**不要运行**，告诉主持人。
   （脚本运行时自己也会打印一次哈希，但那时脚本已经在跑了；先在运行前单独核对一次才可靠。）
2. 在同一个窗口粘贴下面这一行（签名工具的路径换成主持人告诉你的），按回车：

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File "D:\claude code\柠檬记APP\tools\keys\gen-tauri-key.ps1" -Target preview -Signer "E:\柠檬记-工具\cargo-tauri.exe"
   ```

3. 脚本先做检查，然后打印「本脚本的 SHA-256：…」。再和第 1 步核对一次，不一样就按 Ctrl+C 停下，告诉主持人。
4. 签名工具问 `Password:` 和 `Password (one more time):`：**自己想一个密码**：用 **4 个以上随机的词**组成（例如随手翻书挑 4 个不相关的词连起来；不要用名字、生日、常用句子），**自己用键盘手打**，不要从别处复制粘贴（复制的东西会经过剪贴板）；不要和别的密码相同，**不能为空**。输两次，屏幕上不显示是正常的。**这个密码记下来**，下一步存进同一条记录的备注里。
5. 脚本显示「私钥已放进剪贴板」后：在**这台电脑的浏览器里**打开 Google 密码管理器 › 添加：
   - 网站或应用：`柠檬记 电脑版签名私钥（预览）`
   - 用户名：`preview`
   - 密码：粘贴（Ctrl+V）
   - 备注：手打第 4 步你想的那个私钥密码（私钥和它的密码存在**同一条**记录里，R-298）
   - 保存。然后回到 PowerShell 窗口**按回车**，脚本马上清空剪贴板。
   - **120 秒内要按回车**：超过 120 秒脚本会自动清空剪贴板，提示你重来一次（再放一次私钥进剪贴板）。没存好就重新粘贴、保存，再按回车。
6. 脚本让你**核对一次**：在这台电脑的浏览器里打开刚存的那一条，复制“密码”，回到窗口粘贴、按回车（屏幕不显示）。显示「Google 密码管理器里存的私钥和生成的一致」才算存好。
   对不上时脚本会重新把私钥放进剪贴板，把那一条的密码改掉再来一次，最多 3 次（120 秒没按回车也算一次）。3 次都没存好，脚本会说明是超时还是对不上，这把作废：删掉那一条（如果存了），从第 2 步重来。
7. 脚本最后单独一行打印**公钥**（一长串字母数字），后面有一行 key id。用鼠标选中公钥那一行复制，贴进聊天，说「预览签名公钥」。公钥是公开值，不怕看见。
8. **收尾**：关掉这个 PowerShell 窗口。私钥不要再复制到任何地方。

**中途想停**：按 **Ctrl+C**，脚本会清空剪贴板再退出。**不要直接点窗口右上角的 × 关掉**：那样脚本最后清剪贴板那一步不会执行，剪贴板里可能还留着私钥。万一已经点了 ×，马上随便复制一段别的文字（例如这一行），把剪贴板盖掉。

和预览一样，有四处不同：

- 第 2 步那一行改成（`F:` 换成你 U 盘的盘符）：

  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File "D:\claude code\柠檬记APP\tools\keys\gen-tauri-key.ps1" -Target prod -Signer "E:\柠檬记-工具\cargo-tauri.exe" -UsbDrive F:
  ```

- 生成后脚本先把私钥（加密过的）和公钥写进 U 盘的 `柠檬记-签名密钥\lemomemo-tauri-prod.key`、`lemomemo-tauri-prod.key.pub`（只新建、不覆盖，写完刷到盘上），读回来核对一遍；
- Google 密码管理器里那一条叫 `柠檬记 电脑版签名私钥（正式）`，用户名 `prod`；
- 全部做完以后，**先在任务栏右下角点“安全删除硬件并弹出媒体”弹出 U 盘，再拔下来**放好；不要直接拔，也不要一直插在开发电脑上。

## 五、第一次用，可以先练一遍

- 在第 2 步那一行末尾加 ` -Practice`：照样生成一把、问密码，但**只核对格式就丢掉**：不写 U 盘、不进剪贴板、不让你存，最后只显示这把的 key id。密码随便输一个不为空的就行。
- 想把“存进 Google 密码管理器、复制回来核对”也练一遍（看看密码管理器存不存得下这么长的一串，约 350 个字符），再加 ` -PracticeSave`（要和 `-Practice` 一起用）。那一条叫 `柠檬记 练习（用完删掉）`，**练完到 Google 密码管理器把它删掉**。练习用的钥匙已经丢弃，不要交给任何人。
- 练完去掉 `-Practice`（和 `-PracticeSave`）正式跑。

## 六、出错了怎么办

- 「剪贴板历史」「跨设备共享」「transcript」「环境变量 … 设着」：按提示关掉对应的东西，关掉窗口，新开一个再运行。什么都没生成，剪贴板也没动过。
- 「tools\ci-tools.lock 里还没有 tauri-signer」：签名工具还没选定，先别运行，告诉主持人。
- 「签名工具的 SHA-256 和 tools\ci-tools.lock 不一致」：不要用这个文件，重新下载或告诉主持人。
- 「密码为空」：问密码时直接按了回车。重新运行，输一个不为空的密码。
  说明：签名工具遇到空密码时**照样**生成“加密格式”的私钥，只在屏幕输出里打印一行 `<empty>`；脚本靠这一行判断密码为空。私钥格式里的 Sc 标记只说明格式是加密盒，不能证明密码不为空。
- 「私钥没有加密」「公钥格式不对」「key id … 对不上」「输出里找不到私钥和公钥」：签名工具的输出和预期不一样，什么都没保存。告诉主持人。
- 「U 盘上已经有 lemomemo-tauri-prod.key」：先告诉主持人，确认确实要换新钥匙，再把旧文件挪走（**不要删**）。
- 「… 不是可移动磁盘」「… 是系统盘」「找不到 … 这个盘」：插的是移动硬盘、盘符写错了、或 U 盘没插好。换 U 盘，或告诉主持人（见文末“待定”第 2 条）。
- 「120 秒没按回车」：剪贴板已自动清空，脚本会再放一次，照第三节第 5 步存好再按回车。
- 其他报错：**选中报错文字复制，贴进聊天**发给主持人（报错里不会有私钥）。不要截图：截图会进相册或截图工具的历史。

## 七、换钥匙（私钥丢了、怀疑泄露）

- **预览**：在 Google 密码管理器里删掉旧的那一条，按第三节重新生成，把新公钥发给主持人。前端 B 换公钥、出新的预览版，已装的预览版 exe 要手动重装一次。
- **正式**：先告诉主持人，不要自己先删。旧钥匙丢了，已装的正式版收不到自动更新，要通知朋友手动重装新版，这要主持人安排。
