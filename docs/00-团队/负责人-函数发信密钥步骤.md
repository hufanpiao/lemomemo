# 负责人操作：设函数用的三个注册密钥（RESEND_API_KEY、TURNSTILE_SECRET、SIGNUP_HASH_SECRET）

- 日期：2026-10-30（运维写；明早清单第 24 条、验收清单 D3）
- 为什么要做：预览项目的 Edge Function Secrets 里没有这三个，`invite-signup` 一律回 `misconfigured`，用邀请码注册卡在这一步。`account`、`account-purge` 也用 `RESEND_API_KEY`（发注销确认信），`account-purge` 也用 `SIGNUP_HASH_SECRET`。
- 依据：架构 8.4（函数 secret 一表）、0.38 第 19 条（`SIGNUP_HASH_SECRET`：32 字节随机，丢了重新生成）
- 脚本：`tools/keys/set-signup-secrets.ps1`（10-30 已用本机假服务从头跑通，`tests/build/set-signup-secrets.test.ts`）
- 预览、正式**各做一次**，两边的值都不一样。先做预览。
- 每次约 10 分钟。你要做的：在 Resend 建一把只能发信的密钥、在 Cloudflare 复制 Turnstile 的 Secret Key、生成 Supabase 临时令牌、运行脚本、按提示依次粘贴。`SIGNUP_HASH_SECRET` 由脚本在你电脑上随机生成，你不用管。
- 三样东西都不会显示在屏幕上，也不会存到任何文件；不用另存（R-220），丢了就重新生成、加 `-Rotate` 重跑。
- 已经设过的不会被覆盖。只想换其中某一个时，见文末“以后要换”。

## 步骤

1. **在 Resend 建发信密钥**（要写 RESEND_API_KEY 时才需要；★ 你本人）：
   - 打开下面这个地址，点 **Create API Key**：

     <https://resend.com/api-keys>

   - 名字：预览填 `edge-functions-preview`，正式填 `edge-functions-prod`。**另建一把**，不要用 Supabase SMTP 那把（那把只给登录验证码用，两把分开，哪把出事只换哪把）。
   - 权限（Permission）选 **Sending access**（只能发信），域名（Domain）选 **lemomemo.com**。不要选 Full access。
   - 点创建。密钥**只显示这一次**、以 `re_` 开头。先别复制，等第 4 步脚本问到时再回来点复制（这一页先别关）。
2. **找到 Turnstile 的 Secret Key**（要写 TURNSTILE_SECRET 时才需要）：
   - 打开 dash.cloudflare.com，左侧点 **Turnstile**；
   - 预览点 `柠檬记 预览` 那个组件（主机名是 `preview.lemomemo.com`），正式点 `柠檬记 正式`（主机名 `lemomemo.com`）；
   - 点 **Settings**（设置），页面上有 **Site Key** 和 **Secret Key** 两个值。要的是 **Secret Key**（以 `0x4` 开头），不是 Site Key。先别复制，等脚本问到时再来复制（这一页也先别关）。
   - 如果 Secret Key 是隐藏的，点旁边的眼睛或 Copy 按钮就行。`1x0000…`、`2x0000…`、`3x0000…` 这种是 Cloudflare 文档里的测试密钥，脚本会拒收。
3. **生成 Supabase 临时令牌**：打开下面这个地址，新建令牌：

   <https://supabase.com/dashboard/account/tokens>

   - 类型选项目级（Scoped），**只选这一个项目**：预览选 lemomemo-preview，正式选 lemomemo-prod；
   - 到期选 1 天；
   - 权限只勾这两项，其余都不给：
     - Edge Function Secrets：Read-write（写三个 secret，并核对写进去了）
     - Project Settings：Read（核对项目名，防止贴错环境）
   - 生成后先别复制，等脚本问到时再复制。
   - 权限名是照 Supabase 官方文档写的，**没有在真实的令牌页面上核对过**。页面上的写法不一样，或者脚本报 HTTP 401、403，截图发给主持人。
4. **确认剪贴板历史是关着的**：设置 › 系统 › 剪贴板 › 剪贴板历史。剪贴板管理软件、远程桌面、手机连接（Phone Link 的跨设备剪贴板）也会读剪贴板，运行前先关掉。不用退出 Claude（R-223）。
5. **运行脚本**：开始菜单打开“Windows PowerShell”，粘贴下面这一行，按回车（正式那次把最后的 `preview` 改成 `prod`）：

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File "D:\claude code\柠檬记APP\tools\keys\set-signup-secrets.ps1" -Target preview
   ```

6. **按提示依次粘贴**（每次都是：回网页点复制 → 回 PowerShell 窗口粘贴 → 回车；屏幕上什么都不显示是正常的，脚本读完会清剪贴板）：
   - 先是第 3 步的 Supabase 令牌（以 `sbp_` 开头）；
   - 脚本会列出三个名字现在有没有，只问还没有的：Resend 密钥（第 1 步，`re_` 开头），然后是 Turnstile Secret Key（第 2 步，`0x4` 开头）；
   - `SIGNUP_HASH_SECRET` 不用粘贴，脚本自己生成；
   - 格式不对会当场让你重贴，最多 3 次。
   - 看到「三个名字都在，原有的 … 个 secrets 都在」和「全部写好」就成了。
7. **收尾（马上做，先删令牌再关窗口）**：
   - 回到第 3 步的令牌页，**删掉这把临时令牌**；
   - 关掉这个 PowerShell 窗口；
   - Resend、Cloudflare 的网页可以关了（Resend 那把密钥之后在网页上再也看不到原文，这是正常的，不用另存）；
   - 回到 Claude 说一句“预览（或正式）的注册密钥设好了”，然后再试一次用邀请码注册。

## 出错时

- 屏幕上的黄字、红字可以直接截图发给主持人，脚本不会打印任何密钥和令牌。
- 报 HTTP 401、403：多半是令牌权限没勾对或选错了项目，截图发给主持人。要重新生成令牌的话，**先把这把旧令牌删掉**（第 3 步的令牌页），再生成新的，不要让旧令牌留到 1 天后自己过期。
- 「这个 Supabase 项目叫…，不是 lemomemo-preview」：令牌选错了项目，先删掉这把，再重新生成一把只选对的项目。
- 「连续 3 次格式不对」：多半复制错了（例如复制成了 Turnstile 的 Site Key，或 Resend 的密钥没复制全）。Resend 那把只显示一次，丢了就删掉重建一把。
- 写入时报 HTTP 4xx、5xx：什么都没写进去或只写了一部分都没关系，重新运行一次即可（已经写进去的不会被覆盖，脚本只补缺的）。
- 设好以后注册仍然报 `misconfigured`：截图发给主持人。正式环境还要有 `PROXY_SECRET`（预览没有它也能注册，只是限流不准）。

## 以后要换

在第 5 步那行命令后面加 `-Rotate` 和要换的名字（大写原样、逗号分隔、中间不加空格）：

```
powershell -NoProfile -ExecutionPolicy Bypass -File "D:\claude code\柠檬记APP\tools\keys\set-signup-secrets.ps1" -Target preview -Rotate RESEND_API_KEY
```

- 可以写 `-Rotate RESEND_API_KEY,TURNSTILE_SECRET`，或 `-Rotate all` 三个都换。
- 换 `SIGNUP_HASH_SECRET` 的后果：还在 10 分钟里的注册要重来、注册限流计数归零，没有别的影响。
- 换 Resend 密钥后，记得回 Resend 把旧的那把删掉。

## 剩下的风险

- 临时令牌在你删掉之前一直有效，所以第 7 步要跑完马上删。它只有 Edge Function Secrets 读写和 Project Settings 只读，不能动数据库。
- 仅就我们这一侧而言，三个值只在写进 Supabase 的那一个 HTTPS 请求里出现一次。Supabase 平台那一侧是否记录请求正文，我们控制不了。
- 值在脚本的内存里只短暂存在，用完马上清掉。PowerShell 没法把内存逐字节清零，所以最后要关掉窗口。
- 粘贴要经过剪贴板：脚本读完就清，但剪贴板管理软件、跨设备剪贴板脚本查不出来，所以第 4 步要先关掉。
