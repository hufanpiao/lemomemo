- 脚本：`tools/keys/gen-vault-keys.ps1`、`tools/keys/check-vault-keys-leak.ps1`（11-14 已用假值从头跑通，`tests/build/gen-vault-keys.test.ts` 7 条全过）

## 一、生成并写入（第 1 步）

1. **生成临时令牌**：打开 <https://supabase.com/dashboard/account/tokens>，新建令牌：
   - 类型选项目级（Scoped），**只选 lemomemo-preview**；
   - 到期选 1 天；
   - 权限只勾两项，其余都不给：Edge Function Secrets：Read-write；Project Settings：Read；
   - 生成后点复制。不要粘贴到别的地方。
2. **准备窗口**：
   - 确认剪贴板历史是关着的：设置 › 系统 › 剪贴板 › 剪贴板历史（脚本会检查）；
   - 这一步屏幕上会显示两把钥匙各一次：确认身边没人看、没有在共享屏幕或录屏；**把 Claude 桌面应用最小化或退出**，让它看不到这个窗口。
3. **打开 Google 密码管理器**：在浏览器里打开 <https://passwords.google.com>，先不要新建，等脚本提示。
4. **运行脚本**：开始菜单打开“Windows PowerShell”，粘贴下面这一行，按回车：

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File "D:\claude code\柠檬记APP\tools\keys\gen-vault-keys.ps1" -Target preview
   ```

5. 提示粘贴令牌时，粘贴第 1 步复制的令牌（屏幕上什么都不显示，这是正常的），按回车。
6. 脚本提示“准备好了按回车”后：
   1. 在 Google 密码管理器里点“添加”，名称写 **柠檬记 隐私记总钥匙（预览）**；
   2. 回到 PowerShell 按回车，屏幕上会显示 `VAULT_KEY`（黄色的一行）；
   3. 把这一行**完整**复制进 Google 密码管理器那一条（用户名一栏写 `VAULT_KEY`，密码一栏贴值）；
   4. 回到 PowerShell 按回车，屏幕会清掉；接着脚本请你**从 Google 密码管理器里把刚存的值复制回来粘贴一遍**，用来核对你存的是对的；
   5. `VAULT_PIN_PEPPER` 同样做一遍，贴进同一条的备注里（写成“VAULT_PIN_PEPPER：值”），保存这一条；
   6. 两把都核对过，脚本才会写进 Supabase。核对 3 次都对不上会停下、什么都不写，重跑脚本就会生成新的值（原来那次的作废）。
7. 看到 `已写入 VAULT_KEY、VAULT_PIN_PEPPER、VAULT_TOKEN_SECRET；三个名字都在` 就好了。
8. **收尾**：关掉这个 PowerShell 窗口；回到第 1 步的令牌页删掉这把令牌；回到 Claude 说一句“预览的隐私记钥匙设好了”（**不要贴任何值**）。

## 二、泄漏检查（第 2 步，TC-B5-15）

1. 照样确认剪贴板历史关着；打开 Google 密码管理器那一条。
2. 开始菜单打开“Windows PowerShell”，粘贴下面这一行，按回车：

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File "D:\claude code\柠檬记APP\tools\keys\check-vault-keys-leak.ps1"
   ```

3. 依次从 Google 密码管理器复制 `VAULT_KEY`、`VAULT_PIN_PEPPER` 粘贴进去（屏幕不显示）。
4. 脚本会在这几处找这两把钥匙（原样、base64url、十六进制三种写法都找），每处只报“没找到”或“找到 N 处”，不显示在哪个文件：
   Claude 的会话记录和工具输出缓存（`%USERPROFILE%\.claude`）、发布稿子的本地存档、本机资料夹、仓库工作区、git 历史、PowerShell 历史、CI 日志（装了 gh 并登录过才查，没装就写“跳过”）。git 历史和会话记录比较大，可能要几分钟。
5. 结果截图存进 `D:\claude code\柠檬记APP-本机资料\`（不进仓库），回到 Claude 说“泄漏检查没找到”或“泄漏检查找到 N 处”。

## 出错时

- 屏幕上的黄字、红字可以直接截图发给主持人：脚本除了第 6 步那两次，不会打印任何钥匙和令牌。
- 提示「VAULT_KEY、VAULT_PIN_PEPPER：已经有了，不换」：说明以前已经生成过，脚本不会覆盖（覆盖会让已有的隐私记打不开），这是正常的保护。
- 提示「只有一个在，这不正常」：什么都没写，告诉主持人。
- 写入那一步失败：钥匙没有写进去，可以重新生成令牌后重跑；这次存进 Google 密码管理器的那条作废，删掉以免混淆。
