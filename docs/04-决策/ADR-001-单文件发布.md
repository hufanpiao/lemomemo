# ADR-001 单文件发布

- 状态：已采纳（v1 起）
- 日期：2026-10-23

## 背景
App 发布在 claude.ai 的 artifact 上，平台以单个 HTML 页面为发布单位。v1、v2 都是一个手写的 `planner.html`（v2 约 55 KB），样式、脚本全在里面，越改越难维护；本地测试还要手工把“页面骨架 + mock.js + planner.html”拼成 `test.html`。

## 决定
- 线上始终发布**一个自包含的 HTML 文件**，链接保持 https://claude.ai/artifact/MVXvnr3rFUxgFKZesXWGVT 不变，每次发布线上版本号加 1。
- 开发时源码拆分在 `src/`（样式、脚本分模块），由 `build/build.py` 按 `build/manifest.json` 拼成 `dist/planner.html`（发布用）和 `dist/test.html`（测试用）。
- 每个已发布版本冻结到 `archive/releases/vN/planner.html`，不再修改。

## 后果
- 好处：源码可读、可分工；测试页和发布页由同一份源码生成，不会走样。
- 代价：多了一步构建；`dist/` 是产物，不能手改，否则下次构建会被覆盖。
- 以后做独立服务器版时，构建脚本加 `--target web` 输出多文件 PWA（见 [ADR-007](ADR-007-目标形态PWA与独立服务器.md)）。
