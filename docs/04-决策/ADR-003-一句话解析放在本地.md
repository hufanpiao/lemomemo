# ADR-003 一句话解析放在本地

- 状态：**已被 [ADR-015](ADR-015-AI只用Flash-Lite加本地规则.md) 部分取代**（2026-10-24；v2 起采纳。本地规则仍优先、离线仍可用；规则没把握的句子和录音交给 Gemini Flash-Lite）
- 日期：2026-10-23

## 背景
PM-3 提议用一个统一输入框替代两张表单；PM-2 建议“一句话快速添加”，可以调用 Claude 拆成 JSON，但同时指出频率限制和首次授权的问题，建议本地正则兜底。

## 决定
- 一句话解析（`parseQuick`）完全在页面本地完成，不调用 Claude：识别日期、时间、项目、重要；有时间算日程，没时间算待办。
- 解析结果先填进弹出层表单，用户可以改了再保存（v3 起在输入框下方实时显示识别结果）。
- 复杂说法交给聊天：用户在聊天里对 Claude 说，Claude 直接写数据库。

## 后果
- 好处：零延迟、无调用次数限制、离线也能用。
- 代价：只能覆盖规则写到的说法，第二轮评审发现大量误判（“明天3点”被当成凌晨、“3.5万”被当成日期等），v3 逐条修正。
- 规则必须有单元测试守住：`tests/unit/parse-quick.test.mjs`。
