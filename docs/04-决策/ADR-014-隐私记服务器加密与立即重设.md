# ADR-014 隐私记：服务器端加密与立即重设

- 状态：**已采纳**（2026-10-24）
- 日期：2026-10-24
- 来源：需求 R-41、R-56、R-57、R-82、R-86、R-90；安全审查（架构 v4）中 2、中 3；第七轮整体检查；[架构设计-v4](../10-架构/架构设计-v4.md) 5.5

## 背景
随手记里要有一块“隐私记”，用数字密码或 Face ID / Windows Hello 解锁（Windows Hello 只在 Edge 安装版里有；exe 页面打包后用不了 WebAuthn，只能输密码，R-105）。产品负责人要求：忘了密码用邮箱验证码就能立即重设（R-56），隐私记也交给 AI 分类（R-57，朋友也默认开，R-82）。这两条决定了不能做“只有本人能解密”的端到端加密：服务器必须能解密，才能交给 AI，也才能在重设密码后内容不丢。

## 决定
1. **加密**：服务器函数用 `VAULT_KEY` 按用户派生子密钥，AES-256-GCM（随机 nonce，AAD = user_id|note_id|enc_key_id）加密正文；数据库里只有密文。数据库约束保证隐私记不留明文残留：标题、正文为空，转写原文为空、标签为空、AI 元数据和转换记录为空。
2. **密码**：4–12 位数字，`HMAC-SHA256(PIN_PEPPER, user_id:pin)` 存哈希；连续输错 5 次逐级锁定（1 分钟起，最长 24 小时），锁定时推送通知。
3. **令牌**：解锁后发 10 分钟有效的 `vault_token`，内含 `pin_epoch`；重设或改密码时 `pin_epoch` 加 1，旧令牌立即失效，并**清空全部 Face ID / Windows Hello 凭据**、推送通知、发邮件。
4. **重设**：重新用邮箱验证码登录，10 分钟内（看 JWT `amr` 里 otp 的时间，不看 iat）可以设新密码，立即生效，内容不受影响。不设冷静期（R-56）。
5. **上锁**：离开（切到后台或窗口失焦）或前台无操作满 1 分钟，或按 Ctrl+L（R-86，可在设置里改）。明文只在内存里，不进本机缓存。
6. **图片**：放在不对外的 vault-images 桶，4.0.0 **不加密**（R-104 产品负责人已定），不存定位（R-108 起普通随手记的照片也一律不存定位）；隐私说明如实写明。
7. **钥匙生成**：VAULT_KEY、PIN_PEPPER 由产品负责人本人运行脚本生成、直接写入，不经过 AI（第七轮第二轮人员 N4）。
8. **钥匙保管**：`VAULT_KEY`、`PIN_PEPPER` 只放在 `supabase secrets` 和产品负责人 iPhone 的“密码”App 里（R-90）。

## 后果
- 好处：忘了密码也不丢内容；能 AI 分类；拿到数据库也看不到隐私记文字。
- 代价：**运营者技术上能解密**（对外按 R-81 如实说明）；钥匙丢了全部隐私记打不开；拿着已登录手机又能收邮件的人可以重设密码（补救是通知和邮件）。
