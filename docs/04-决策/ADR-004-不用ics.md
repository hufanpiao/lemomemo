# ADR-004 不用 .ics 日历文件

- 状态：已采纳（v3）
- 日期：2026-10-23

## 背景
PM-1、PM-B、PM-D 都建议导出带提醒（VALARM）的 .ics 文件，让手机系统日历在页面关着时准时提醒。主持人核实：claude.ai 页面允许下载的格式只有 txt、json、md、csv、pdf 等，不包括 .ics。

## 决定
- 不做 .ics 导出，也不做“加到手机日历”按钮。
- 备份导出只做 JSON（v3，PM-D⑥）。
- 页面关着时的提醒改走 Claude 定时推送（[ADR-005](ADR-005-页面关闭时的提醒靠Claude定时推送.md)）。

## 后果
- 页面关着时没有系统级的准时提醒，PM-B 设计里的 `icsFor` 字段不做。
- 迁到独立服务器后可以重新评估（届时可下载 .ics，也可用 Web Push，见 [ADR-007](ADR-007-目标形态PWA与独立服务器.md)）。
