## 四、启用本机的提交前密钥检查（合并后做一次）

主持人把运维分支合进来以后，在 `D:\claude code\柠檬记APP` 执行一次（不用管理员）：

```
git config core.hooksPath .githooks
```

之后每次提交都会先跑 gitleaks；没找到 gitleaks 也会拒绝提交。**各个 worktree 共用这一项设置**，所以要等运维分支合并、`.githooks/pre-commit` 在主干上以后再开，免得别的 worktree 提交时找不到钩子文件。
