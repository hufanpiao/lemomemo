## 0. 先看域名（阿里云）
- [ ] 实名认证已通过：阿里云控制台 → 域名 → lemomemo.com，状态不再显示“未实名”或“暂停解析”。
- [ ] 打开**自动续费**。当前到期日是 2028-10-24。
- [ ] 阿里云账号开**两步验证**：右上角头像 → 安全设置 → 开启“MFA（虚拟 MFA）”或“登录保护”，用手机验证器 App 扫码。
- [ ] 查一下阿里云这边有没有开 DNSSEC：域名 → 管理 → DNSSEC 设置。**如果开着，先关掉**再做第 1 节的 DNS 修改，不然换服务器后网站会打不开。
- [ ] 第 1 节 DNS 换好、Cloudflare 显示 Active 以后，打开**注册商锁**：域名 → 管理 → 域名安全（或“域名安全锁”）→ 打开“**禁止转移锁**”（防止域名被转走）。
  - 注意：“**禁止更新锁**”会连 DNS 服务器也不让改，**要在 DNS 换好以后**再决定开不开；开了以后要改 DNS，得先关掉它。
  - 阿里云另有收费的“域名安全锁”（注册局级别），个人项目一般不需要，可以不买。

## 1. Cloudflare（放网页，管域名）
- [ ] 打开 dash.cloudflare.com/sign-up，用 Gmail 注册，然后去邮箱点验证链接。
- [ ] 开启两步验证：右上角头像 → My Profile → Authentication → 2FA。
- [ ] 实名认证通过后：Add a site → 输入 `lemomemo.com` → 选 **Free**。
- [ ] 记下 Cloudflare 给你的两个名称服务器，格式是 `xxx.ns.cloudflare.com`。
- [ ] 回到阿里云：域名 → lemomemo.com → 管理 → DNS 修改 → 修改 DNS 服务器，把它换成上面那两个。
- [ ] 等 Cloudflare 发来“站点已激活”的邮件，从几分钟到几小时不等。
- [ ] **激活以后开 DNSSEC**：Cloudflare → lemomemo.com → DNS → Settings → DNSSEC → Enable。页面会显示一组 **DS 记录**（Key Tag、Algorithm、Digest Type、Digest 四项）。
- [ ] 把这四项填到阿里云：域名 → lemomemo.com → 管理 → DNSSEC 设置 → 添加 DS 记录。填完回 Cloudflare，等它显示“Success”（可能要几小时）。DS 记录是公开信息，不是密钥，看不懂可以截图问。

## 2. Supabase（服务器：数据库、登录、文件）
- [ ] 打开 supabase.com，点 **Continue with GitHub**（建议先做第 3 步注册 GitHub），或者用 Gmail 注册。
- [ ] 开启两步验证：Account → Security。
- [ ] **只注册这一个 Supabase 账号**（R-105），不要再开第二个账号。
- [ ] 先**不要**建项目。开发时在这个账号下建**两个免费项目**：一个正式、一个预览（R-90），区域都选首尔。注册时只要有账号就行。
- [ ] 说明：正式项目的管理令牌**只放在发布环节**（GitHub production 环境，每次要你点“批准”才能用）；Supabase 能不能发“只管一个项目”的令牌，B0 由运维核实：能的话，预览环境放一把只管预览项目的令牌；不能的话，预览环境不放 Supabase 令牌，改用预览项目的数据库连接串（见第 6 节）。

## 3. GitHub（放代码，自动发布）

- [ ] 开启两步验证：Settings → Password and authentication。
- [ ] 先**不要**建仓库，开发时会建一个**私有**仓库。
