# data/ 数据

真实数据存在 claude.ai 的云端数据库里（挂在线上页面下）。这个文件夹放的是：**数据结构**、**本地备份**、**迁移脚本**。

| 子文件夹 | 内容 | 进不进 git |
|---|---|---|
| [schema/](schema/) | 数据结构的机器可读版本（JSON Schema），和 [数据字典](../docs/05-数据字典/数据字典.md) 保持一致 | 进 |
| [backups/](backups/) | 云端数据的本地备份，每次做新版本前必须备份一次 | **不进**（真实个人数据，只留在本机；只有 README 进 git） |
| [migrations/](migrations/) | 数据结构变动、迁到独立服务器时用的迁移脚本 | 进 |

备份规则见 [ADR-009](../docs/04-决策/ADR-009-每个版本前备份数据和源码.md)。
