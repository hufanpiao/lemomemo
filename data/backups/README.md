# 数据备份

**R-208 起（2026-10-28）**：v3（claude.ai 看板）的数据负责人全都不要了，**不再备份 v3 数据**。本文件夹下的旧数据由负责人本人删除，脚本不负责。4.0.0 上线后含用户数据的备份另行设计（[架构设计-v4](../../docs/10-架构/架构设计-v4.md) 第 10 节）。

**版本前备份现在只备份源码**（[ADR-009](../../docs/04-决策/ADR-009-每个版本前备份数据和源码.md)）：每次开始做新版本之前、每次发布之前运行一次。

## 怎么备份
1. 先把改动全部提交；
2. 运行 `python build/backup.py <时机>`，例如 `python build/backup.py 4.0.0开工前`：打 git bundle 并校验，从 bundle 克隆做一次恢复测试（`git fsck --full`，核对 HEAD、目录树、分支和标签），bundle 和 `清单.json` 写到 `E:\柠檬记-备份\版本前\<日期>_<时机>\`；
3. **不加密**（R-209）；放 E 盘，不放 `D:\claude code\` 下面（R-105）；
4. 在 [发布记录](../../docs/08-发布/发布记录.md) 里记一笔（路径、大小、SHA256、提交号）。

## 怎么恢复
`git -c core.longpaths=true clone <bundle 文件> 待办APP`（仓库有超长路径，不加会检出失败）。

本文件夹里除本 README 以外的内容都**不进 git**。
